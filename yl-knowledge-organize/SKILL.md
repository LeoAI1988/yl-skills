# 思想体系与阅读组织

读同级共同合同，先看已有观点树和领域配置。树状层级是主阅读方式，跨领域关联为补充；标题优先用本人原话或可辨识的加工，不只按抽象原子类型分文件夹。

主观点→分支观点→方法/案例/表达→原文与作品。大领域依实际材料形成，不为了目录对称强行凑齐。新来源更新旧概念的发展，不按 Get/其他来源另立体系。

思想体系和完整论述是综合层，不伪装成新的原始语料。作品关联区分“从本文提炼”和“创作时实际使用”，不能倒推创作过程。关系须有具体证据，关键词相同不等于因果。

更新五个读者入口和正反链接。已有库优先调用配置的 `network_refresh`/阅读 hook 并检查其未决队列；新库生成普通 Markdown 分支和双链。通用 `knowledge.py refresh` 仅生成来源/对象阅读索引，不能冒充已经完成语义观点树策展。
