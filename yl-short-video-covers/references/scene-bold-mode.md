# 实景大字

用实景原帧呈现口播主题及片中依据。路由为 `scene-bold`。指定样张或沿用个人认可样张时，先按下节确定每条的样张和制作方式。

## 按样张复刻

1. 优先打开用户当次指定的实际图片，其次打开个人配置里的认可样张。遇到旧链接先从正式成品或已核验的案例找回同一张图。拼图只取指定单幅。样张仍不可读时记录缺项，所有近似候选都留在工作区。
2. 批量制作时给每条绑定一个版式样张和一张本片无字原帧。通栏样张锁定横跨上方的两行大字和底部宽卡。侧排样张锁定左侧斜排大字、右侧真人近景和左下证据卡。根据用户指定、可辨的手势及五官留白选样张。卡片形状、底色、倾斜和黄条随所选样张，内容取自本片。
3. 有原模板或本地排版能精确复现时，沿用该模板，并以真实样张验证。否则使用可接收参考图的图像编辑。把单幅样张与本片无字原帧同时作为输入，明确样张提供笔画、字行、落影、构图和卡片，原帧提供人物、表情、眼镜和实景。逐行给出本片定稿文字、强调色及卡片原文，仅使用本片的人物和文案。指定或偏好使用 OpenAI API 时，按 [API 额度执行方法](../../yl-openai-api-credits/SKILL.md)。
4. 用户反馈字体、投影或构图有差异时，回到对应样张重新选择图像参考编辑，或使用已经通过同尺验证的原模板。按反馈修正对应字形、光影和排版，逐张重新验收。

## 选景和分区

1. 从完整视频或同版无字底片比对开头和代表帧。找眼神、表情或手势清楚且和标题有关的瞬间。裁成 1080×1440 时保留原片自然光线、景深和人物大小关系，给主体留出独立区域。横屏原帧的面部常可落在画面中部偏右，大小按实际镜头调整，人物不固定到某个角落。
2. 用上方或主体外侧留白放标题。先按完整词组切成两三行，分别确定阅读顺序和强调行。字形向右斜，字行可略向右上扬，采用超粗无衬线字体、白字与暖金重点、紧行距和短黑投影。最长行以变形后真正可见的字面为准尽量填满分给它的宽度，字群下沿可以贴近主体肩线，五官周围留出空隙。空间不足时先重排断行、放大重点词、收紧辅助字或重选原帧，用户定稿标题逐字保留。
3. 下方另排结论或证据。上方说主题和钩子，下方用一至三行说清结果、条件、原话或片中有出处的数字。卡用半透明深色或浅色底，重点词或数字再单独着色。字号小于主标题，同时在缩略图可读。底板宽度随内容和画面，避开脸部与关键手势。若视频只有一个可表达的短判断，按实际内容省略卡片。
4. 主标题区域可局部压暗，并用描边和短投影提高反差。四周保有实景亮度与人物肤色。避开现成字幕、界面边栏和参考图中的社交数据。标题和小卡均使用本片话题与可核对的说法。

## 三种布局示例

按用户给的字和断行逐行排，先放大真实字面与可用文字区，再用 `--headline-weight` 加同色字重；放大后在手机尺寸逐字检查字腔。凡是标题与人相交，三种布局均可用与底片裁切、平移逐像素对齐的透明人物层，将发丝、耳朵、镜架压到字前。个别关键词被挡住时调标题或取景，既保留层次又读得全。

自然肤色以相机原帧为准，本地排版沿用默认 `--skin-lift 0`。只有用户明确要求提亮时才调整，把镜片内可见的皮肤与镜外面颊放在一起检查，保留现场阴影、皮肤纹理和真实反光。

| 上方主标题 | 下方信息层 | 适用构图和参数 |
| --- | --- | --- |
| 左上白色英文主题词和金色中文重点 | 深蓝短签叠在浅色卡上沿，关键词用蓝字 | 适合人脸偏右、左侧上下都有空间的照片。用 `--card-style light`、`--card-label`、`--card-accent`。 |
| 人物靠右，左侧两行黄白大字向右上扬。辅助字可收窄，为核心对照词留足宽度 | 左下微斜暗卡，内有一条紧凑黄底短结论 | 适合主题能用两行讲清，正文还需要一层关键事实和一处短结论。用 `--card-style dark`、`--card-tilt`、`--card-strip`。 |
| 横向铺开的通栏标题，人物头发在标题少量字边前 | 底部宽暗卡，事实数字单独高亮 | 字区先占用上方宽度。用与裁切后原帧逐像素对齐的 `--foreground` 置于标题前，再用 `--face-box` 保护五官和 `--card-accent` 标出数字。轮廓轻压标题边缘，保留每个关键词的可辨字形。 |

## 同尺对照验收

把样张与候选按同一尺度并排，在 1080×1440 和 270×360 分别逐张对照。记录每条对应的样张、原帧、输出及下列观察结果。

| 项目 | 对照要点 |
| --- | --- |
| 字形与大小 | 对照超粗斜体的笔画粗细、转角、重心和中英字重，再看最长行的实际字面是否吃满所选布局的安全文字区。核对每个字、数字和断行，保证紧凑字距下字腔仍清楚。 |
| 行距与斜率 | 看两行的距离、基线角度和字形倾斜是否接近样张，辅助信息与主标题有明确层次。 |
| 落影 | 对照黑落影的方向、偏移和厚度。在完整尺寸和手机尺寸均应看清样张要求的立体层次。遇到深底、镜头高光或很粗的字形时，放大确认影边与字边能分辨。 |
| 构图与卡片 | 对照标题占区、人物的大小和站位、卡片宽度和位置。两种布局按各自绑定的样张验收。检查卡中的事实有原文依据。 |
| 人物与实景 | 与本片原帧并排看五官、肤色、镜片和自然光。发丝可轻压少量字边，五官、末字和关键笔画完整可读。 |

图像编辑后发现五官、肤色或镜片亮度偏移时，按眉眼、鼻梁与镜架对齐原帧。需要复用原片像素时，整张脸连同眼镜作为同一区域处理，柔化外缘并保护标题笔画，再分别核对镜片内与两侧面颊。

上述项目全通过后才替换正式封面。字宽、画布尺寸和脚本清单只覆盖可测参数。重新加载审片页，核对实际读取的封面文件、尺寸和版本指纹。

## 本地排版和检验

通用实景布局可调用 [实景渲染入口](../scripts/render_scene_cover.py)。有参考样张时按同尺结果确认脚本能否复现具体风格。示例在 Skill 文件夹中运行，原帧及输出都位于外部工作目录。

~~~powershell
python -B -X utf8 scripts/render_scene_cover.py --frame ../work/scene.png --crop 600,0,1680,1440 --title "同一件事|怎么更快" --accent-line 2 --line-sizes 0.8,1 --text-box 28,50,770,580 --slant 10 --tilt 4 --card "找准重复步骤|先做一个例子" --card-box 32,1030,960,1376 --card-line-sizes 1,.82 --card-accent "重复步骤" --out ../work/cover.png --manifest-out ../work/cover-check.json
~~~

- `--crop` 使用 EXIF 旋正后的源像素选区。选区为 3:4 时严格采用给定选区，其他比例按中心裁到 3:4。省略时居中裁切整张原图。
- `--text-box`、`--card-box` 与可重复的 `--face-box` 使用 1080×1440 画布坐标，格式为 `x0,y0,x1,y1`。层叠后露出的标题或卡片穿过面框会报错，光影在面框附近渐隐。
- `--title` 和 `--card` 以 `|` 分行。用 `--line-sizes`、`--line-gap`、`--slant` 和 `--tilt` 调整主标题。正的 `--slant` 让字形上边向右，正的 `--tilt` 让行基线向右上扬。可用 `--font` 指定已在机器上安装的重黑字。以上文字按实际渲染边界自适应。
- `--accent-line` 从 1 开始，默认突出末行，给 0 可用全白。结论卡由 `--card-style dark|light` 选底，`--card-accent` 可重复指定要高亮的词，`--card-line-sizes` 控制行间层次。用 `--shade` 调整主标题附近的渐变压暗。
- `--card-label` 添加白字深蓝短签，叠在信息卡上沿。`--card-strip` 在卡内添加黄底短结论，`--card-tilt` 让整张卡轻微倾斜。短签需要有独立的信息。
- `--foreground` 接收已与裁后画面完全对齐的 1080×1440 透明人物层。顺序为原场景、标题、人物前景和下方卡片。软件按可见字形像素核算覆盖比例，单行被盖超过四分之一时提示重排。确认实际遮住的是字边而非关键笔画，并逐张检查眼睛、鼻子和嘴。
- 对照原帧查看 1080×1440 成图和 270×360 缩略图。检查标题有没有吃满安全文字区、人物五官旁有没有干净空间、卡的信息能否一眼读出，以及光线和原场景是否清楚。外置清单可用来核对实际字框、裁切、风格参数与成品哈希。参考图、个人素材和过程文件留在核心之外。
