# 发布流程

按顺序执行。每步失败先解决再进入下一步，不要跳步重试。

本文是当前宿主直接操作视频号页面的流程。收到用户发送的“按已保存清单发布”指令后，读取指定批次并进入页面登录检查；无需工作台开放平台 OAuth，也不调用 `/api/publish` 或以 `/api/runtime` 为先决条件。若之前误走网页直连而收到 503，应回到这里检查实际页面，不能让用户继续等待无关的 API 授权。不得关闭网页 API 原有的授权保护。

## 一、准备阶段

1. 列出成片来源目录的内容，逐条记录：目录名、成片文件名、封面文件名、审查稿路径。**目录里有封面而你打算不用，必须先说出来问用户**，不能默默跳过。
2. 从审查稿提取每条视频的顶部标题。查找 `## 三项内容分析` 下 `标题匹配：` 字段，形如 `前半／后半`，斜杠前后拼起来即为完整标题。
3. 检查标题字数。平台短标题至少 6 字，不足时按标题主旨改写完整后再填，并告知用户改成了什么。
4. 把时刻表逐条展开成待办：时间 → 视频 → 商品 → 标题 → 封面文件。任何一条缺少标题来源或封面文件就先问，不猜。

## 二、文件准备

优先直接读取正式成品与封面路径，按当前宿主工具规范确认可访问性，不预判所有工作区外路径都被禁止。只有实际工具明确拒绝或存在已确认的传输要求时，才把本轮所需文件复制到独立临时目录；不使用联接绕过限制。登记正式源、暂存路径、大小与完整 SHA-256，重试复用已核验副本。按通用默认的 [去重收尾](../../yl-video-archive/references/completion-cleanup.md) 执行：平台完整接收且目标列表回读通过后，自动清理本批暂存，不等预约时刻，不依赖个人约定或额外清理指令；保留失败/结果不明/仍被后续条目使用的文件。发布记录与后续引用使用正式成品路径，不能长期依赖暂存。

## 三、登录与账号核对

1. 先检查宿主当前可见的视频号助手页面；已有登录态就复用并核对账号，不主动退出或清 Cookie。没有页面时打开视频号助手，通过真实页面判断是否需要登录，不能预先认定没有会话。
2. 仅在页面实际要求登录时展示二维码给用户扫码，等待手机确认和后台成功状态。若二维码明确加载失败，可重试一次；扫码和平台登录回调期间不导航不刷新。这是视频号页面登录，不是 WorkBuddy 开放平台 OAuth。
3. **登录后立即核对账号名**。账号不对就停下，不要继续操作。

### 小店授权会顶掉登录态

挂商品时若弹出微信小店授权，**必须用小店超级管理员的微信扫码**——这是平台限制，商品数据权限挂在管理员账号上。

但扫完之后，视频号助手的登录态会跟着管理员本人那个号走（管理员自己也有视频号）。表现为：填好的表单全部丢失，页面跳回账号首页，账号名变成管理员的号。

**正确顺序**：先登录运营号 → 授权一次小店 → 之后挂商品不再弹授权。授权完成后重新核对账号名，若已跳到别的号，重新登录运营号再继续。

### 会被踢下线的情况

用户在同机微信或浏览器里也登录了视频号助手时，可能出现会话互斥，页面弹"账号已在其他设备登录"。发生时先保存待办与已核验结果，协调保留一个操作会话；确需重新登录时由用户正常扫码，随后核对账号与已提交作品。不自动清除 cookies，不连续重登或重发。

## 四、逐条发布

对每条视频重复以下循环。

### 1. 入口

视频管理 → 发表视频。优先在当前编辑表单内定位用途明确的原生视频文件输入框，使用宿主支持的文件上传操作；需要文件选择器时再点击上传区域。不要用全局第一个或最后一个文件输入框猜目标。

上传耗时随体积变化，几十兆到几百兆不等。**轮询等待上传及处理完成，并核对视频预览；输入框出现不等于上传成功，不按固定秒数盲等**。

### 2. 填描述

描述框填：短标题 + 一段空格 + 用户给定的标签串。

标签串原样保留，包括其中的空格，不自行增删标签或改顺序。

### 3. 填短标题

短标题输入框填视频顶部大标题。

字数不足 6 字时平台会红字提示，且发表按钮不可用。按标题主旨改写完整，并告知用户改写结果。

**🔴 特殊字符限制（2026-10-15 实测新发现）**：平台红字提示「标题包含特殊字符，符号仅支持书名号、引号、冒号、加号、问号、百分号、摄氏度，逗号可用空格代替」。

审查稿标题里的全角斜杠「／」是**稿件展示用的分隔符，不是标题的一部分**，提交平台前必须替换为空格。

| 审查稿原标题 | 提交平台填 |
|---|---|
| `整理书桌／先分类再收纳`（通用示例） | `整理书桌 先分类再收纳` |
| `制作计划／明确目标与步骤`（通用示例） | `制作计划 明确目标与步骤` |

出现非法字符时**发表按钮会静默变 disabled**，页面上没有任何按钮态提示，只有发表按钮上方一行红字。红字消失 = 通过。**不要去点「手机预览」「声明原创」找原因**——这两个入口不校验标题，会把人带偏。

**定时发表单选框必须显式点开**：新发表页可能默认为「不定时」，直接去点尚未出现的时间输入框会 timeout。先根据当前页面定位并使用宿主支持的点击操作选中「定时」→ 确认出现「请选择发表时间」输入框 → 再点开填时间。不依赖历史元素索引或页面脚本点击绕过宿主工具限制。

### 4. 声明原创（用户要求时）

点原创声明复选框 → 弹出原创权益确认框 → 勾选同意 → 点「声明原创」按钮确认。

先核对媒体时长和平台提示。已观察到不足 5 秒时平台禁止声明原创；此类视频按清单的短视频例外不声明并记录限制原因，不能反复点击灰显框。时长未知或恰好 5 秒时，以当次平台资格为准；时长足够不等于自动具备全部原创资格。使用弹窗范围内可访问的复选框和按钮定位，缩放或滚动后不得复用旧坐标。

**勾选复选框只是触发弹窗**，必须完成弹窗内的勾选和确认才算生效。跳过弹窗会导致复选框状态与实际声明不一致。

### 5. 清空位置（必做）

位置输入框**默认带城市名**（如"深圳市"）。不清掉会随作品一起发出去。

操作：点位置框 → 下拉展开 → 选「不显示位置」。

用户明确要求带定位时才保留，否则一律清空。这是"不作为就出错"的项。

### 6. 上传封面（必做）

平台默认只用视频自动截帧。成品目录里做好的封面必须手动上传。

操作顺序：
1. 点顶部「封面预览」小图，打开「编辑封面」弹窗
2. 在当前封面弹窗中定位原生图片文件输入框，使用宿主允许的上传方法选入封面 PNG；不能唯一确认目标时先查看当前页面，不使用全局 `.last()` 猜测
3. 上传后弹窗内会出现自定义封面缩略图，核对与本条源封面一致并确认已选中
4. 点右下「确认」生效
5. 回到表单后核对主预览区封面已变成自定义那张

同一素材多次发布时复用同一张封面文件。

### 7. 挂商品（需要时）

商品不在独立字段里，走「链接」下拉：

1. 点「链接」下拉 → 选「商品」
2. 链接栏下方出现「选择需要添加的商品」→ 点击展开商品列表
3. 商品列表中按商品名和价格定位唯一目标行，在该行内部勾选单选框；同名时结合商品 ID 等可见信息确认，不按全局索引或旧坐标选择
4. 点右下「添加」

挂载后商品名称显示在链接栏下方的商品条上，可据此确认挂对没挂错。

同一账号可挂多个商品，重复点「添加」可继续添加。用户说"无商品"时保持链接为默认未选状态。

### 8. 定时

1. 点「定时」单选框（不是「不定时」）
2. 出现「发表时间」输入框后点击展开日期时间选择器
3. 先确认目标日期；主框只读时，定位面板内可编辑的辅助时间框，使用宿主支持的聚焦和键盘操作。确认焦点在该输入框后，连续全选、键入 HH:MM，中间不插入鼠标操作。禁止通过页面脚本 setter 或派发事件伪造输入成功
4. 先回读辅助框，再在当前截图中确认远离日历及日期单元格的安全空白位置关闭面板；宿主允许的失焦操作也需验证确实提交。不要复用某次窗口的坐标或固定等待秒数
5. **回读主表单完整日期和时间**，逐字比对本条清单。日期、小时、分钟任何一个不符都不提交；辅助框显示正确不能替代主表单生效。保存主表单核验截图

同一操作两次无效就停止重复点击，重新查看焦点、控件、可见错误和主表单值。仍无法确定时保留未提交草稿并报告阻塞；只有确认未提交且允许放弃草稿时才重新打开干净发表页。继续后续独立条目须遵循用户的排期和授权，不能拿错误时间“先发表再改”。

这是最容易出错的一步。日期选择器不关闭时，`inputValue` 返回的是修改前的值，界面上看着填对了但实际没生效。**发表前必须回读校验。**

### 9. 回读校验

点发表之前，以下八项逐一确认：

| 校验项 | 方法 | 期望值 |
|---|---|---|
| 短标题 | 读短标题输入框 | 顶部大标题 |
| 定时 | 读发表时间输入框 | 时刻表指定时间 |
| 位置 | 读表单文本，找「位置」下一行 | 不显示位置 |
| 商品 | 读表单文本，找「商品」 | 时刻表指定商品，或未挂 |
| 原创 | 读 `.declare-original-checkbox input` 的 `isChecked` | true（若要求） |
| 活动 | 读表单文本，找「活动」 | 不参与活动 |
| 封面 | 读封面预览区 `img.cover-img` 计数 | ≥1，且为自定义上传 |
| 发表按钮 | `isDisabled()` | false |

**八项全过才能点发表。** 原创项允许按平台明确限制记录“不声明及原因”；封面不能仅凭图片元素计数判断正确，必须核对实际图片。`isDisabled()` 返回 true 时先查当前页面的非法字符、必填项、上传和处理状态，此时不要点发表。

### 10. 发表

点「发表」后回列表核对本条平台 ID、视频、商品、定时时刻和实际状态，并保存核验时间和截图。页面跳转仅是流程信号，不是成功证据；结果不明不重发。

## 五、收尾核对

1. 回作品列表页，提取每条的"将于 YYYY 年 M 月 D 日 HH:MM 发表"，与时刻表逐条比对。
2. 时间不符的立即用「修改并重新发表」修正，改完再核对一次。
3. 如实报告已完成条目、失败条目、未完成原因。**不能把"点过发表"当成"发布成功"。**

## 修改已定时未发表的作品

先按平台作品 ID（有则优先）、标题、缩略图和当前预约时间定位唯一目标卡片，再在卡片内部寻找「修改并重新发表」；不得点击全局第一个同名按钮。进入编辑页再次核对视频、标题、封面和商品身份，错条立即退出且不保存。只改已授权的字段，回读完整主表单后提交。回到列表确认目标的新时间、旧时间已被覆盖且没有新增重复条目；保留更正前后核验记录，不用“最终正确”掩盖曾经误排的事实。

编辑页修改后提交会触发 beforeunload 对话框，需处理后才能完成跳转。

**已发表的作品不承诺可改**，也不尝试改。

## 常见故障与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 登录页显示"加载失败，点击重试" | 二维码 iframe 加载失败 | 刷新页面重新生成码 |
| 表单内容莫名清空、账号变了 | 小店授权用管理员号扫，登录态被顶掉 | 重新登录运营号 |
| 弹"账号已在其他设备登录" | 可能存在会话互斥 | 保存待办并协调单一操作会话，必要时正常扫码；不自动清 cookies 或重发 |
| 点发表按钮没反应 | 短标题不足 6 字、含非法特殊字符、或必填项未完成 | 看红字提示，补齐后重试 |
| 发表按钮静默 disabled、页面无报错 | 短标题含「／」等非法字符 | 按特殊字符表替换后重试 |
| 时间填了但没生效 | 焦点丢失或组件尚未提交 | 连续键盘输入辅助框，安全失焦后回读完整主表单；不符禁止提交 |
| 上传文件被拒 | 当次工具可能限制可访问路径 | 先确认实际报错，必要时复制到允许的临时目录并校验字节；不提前假定所有宿主都有限制 |
| DOM 定位无结果或元素坐标为零 | 可能是隐藏控件、视口或 shadow root 等问题 | 先检查当次宿主可访问树／locator，再用新截图定位；不把一次失败推广为所有 shadow DOM 都不能定位 |
| 弹窗坐标点击不稳定 | 缩放、滚动改变了位置 | 优先在目标弹窗内使用语义定位，上传使用可明确识别的原生文件输入框；必要的坐标必须重新截图 |
| 编辑页跳转卡住 | beforeunload 对话框 | 显式处理该对话框 |
