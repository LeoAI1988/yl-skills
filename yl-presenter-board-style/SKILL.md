# 横屏人物图解风格

用户说出参考名称时，从个人 profile 的 `video.presenter_board_styles` 找到同名预设。也可显式传入 JSON 文件。素材、参考作者、样片和别名由个人层维护。

## 从参考片取样

逐条确认画布、旋转、起止、原视频循环、屏幕黑边及播放器控件。用有内容的有效画面测比例。对照开篇、观点转折、数字例证、过程演示和结尾，为每种采用的版式记录来源时刻。区分跨片反复出现的做法和个别装饰。动态判断看连续帧，声音判断用原音或写清测量手段。把结果落到[预设格式](references/preset.md)。

## 剪到本人原声上

1. 按[真人口播精剪](../yl-remotion-talking-head-editor/SKILL.md)整理失败起句、重复段和停顿。复合素材保留各自源时钟，每条成片共用一条输出时间轴。保留本人独有的比喻、实例、数值和结尾。
2. 先读取预设的 `opening`。若为 `fullscreen_to_split`，片首第一帧使用全屏横向动态人像，依照第一层论点的语气选择缩窗落点。从落点向前预留过渡时长，将同一段连续的人像平滑收至右侧竖向圆角窗，每帧按原比例裁切并跟随人脸。落位后才揭示左侧图解，底部字幕跟随原声。验收须抽看片头全屏、缩窗中段和落位后的连续实帧。其他开场依本次预设选择。分栏阶段保持观看位置稳定。
3. 为每个论证节点记录触发原句和画面变化。数字出口时揭示数字，列举按项点亮，比较时上一项留作参照，条件、结果和反转分步出现。字幕分页可以沿用同一张图。用真实单位，为比喻画原创示意。有真实演示素材时让它居中占主画面，人像缩到右上角。
4. 底纹在手机尺寸应隐约可见。主字粗白，每屏用一种主强调色，黄用于判断或数字，其他颜色按样本和语义选择。暗态可预告后项，信息出口时切到可读亮度。将底带位置、文字可见框传给[字幕排版](../yl-video-text-layout/SKILL.md)。
5. 双语字幕共用时段。中文跟原声，英文次一级，允许把短连接词并到相邻语义页。核对专名、单位、转折、否定和指代。
6. 通过[布局工具](scripts/layout.py)读取实际预设，取得本次导出的像素矩形、字幕中心和色板。先出大人像、分栏、数字或关系变化的关键帧，再从原片合成。检查最长双语页的实际字宽、手机阅读尺寸、圆角、人脸和底带。

## 验收与交接

逐条检查源文件映射、画幅、完整音轨、片首尾、连续帧变化。确认小窗确实在播放本人原片，关键字、数值与原声同步，演示素材有出处。观点片可使用原创信息板。交付成片、字幕与能回查到原片的时间轴。连续听审、机器对读、作者确认各记实际状态。
