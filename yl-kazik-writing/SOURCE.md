# 来源与公开版范围

## 来源

本目录是日常版 `kazik-writing-clone` 的独立公开适配版；原版未被修改。本版自己的版本见 `VERSION`，逐文件上游指纹见 [references/source-snapshot.json](references/source-snapshot.json)。快照只记录来源 slug、安全相对路径和 SHA-256，不包含作者机器路径、账户凭证或原始私人材料。

## 许可

原目录未附独立 LICENSE。用户本轮明确称它为“自己做的卡兹克写作 skill”，并授权公开整理。本公开版维护者方法、脚本和整合文档以随附 [MIT License](LICENSE) 发布，署名为 yl Skill Cluster contributors。参考研究对象为“数字生命卡兹克”的公开文章；这些文章的版权仍归原权利人，本包不包含文章全文，不授予原文、截图或独特表达的再分发权，也不表示原作者参与、授权或背书。公开来源矩阵保留标题与链接，属于历史研究线索，未在本次整理中重新验证指标。

## 适配内容

- 保留文章原型、HKRO、证据阶梯、标题/开头、主线、节奏、原创性审计、归档闭环和查重脚本。
- 私人笔记 ID、知识库名称、原话与真实项目实践不随包分发，改用安装者语料卡。
- 用通用事件案例模板替代含私人实践和动态事实的单篇案例包；保留公开来源目录和机制观察。
- 所有句段例子换成明确标注的虚构教学例，不冒充实际经历或当前产品事实。
- 固定 CTA 改为可选 `--cta-file`；不再携带参考作者邮箱。
- 区分本引擎与 `yl-human-writing`；笔记服务改为可选自配，不依赖未列明私人 Skill。

## 运行与数据

Python 3.10 或更新版本，只使用 Python 标准库。无需访问维护者的机器、账号或其他私人 Skill。安装者提供自己的原始素材。所有任务输入、CTA、临时文件、日志和派生成果应保存在安装者自己的项目目录；本目录只放规则、可分发参考和脚本。连接外部笔记或图片服务时，由安装者自行配置工具与凭证，并按其实际授权范围调用。没有连接器仍可用本地材料完成写作。

运行路径均相对当前 Skill 目录，建议从 Skill 根目录执行，输入和输出可指向安装者项目中的绝对路径。逐文件复核与验证见 [AUDIT.md](AUDIT.md)。
