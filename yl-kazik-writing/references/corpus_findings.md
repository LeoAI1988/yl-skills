## 4. 选题引擎

稳定出现五类：

1. 热点事件 + 亲手测试；
2. 产品更新 + 具体工作流；
3. AI技术 + 普通人的利益冲突；
4. 前沿信号 + 行业规则判断；
5. 真实人物 + 技术情绪。

选题强度来自交叉，不来自标题形容词：

`专业领域 + 普遍兴趣 + 当前时间窗口 + 用户拥有的真实材料`

## 5. 标题与开头

高传播标题常组合：

- 第一人称真实投入；
- 明确数字或使用时长；
- 强冲突、反转或悖论；
- 时代变化；
- 具象物承载抽象问题；
- 高识别人物、产品或平台。

开头先给场景、操作、人物或异常结果，再补背景。不要先定义概念。

## 6. 正文与结尾

最稳定的正文不是简单“总分总”，而是证据阶梯：

`个人触发 → 反常案例 → 更多证据 → 机制解释 → 扩到行业或人的处境 → 作者判断`

全文样本还表现出：

- 第一人称是实验者、消费者或调查者，而非全知编辑；
- 中段有多次小反转；
- 口语提供亲近感，截图、数据和公开材料提供可信度；
- 允许暴露成本、失败和误判；
- 结尾常扩大尺度，但必须由前文因果自然生长。

## 7. 爆点机制

1. 反常识；
2. 可验证；
3. 视觉证据；
4. 权威材料；
5. 普通人利益；
6. 双面情绪；
7. 尺度升级；
8. 时间优势。

爆点不能牺牲事实边界，也不能把参考作者的独特笑话和比喻搬进新文。

## 8. 使用限制

- 30篇中只有10篇完成全文结构阅读；
- 其余20篇不能推断未核实的结尾和完整段落顺序；
- 腾讯指标只用于研究样本，不用于宣称公众号排名；
- 样本标题可以帮助识别机制，不能作为标题模板逐字改造；
- 文章的独特性必须来自用户材料，而不是从样本抽取口癖。
