# 图示与版式决策

## 按关系选图

| 要表达的关系 | 优先构图 | 检查重点 |
|---|---|---|
| 多个平台或类别并置 | 同尺寸卡片／整齐列表 | 视觉权重一致，不暗示从属或顺序 |
| 分类、形式、平台对应 | 分栏生态图／泳道 | 标签各属哪个维度；一对多与并列区别 |
| 多种素材与表达形式 | 矩阵或少量示例路径 | 不穷尽所有连线，避免交叉线网；非排他关系要写清 |
| 小闭环与大闭环 | 两层环路／上下分层 | 每条反馈线的对象明确，复盘回到真正积累资产的节点 |
| 平台内部生态闭环 | 圆环／环形节点 | 闭环节点及方向明确；外部渠道在环外同级并置 |
| 核心资产向外衍生 | 中心辐射／主干分支 | 核心地位与派生关系同时可见 |
| 输入、加工、个性化结果 | 左中右三栏 | 来源平行、加工居中、结果分组；留出商品图独立空间 |
| 世界观解读多个现实问题 | 透镜／同一框架与多样现实的映射 | 图示解释选题生成机制，而非堆放互不相关图标 |
| 积累、复用与复利 | 增长飞轮／逐步扩大的资产库 | 回流产物是什么；数量来自原稿或显式示例 |
| 不同发布顺序 | 双路径对照 | 各路径的验证/沉淀作用；不要重复生态总览 |

少量层级用颜色、距离和排列说明，不依赖大量箭头。圆角卡片可柔化版式，但不全局替换：权重色条、刻度和容器按功能决定形状。循环线有方向、有回写目标；线不穿字，不用无意义闭环凑对称。

## 内容与视觉分工

- 主标题说本页结论，副标题承接角度；正文只保留台上必须看见的关键词。更多解释放演讲者备注或源段映射。
- 三句核心观点可合成一幅概念图或拆成三幅；先定义每句话的视觉隐喻，后面复现时沿用同一视觉母题。
- 文字和图示是可编辑层；艺术概念画是独立图片。避免图片中烘焙整段文字导致批注修改困难。
- 严格区分“文字颜色改白”“删掉这行”“所有框调整”等局部与全局范围。图示重构仍保留内容逻辑，不借机改写已确认观点。
- 背景透明看实际透明通道和放入幻灯片后的边缘，黑底不能通过换一块黑色底板伪装成透明。
- 商品图不拉伸；保留二维码静区。可按确认范围裁空白，但不裁商品或码。若要求与副标题顶部对齐，以实际形状坐标为准，渲染后确认，不用目测预估代替。

风格卡是项目级资产：尺寸、字体、背景、主辅色、字号层级、边距、卡片/线条、页眉页脚及图像母题都应来自本次参考稿。用户没有给参考时才提出合适的视觉方向；不要把个人模板放入公开 Skill。
