# 宿主运行与验收

## 先确认可用能力

本 Skill 提供方法和只读检查器，不附带幻灯片渲染引擎、商业插件、字体或私人模板。

- Codex 有 Presentations 能力时，按当前宿主官方说明发现运行时；可使用其可编辑演示文稿 API。不要写死作者的安装路径或复制其受限说明到分发包。
- WorkBuddy 使用它当前可用的 PPT 工具、PowerPoint 自动化或已安装生成库。共享 Skill 并不共享另一宿主的专用运行时。
- 对现有文件的小修改优先保留原生包与对象；生成库重建可能损失母版、动画、备注等，先检验保真再选用。
- 缺少工具时说明具体缺口，仍完成可做的规划/定位；安装软件、下载字体或上传素材按当前任务授权，不因装了 Skill 自动授权。

## 只读检查器

Python 3.10+，仅标准库，不联网、不改 PPTX：

```text
python -B scripts/pptx_inspect.py inventory /path/deck.pptx --out /path/qa/inventory.json
python -B scripts/pptx_inspect.py compare /path/base.pptx /path/revised.pptx --out /path/qa/diff.json
```

清单按 presentation.xml 的真实顺序列页，提供文本、形状ID、名字、局部几何、图片引用和文件哈希，供匹配批注。报告可含私人正文，保存在工程区，不能并入 Skill 发布。

比较报告列原始包变动和归一化页面指纹；忽略已知对象命名/ID噪声，以资源内容摘要替代关系编号。它不是视觉比较器：继承母版、布局、字体及主题变化还需查 changed_parts；组内坐标不是屏幕绝对坐标。不要据此宣称所有未改页视觉相同。

## 实际渲染

有 PowerPoint 的 Windows 可用本机 COM 导出副本为 PNG；只关闭本次打开的演示稿，不关闭用户其他文档。若导出 PDF 遇 COM 参数类型问题，可核实当前 API 的 SaveAs PDF 格式；不要通过反复启动多个实例碰运气。PowerShell 5 的含中文脚本使用 UTF-8 BOM，Python 使用 UTF-8。

可用 LibreOffice 或宿主渲染器时标注实际引擎，字体替代或功能不支持单列说明。只有原生应用打开和渲染成功才可报告这项验收；不能把生成函数返回成功当成渲染成功。

## 必要检查

1. ZIP CRC、XML可解析、页面顺序、尺寸、源文件哈希；缺关系或缺媒体是错误。
2. 批注具体字句替换和删除；文本没有重复叠放；字号、颜色及上下对齐正确。
3. 渲染后的截断、拥挤、线穿字、错误箭头、非透明背景、图码清晰度；文字和形状仍可选中编辑。
4. 版本矩阵中的差异成立，公共页对应，商品原件未被误换；若图片被应用重新编码，像素及肉眼检查补充字节哈希。
5. 未要求真实扫码时，不额外声称扫码验收。保持原图只是降低二维码损坏风险。

按变化规模选择验收：一处文案修订不需要重新设计全套；母版或图示系统全改则检查所有受影响页。交付记录区分“已生成”“可打开”“已渲染检查”“用户定稿”。
