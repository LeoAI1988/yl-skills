# 浏览器核验要点

这些是发布界面曾出现的行为，当前页面不同则按新证据处理。

- 上传前先监听文件选择器，再点击实际上传按钮；等待要捕获超时，避免未处理异常丢失页面状态。扩展若禁止本地文件访问，解释所需设置并等用户操作；已开启后不重复要求。
- “选择封面”“重新上传”等文字可能只是容器内说明。无效果时检查当前 DOM 或截图，点击实际控件，不连续盲点。自定义封面上传后看预览再点完成；缺另一比例的封面按用户授权处理。
- 标签逐个输入 `#标签` 后用空格确认，并读取话题节点数量、名称。粘贴整串文本可能仅最后一个被识别。
- 单选框、弹窗保存有异步延迟。动作后读状态；不要在旧弹窗未消失时点击底下设置。索引可能变动，语义控件通常更可靠。
- 建议顺序：视频和标题 → 封面 → 标签 → 合集 → 声明/章节 → 公开范围 → 保存权限 → 定时。最后回读全部字段，尤其合集可能导致保存权限重置。
- 平台“作品检测失败”可能只是预检测繁忙，不等于上传或发表失败。按明确提示处理，最终结果由提交后的作品列表确认。
- 定时提交后核对作品管理中的时间与审核状态，保存包含周围页面信息的截图。恢复会话先读列表，防止重复提交。
- 实际播放器下载失败时，可用当前播放器截图与本地对应片段核对；不要用封面代替正文。下载失败不代表平台作品不存在。
