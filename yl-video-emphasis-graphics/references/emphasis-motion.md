# 重点分析标注与参考动效

使用参考样式或生成透明图解时读取。按对应语段制作可解释观点、步骤、对比和关系的动态图层。具体参考媒体、样片文案和测量证据保存在项目或个人层。

## 读取参考和测量

1. 核验全部参考文件的哈希、尺寸、实际 PTS 与有效画面区域。屏幕录制先确定作品画面，排除播放器、系统通知、状态栏及循环重播区段。
2. 全长分段查看，登记每组重点的语义、出现顺序、保持时间和退场方式。动作边界按实际帧补采，测量透明度、位置、尺寸、遮罩、线条生长和元素间延迟。粗采样时间须标明精度，不能写成原工程精确关键帧。
3. 分别记录字体可见字高、字重、颜色、行距、左对齐基准、编号比例、辅助字与主结论比例。原字体身份无法确定时，使用实际加载的近似字体并保留差异记录。
4. 对齐动作时，标出前一项还留在哪、下一项随哪个词第一次可见。例如有几项汇聚时先展开节点，连线到达后才揭示结论。横屏录屏按有效作品画面换算文字和图形的大小。缺少相同机位、光线和曝光的无遮罩帧时，源遮罩透明度只能做视觉近似。
5. 将参考确认值写入外置样式配置并由生成器读取。同一套标注维持统一排版，结合本片人物运动和画面方向选择位置。用户圈定位置优先。参考含半透明暗底时，一并测量覆盖范围、中心透明度和边缘羽化，文字与底层分别检查。

## 语义动效类型

| 类型 | 组成与时间顺序 | 适用内容 |
| --- | --- | --- |
| 编号章节 | 大号数字先出现，右侧主句按口播逐行补齐，下一章节清退整组并更换编号 | 分条观点、资产分类、操作步骤 |
| 逐层结论 | 小引导语、主概念、关键结论逐层出现，结论字号最大，必要时已有元素平移让出空间 | 定义、因果、核心判断 |
| 关系流程 | 先显示起点，再画箭头或连接线，最后出现终点，后续步骤随原声追加 | 输入与输出、积累与结果、步骤串联 |
| 对比划除 | 显示原概念，随否定语义绘制删除线，再显示替代概念或结论 | 过程与结果、看客与创造者等明确对比 |
| 节点结构 | 实心点由聚合到分散，外圈依次扩展，再逐条生长连线 | 团队结构、个体闭环、协作网络 |
| 节点标签 | 标签随语义出现，可轻微缩放、淡入。全白字预设使用白字节点；其他配色按其预设使用胶囊 | 图中节点名称、短关键词 |
| 羽化暗底 | 半透明黑色遮罩覆盖整组分析区域，边缘柔和过渡，与该组同步渐显渐隐 | 用户指定参考暗底，或复杂背景下的重点分析 |

文字优先保持完整短语，行与行的出现时间跟随原声。章节标题可在同一段中持续保持，辅助分析随论述替换。文字、编号和图形都只表达本段真实内容。关系箭头、删除线与节点结构须有语义依据。

## 从参考动作选图形

逐组记录说到哪个词时画面开始动、动的是哪个对象、什么留在原位、动作结束后能读出哪层关系。对一段动作顺序取初态、中间态和完成态。屏幕录制先裁出作品的有效画幅，再量节点中心、位移、箭头头部和字块边缘。选两三种与本片论证对应的观察去做小样，其他形式只在内容需要时使用。

| 要说明的变化 | 分拍安排 | 看完成帧时核对 |
| --- | --- | --- |
| 条件导致后果 | 先给前提，沿阅读方向画出长杆，箭头到达后再显示结果 | 源和结果之间有独立通道，箭尖指向结果文字的边缘或节点 |
| 强弱、次序或否定 | 标尺保持位置，游标随语义移动。否定时沿旧判断的字面画删除线，再在空位揭示判断 | 观众能认出比较对象。口播没有给出数值时，刻度保持无数值 |
| 多项依赖一个对象 | 各项先分开占位，再分别画支线向同一端汇聚 | 汇聚端的底色挡住穿字的线。清退时保持因果次序 |
| 聚合体变成独立节点 | 紧聚后短暂停留，各点拉开；套圈稍微错开，再画第一组边和余下的边 | 中间状态能分辨聚散、边界、连接。需要解释的独立关系有原文支撑 |
| 替换工具或移交工作 | 固定系统或接收端的位置，先退旧连接与旧对象，再把新对象接到同一处。可以用沿线光点表示恢复运行 | 连续看替换前、中、后三拍，能指出谁换了、谁一直在。长标签可分别放在线的上下方 |
| 抽象概念成为结论 | 已有两端移动让出空间，在说出概念时放大中心结论，外围标签降为次级 | 放大过程中仍能追踪前后两个概念的位置 |

先预留最大文字边界，再定箭线起终点。行间只剩符号大小时，把节点上下或左右拉开，换一条独立轨道，或让次级标签换行。图形要解释语义才使用箭头；并列、成组、删除、替换各自有能表达变化的动作。多段连续复用同一图形时检查发生变化的究竟是哪条关系。

## 可测量的动作起点

以下是逐帧观察得出的近似起点，采用本轮实际参考测量值时覆盖。30fps 下先量化为整数帧。

- 文字和编号入场约 0.2～0.3 秒，透明度由 0 到 1，向上移动约 0.3～0.5 个可见字高，减速至静止。每个短语独立开始，段内已出现文字继续保持。
- 整组退场约 0.1～0.2 秒，渐隐或在段落切换时清退，保留语义切换所需的短空隙。
- 胶囊标签约 0.2～0.3 秒由 0.8 倍到 1 倍并渐显。
- 节点聚合到展开约 0.4～0.6 秒。外圈扩展约 0.2～0.3 秒，节点间错开约 0.1 秒。连接线按方向在约 0.3～0.5 秒内生长。
- 图解文字与线条读取图解预设。全白字预设中的组标题、编号、关键词、结论和节点标签均使用纯白字。独立视频标题读取标题配色。口播字幕按重点图解入口统一使用贴字黑底和常规白字。参考要求半透明黑底时，在图解下方独立合成羽化遮罩，覆盖整组内容。圆形遮罩的中心不透明度使用 `backdrop.circleAlpha`。抽查亮背景、人物进入羽化边缘及字幕换句时的实帧。中心黑底不透明度为 α 时，原背景在中心的比例约为 1 − α，羽化边缘逐渐露出更多实景。若白字在浅背景上读不清，先换侧、给字加轻阴影或调整组内布局。局部透明轨需为高斯羽化预留足够边距，在素材上核验轨道边界连续。

全片密度与语义锚点遵循[重点图解入口](../SKILL.md)。同一图组可随讲解、动作或状态变化逐项揭示关系。

## 生成与接入

使用 `scripts/render-emphasis-overlays.py` 生成透明状态图与 ffconcat。它沿用现有导出器的 `[startFrame,endFrame)` 状态格式，可和字幕/标题透明层先合成，再由已匹配的无字底片一次导出。

```text
python scripts/render-emphasis-overlays.py --spec ./work/emphasis.json --base-manifest ./work/layers.json --out-dir ./work/emphasis-render
```

`--out-dir` 使用新目录。规格字段如下。

- 顶层使用 `width`、`height`、`fps`、`durationInFrames`、`fonts`、`components`。`fonts` 将字体角色映射到安装者的字体文件。
- 个人预设指定统一图解字色时，将 `textColor` 写入顶层 `diagramTextColor`。渲染器将其用于全部图解文字，包括模板自带配色的编号、关键词和胶囊。纯白字胶囊配深底。独立视频标题沿用基础标题层。
- 每个组件包含 `kind`、`startFrame`、`endFrame` 及位置。支持 `text`、`pill`、`line`、`circle`、`backdrop`、`caption`。组件按清单顺序叠加，背景组件放在对应文字和图形之前。
- 每条已有字幕按行生成 `kind: "caption"`，提供 `text,font,size,x,y`、起止帧和 `align: "center"`。字体映射到常规字重，x 取画面中线，y 取该行顶边。字幕组件在图解之后合成，自带贴字黑色直角底条和纯白字。生成圆形图解底板时指定 `shape: "circle"`、相等的宽高。规格顶层的 `backdrop` 接收个人预设的羽化底配置。旧规格中组件显式指定的 `alpha` 仍优先生效，局部重做圆底时应一并更新该处覆盖值。
- `text/pill` 包含 `text`、`font`、`size`、`x`、`y`，可设 `color`、`align`、`stroke`、`shadow`。坐标是文字图块左上角，图块含12像素留边。
- `line` 包含 `x,y,x2,y2,width`，`draw` 控制 0～1 的线段长度。`arrow: true` 绘制跟随线端移动的实心箭头。`headLength` 和 `headWidth` 是最终箭头的长与宽，单位为图层像素。省略时随笔画和画布高度取值。向左、向上和斜向沿端点方向计算，收回时亦跟随线端。在起笔阶段按已展长度收小箭头，避免箭尾反穿起点。
- `circle` 包含 `x,y,radius,width,filled`。位置和半径可用于聚散与外圈展开。
- `backdrop` 包含 `x,y,width,height,feather,alpha`。`alpha` 为黑色遮罩中心不透明度，`feather` 为像素羽化半径，`opacity` 关键帧控制整组进退场。允许遮罩跨出画布，使贴边区域连续渐暗。
- `keyframes` 按 `frame` 递增，各相邻关键帧应包含相同的变化属性。可改变 `x,y,opacity,scale,radius,draw`，插值默认为减速三次曲线，`ease=linear` 为线性。保持段两端填同值。
- 项目清单另登记每组原文依据、语义锚点、最终起止帧、类型、前一重点间隔与必要偏离原因。所有坐标均属于精剪及倍速之后的成片。

动态图层每个变化帧输出一个状态，静止区间复用图像。字体、规格、生成器、基础文字层和输出图像依赖必须进入缓存身份。完整帧覆盖与技术生成成功之后，继续检查实际导出画面。

## 对照与验收

按参考事件对齐，检查入场前、25%、50%、75%、稳定、退场及下一组出现时的帧。核对主次比例、字形、每行开始时间、位移/透明度、编号清退、线条生长和节点位置。先完成一个文字组及一个实际采用的关系图组，再批量导出。

把**整帧**缩小到目标终端的实际播放宽度，先按原速看动作，再抽帧核对。可设 `motionReview`，如 `{"displayWidth":3840,"previewWidth":390,"minShaft":18,"minStroke":1.8,"minHead":4.5}`。单位均为像素，后三项是预览中的**净箭杆长度**、杆粗、头宽起点，可随设备调整。预览尺寸按整帧计算，即使当前透明层只占画面一角。`displayWidth` 填以图层坐标单位表示的整幅宽度；例如半分辨率渲染的透明层叠到两倍输出时填半分辨率的整幅宽度。在几何稳定状态排除头部长后量箭杆，原速检查中间帧能否追踪方向。独立运行 `--check-motion` 可诊断已有规格；新规格有此配置时，渲染前也会核验。结果还需从实片看箭尖是否被文字吞掉、对比度和落点是否清晰。纯节点图按聚散、圈与连接的视差实测。

对最终视频逐组检查完整显示区间的人物遮挡、基础字幕冲突、句意对应及阅读时间，保存真实导出帧和参数差异。原工程、字体或遮罩证据不足的部分如实记录为近似匹配。“完全一致”仅在相应属性具备实际对照证据时使用。

采用调用方确定的底片与时间轴。有口播时复用已校对的文稿和时轴，将原字幕层替换为贴字黑底白字。已烧录字幕时先查同版无字底片；现有字幕已符合样式时直接保留。只有画面或无对白的素材可直接加图解。

图上写出具体对象、数额或结果，清除“口播举例”等制作提示。用户指定全白字时，逐层检查标题、副行、数字与图解，封面的强调色只在封面层生效。羽化遮罩接近局部图层边缘时留足衰减距离，再在实际底片的亮部检查有无硬边。
