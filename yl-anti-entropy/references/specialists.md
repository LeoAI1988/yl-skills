# 专项对照

本Skill汇总可单独启动的电脑排查与通用方法；各专项自己的归档/清理段落继续保留，不能因为有总入口就删除它们。

| 专项 | 保留/完成依据 | 本地收尾 |
|---|---|---|
| [视频归档](../../yl-video-archive/SKILL.md) | 唯一初始母带、确认成品、说明、已有逐字稿/封面 | 确认结果后清除对应历轮工程；分类入口只保留映射 |
| [口播](../../yl-remotion-talking-head-editor/SKILL.md)、[访谈](../../yl-chatcut-landscape-interview-editor/SKILL.md) | 用户批准结果、真实原声与原片、必要说明 | 当前确认成果成为唯一版本；不另备份旧输出/付费中间件，清场不冒充听审 |
| [课程剪辑](../../yl-course-video-editor/SKILL.md)、[切片](../../yl-remotion-video-slicer/SKILL.md)、[混剪](../../yl-viral-video-remixer/SKILL.md) | 课程/原素材正式位置、确认成品及必要源到成果说明 | 不复制母带；结束后清构建/渲染缓存、代理、分段及一次性工程 |
| [视频号发布](../../yl-channels-publisher/SKILL.md)、[抖音](../../yl-douyin-publisher/SKILL.md)、[小红书准备](../../yl-xiaohongshu-publisher/SKILL.md) | 正式成片/封面、平台实证状态、后续依赖、**发布清单记录**（工作目录 `…/output/发布清单_*.json/.md` 及 `publish-history` 批次/逐条状态，是「哪些已发过/已排期」的唯一查重依据，**任何时候都不清**） | 不备份日常发布成果；真实完成项清暂存，未提交/失败/未知项保留需要的文件；**发布清单记录必留，只清上传暂存副本（`upload_tmp`/`_publish_stage`/`publish_*` 等临时目录）**；不扩大平台授权 |
| [PPT](../../yl-ppt/SKILL.md)、[长视频总结](../../yl-course-summary/SKILL.md) | 最终PPTX/PDF/MD及原稿、正式资产 | 不备份日常候选/旧稿；用户定稿后清制作脚本、构建、渲染和截图，正式可编辑成果保留 |
| [封面](../../yl-short-video-covers/SKILL.md) | 最终封面、原始照片和明确交付 | 不再复制到多个业务目录；确认后清候选、试排与临时渲染 |

系统迁移/安装冲突的必要恢复机制与用户明确要求的备份不是普通日常产出；不能因此取消安装器的真实冲突保护，也不能把这种例外推广成每次发布都备份。原文与知识库正式来源职责保持，清理不启动云端写入。
