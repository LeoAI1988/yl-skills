# 查找与调用

读取个人配置、库导航和当前问题。按用户词语、别名、领域、概念与显式关系检索，再回读原文。可用 `python -B ../yl-knowledge/scripts/knowledge.py --profile PROFILE search --query "关键词 别名"`；已有库可调用其已核实搜索程序。

结果返回对象 ID/路径、来源、相关片段、上下文、确认和时点边界；与问题不匹配的热门词不要硬用。默认不检索凭据、备份或私人事实；用户明确查本人私人档案时可在授权范围单独读取。不能因此跳过已经归入普通体系的安全思想。

先原文和完整论述，再看摘要。语义相似是一种线索，不等于同义、事实已验证或本人确认。当前通用脚本是全文词语检索，不称为向量检索；未来可选适配器增强，但原文回读不省略。

写作只取必要资产，不堆概念。查找请求本身不授权改库、同步云端、发布或创建个人分身。
