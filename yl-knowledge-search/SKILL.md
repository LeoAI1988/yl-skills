# 查找与调用

读取个人配置、库导航和当前问题，再读 [统一检索约定](references/retrieval.md)。按个人 retrieval.python 运行本Skill的 `scripts/retrieval.py --profile PROFILE search --query "问题"`。默认文字与本地语义混合检索；记得特色原话时可用 `--mode text`。统一搜索完整文字主源，未形成原子的段落也在范围内，不能只查原子和导航。

结果返回对象 ID/路径、来源、相关片段、上下文、确认和时点边界；与问题不匹配的热门词不要硬用。默认不检索凭据、备份或私人事实；用户明确查本人私人档案时可在授权范围单独读取。不能因此跳过已经归入普通体系的安全思想。

先原文和完整论述，再看摘要。命中后展开完整父段，继续回读前后文；不将相邻卡片当上下文。语义相似不等于同义、事实已验证或本人确认。模型不可用/索引不完整时明确报告降级，不把仅文字检索称为混合检索。无结果须检查别名、原文和覆盖缺口，不能直接断言没有相关内容。

抽象、跨领域或隐喻问题不能只查一次。保留用户原问，再拟定至多3个等义问法或关键概念，使用 `--also-query "等义问法"` 合并召回；不新增立场，不丢掉否定和条件。由当前Agent根据原段判断相关与不相关、原话与加工说明，不把向量排名当最终裁决。没有直接证据时明确说明“找到相关候选，但未找到能回答这个问题的原文”。这一步不调用额外收费模型。

写作只取必要资产，不堆概念。查找请求本身不授权改库、同步云端、发布或创建个人分身。
