# 来源、导出与续接

## 完整文本优先，避免长时间没有结果

1. 先找已有字幕、逐字稿和源文件记录，核对其对应的视频/章节与选定版本。不要重复转写已取得完整文本的视频。
2. 只补缺失视频或章节。用当前宿主公开、已授权的转写能力；本地工具、远端服务和导出方式都以当前文档与实际环境为准，不依赖作者机器的脚本或账号。
3. 长批次先验证一小段是否识别正常、耗时是否可接受，再扩展。转写按视频或章节分段落盘，有进度与续接点；一次失败不要丢掉整批已取得文本。
4. 完整视频总结需要覆盖选定范围的完整转录。服务若有官方完整转录文件/导出入口，优先取文件；只能分页时遵循实际返回的截断标志和下一游标，每段保存，检查结束位置。有限预览、检索命中或默认第一页不能冒充全文。
5. Windows 媒体工具路径含盘符/反斜杠时，使用工具文档支持的路径和临时目录参数；先解决参数转义，不用相同错误反复批量重试。原始材料保留，不因临时目录失败覆盖用户文件。

任务只授权本地交付时，不因此推断允许将私人材料上传到外部服务。使用既有授权与用户选定工具，不额外重建剪辑项目；没有工具就先交付已有来源能完成的章节，并逐项说明缺口。

## 可重复的 PDF 导出

优先定位宿主提供的 Python 与 PDF 库。附带脚本要求 Python 3.10+、`reportlab`、`pypdf` 和可嵌入的中文 TrueType 字体；字体由当前安装者提供，不随 Skill 分发。字体或库缺失时选可用的宿主工具，或按授权准备依赖。

在核心之外准备总结清单：

```json
{
  "title": "长视频总结",
  "author": "",
  "date": "",
  "lessons": [
    {"id": "1-1", "title": "第一小节", "markdown": "正文/1-1.md"},
    {"id": "1-2", "title": "第二小节", "markdown": "正文/1-2.md"}
  ]
}
```

`markdown` 相对于清单位置解析，也可由安装者明确传入绝对路径。`lessons` 字段为兼容已有导出接口保留，可代表视频、话题章节或课时。清单顺序就是阅读顺序，不能靠字符串排序把 1-10 放到 1-2 前面。清单是已确定的总结/教程正文清单，不是让脚本从视频自动理解内容。

```text
python -B scripts/export_handbook.py --manifest /work/总结清单.json --output-dir /delivery/视频总结 --work-dir /work/排版 --font /fonts/regular.ttf --bold-font /fonts/bold.ttf --bundle
```

每个清单条目生成 Markdown、同名 PDF、阅读目录与合集。`--no-combined` 关闭合集；`--overwrite` 只在当前任务已经授权重建该输出时使用。脚本在写出前检查全部目标是否已有文件，默认拒绝覆盖；输入 Markdown 与同位置的已有正文不重复写入。输出目录和工作目录不能在 Skill 核心之内。

已有课时目录的课程手册按 [课程手册归档](course-filing.md) 交付：本工具输出到临时目录并传 `--no-combined`，不传 `--bundle`；再将各节 MD/PDF 放回对应课时，仅汇总 PDF 和生成 PDF-only ZIP。下面的通用混合格式不代表课程正式入口应包含 MD 或导航稿。

支持普通段落、标题、加粗、行内代码、链接、列表、引用和简单表格；只在行首识别 Markdown 标记，保留词内下划线。复杂图片、合并单元格、Mermaid 和数学排版应选合适的宿主工具，不能默默丢弃内容。脚本不联网，不上传材料，不自行安装字体或依赖。

可选署名块：`<div align="right">` 独占一行，内部每个文本行用 `<p>文字</p>`，二维码用 `<img src="外置原图绝对路径" width="100" alt="二维码" />`，最后 `</div>` 独占一行。只解析这组有限标记，PDF 以右侧署名表格排版；原图嵌入 PDF，无需读者访问本机路径。Markdown 则保留原图引用，跨机器分享 Markdown 时另行约定资产随行方式。署名块的文字同样参与 PDF 完整性校验。

脚本检查每条正文与 PDF 文字的覆盖，并验证合集书签和页数。`export-report.json` 留在工作目录。渲染截图和视觉判断另做：有 PyMuPDF/Poppler 等可用工具时渲染全页，检查中文、表格、页码和步骤分组；缺少渲染只报告文件级检查，不宣称视觉通过。

## 结束与复用

- 普通长视频按约定交付 Markdown、PDF、目录和需要的合集/ZIP；已有课时目录的系列课程使用上面的分散归档与 PDF 汇总规则。ZIP 不含转写、凭据、缓存和内部报告。
- 打开读者会实际查看的文件，核对目录链接与书签目的页。
- 清理只限自己生成的可再生中间文件，遵循当前工作区的路径与权限规则；清理失败不阻断已验证的交付，也不改写成清理完成。
- 新视频/章节、修改或续接沿用已有小节编号、用户手改与清单。只补新增和受影响的章节，更新合集及目录后再核对。
