# 本地资料接入

读同级 `yl-knowledge/references/contract.md`、个人配置及 `yl-knowledge-distill/references/objects.md`。只处理用户指定来源，不全盘扫描。

先清点每份文件、每张照片、每段音视频；原件保持不变。使用已有可用解析/转写工具。图片按实际版面连读，跨页句子不能按左右页截断；录音须保留时间位置。另一份OCR/ASR结果一致不等于已对照原件。

发现阶段独立于已入库扫描：运行 `python -B scripts/discover_local.py --profile PROFILE --output REPORT.json`，枚举个人配置 `local_discovery.roots`（默认 `source_roots`）内的文件，和 `local_discovery.registries` 的当前路径/哈希登记比对。没有边车、未提升、未产生原子的材料也必须出现；不能只检查已登记对象后宣称没有新增。登记格式为 `sources` 数组，每项含 `path`、`sha256`，可附 `source_id`、`processing_status`。已有库用适配器输出同一格式，不能为迁就发现器重建知识库。默认不跟随目录链接；缺失根目录与读取失败单独报错。历史未登记项保留队列，不能用日期过滤假装完成。

发现只产生候选，不能自动认定作者、完成阅读或蒸馏。逐项区分原始课程转写、本人新稿、源话重编稿、手册/大纲派生稿、外部引用与工程说明；同一内容的原文和派生版本保留关系。复用原文的派生稿须检查新增部分，未读项如实登记。已登记哈希不变也可能尚待语义处理，继续检查处理收据。

分别保存忠实转写、最小清洗正文和不确定片段。只修有依据的错误；不以通顺为由概括、改立场、删除比喻或有效重复。Agent全局印象、主题总结不混进原文。能直接看清/听清的自行纠正；只把真正残留疑点连同局部原件集中交给用户。

先按来源ID和内容比对旧稿。同源且高度相似仍须检查未重合部分，补充新表达、条件或观点；不因多数句子相同就宣布无新增价值。完全相同的正文只引用既有实体，保留来源别名。

文字源可用 `knowledge.py --profile PROFILE register --file FILE --id SOURCE_ID --origin local --ownership unknown` 登记。进入 `yl-knowledge-ingest`，再由总入口完成提炼、表达、关系、全文索引及验收。索引更新不是内容复核的替代品。

本人整理权限与公开使用权限分开；混合材料逐段处理，不按某个固定目录名整条跳过。外部项目原位映射，敏感事实和凭据不混入普通写作索引。来源位置、格式适配和工具选择由个人配置指定。

迁移或批量修订前保留备份和明确文件清单；同步来源登记、原子引用、阅读链接与检索索引，校验文件数、内容及可回源性。不覆盖同名源，不把缺失原件猜成已被用户删除，不自动清除备份。
