# 来源与范围

依据维护者已使用并反馈认可的课程录屏剪辑流程及本地课程剪辑方法重新整理，实现可移植的候选分析、统一时间轴与 FFmpeg 导出工具。方法保持表达、时间/教学动作、呈现/声音三个维度；修正了把 ASR 无词当作无教学价值及用整段音量处理代替声源处理的问题。

本成员文档与新编标准库脚本采用 MIT。没有复制第三方受限编辑方法、宿主内置 Skill 原文或课程媒体。FFmpeg、转写库、模型、字体与其他外部依赖由安装者提供并遵守实际许可。

真实试剪、用户反馈、工具安装位置、全局热词和验证记录留在核心外。包内技术检查不证明所有未来课程的剪留、字幕或双声分离质量；源内音频有损混合时只能根据实际分离证据说明保护范围。
