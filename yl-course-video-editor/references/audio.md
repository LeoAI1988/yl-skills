# 演示播放与讲师音量

把“讲师讲话”“示例播放”“两者重叠”作为不同声源状态。每次播放/拖动/暂停/循环都会改变参考偏移，不能从播放器打开到关闭套一个时间增益。

## 诊断与处理

1. 探测全部音轨与左右声道。分别测代表性的讲师段、播放段、每次起止及重叠段：短时响度、RMS 与 true peak/峰值。RMS 用于比较，不等同 LUFS；不要把峰值或整片综合响度当作人声听感。
2. 有独立系统声/话筒轨：只调整系统声；讲师同一段增益保持 1，缓变增益避免爆音。示例单独播放时接近授课舒适音量，讲师点评时按可懂度进一步降低示例。
3. 只有混合轨：先查立体声结构、工程文件和画面可见的原样片路径，再在已授权素材目录找原样片。不要先把找素材的工作抛给用户。旁白可能与样片是同一个人，普通按说话人分离不一定适用。
4. 原样片匹配时，用多个窗口核验波形/频谱相关、局部速度、声道、重采样和偏移；播放器暂停/寻址后的每段独立对齐。可估计录制链路的滤波/回声，将匹配的播放贡献消减后按较低增益加回。拟合用播放声主导的窗口，验证用未参与拟合的窗口及真实重叠段，防止把讲师当噪声一起消掉。相关高不证明残差全是讲师。
5. 分离需检查讲师是否清楚、是否少字、变薄或出现音乐噪声，边界是否突变，样片是否还有超大残留。若分离不可靠，不可声称“讲师完全不变”；保留分离候选、可验证的独播处理与具体待审位置。明确要求保护人声时不能用整段降增益、全片归一化/限幅冒充独立处理。

压低多少从当前讲师参考测量和听感决定，不写死 -6/-12 dB。处理前后保留测试窗口、参数、修正区间和结果。不能只检查成片全局峰值。

同一录屏存在一遍无讲师叠声的播放，且讲师左右声道近似相同时，可用 `scripts/balance_playback.py`。脚本至少检测两个讲师独讲窗口，从左右差拟合先前播放参考，不用讲师所在的中置信号拟合；以左右差门控处理暂停，避免减出反相样片。讲师明显立体声、参考有讲师或参考不匹配时不适用，合成测试不能替代真实听审。

```text
python -B scripts/balance_playback.py --audio /work/original-stereo.wav --plan /work/audio-plan.json --output /work/balanced-v2.wav --report /work/audio-report-v2.json
```

计划含 `reference_spans_reviewed: true`、`lecturer_check_windows: [[开始,结束],...]` 和 `spans`。每段含 `type`（`playback_only` 或 `reference_overlap`）、`start/end/gain_db/reason`；重叠段另含 `reference_delta`（当前源时间减先前参考源时间）、`fit: [开始,结束]`、`reference_playback_only_confirmed: true`。秒单位，源时间升序，互不重叠，参考须为已审核的纯播放。此工具需要 NumPy/SciPy，保留实际编码残留的检查边界。

## 只改已认可成片的音量

复制视频轨保留画面、字幕、剪点和速度；音轨需要重新编码。可从原片处理音频后按冻结的最终映射重组并**只应用既有倍速一次**，或直接在成片时间轴处理，不再倍速。已存在静音操作画面需沿用经过核定的静音清单。

复核播放开始/结束前后、暂停点评、再次播放与双声重叠。比较讲师独讲区修前/修后的样本误差与响度；若 AAC 重编码产生误差，报告实际容差，不谎称音频字节相同。视频轨数据、帧数和时长应保持一致。真正的保护人声证据来自独立轨或受验证的分离及听审，不能由源片映射校验替代。

只改少量播放区间时，可在冻结的成片时间轴插入修正音频，区间之外沿用原成片解码音频。AAC priming、concat 和 mux 的偏移要用实际音频相关/时戳检查，不能直接把新解码 WAV 当作与旧成片零偏移。保留每次播放最后的尾音，边界以原声检查，逐窗口查残留突响；参考消减的暂停门控不能替代最终尾部检查。
