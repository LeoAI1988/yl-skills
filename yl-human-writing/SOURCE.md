## 适配内容

- 保留完整主流程、论坛长文、现实、虚构、文体与七遍修订参考，保留完整检查能力；原命令转接公共候选检查器，聊天便携版附带完整公共约束。
- 去掉个人身份与固定 CTA，把表达校准改为安装者自己的材料。
- 明确用户已确认原话和文体高于默认检查提醒，不因脚本命中破坏原始表达。
- 通用引擎独立列示，不把它称为“卡兹克第二版”。
- 所有示范原版已经明确标为虚构，保留该说明；不携带私人素材。

## 运行与数据

Python 3.10 或更新版本，只使用 Python 标准库。无需访问维护者的机器、账号或其他私人 Skill。安装者提供自己的原始素材。所有任务输入、CTA、临时文件、日志和派生成果应保存在安装者自己的项目目录；本目录只放规则、可分发参考和脚本。连接外部笔记或图片服务时，由安装者自行配置工具与凭证，并按其实际授权范围调用。没有连接器仍可用本地材料完成写作。

运行路径均相对当前 Skill 目录，建议从 Skill 根目录执行，输入和输出可指向安装者项目中的绝对路径。逐文件复核与验证见 [AUDIT.md](AUDIT.md)。
