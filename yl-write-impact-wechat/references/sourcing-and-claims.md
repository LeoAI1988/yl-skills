# 素材与主张合同

## 1. 证据优先级

Get笔记录音材料按以下顺序读取：

1. `data.note.audio.original`
2. 同一笔记正文和作者明确补充
3. 作者历史原创文章
4. AI 摘要，仅用于检索定位，不作为原话证据

保留笔记 ID、标题、知识库、作者归属和原始片段。笔记 ID 必须来自 API，始终按字符串处理。

## 2. 素材归属

| 来源 | 可用于 |
|---|---|
| 作者录音逐字稿 | 原话、亲历、感受、判断 |
| 作者历史文章 | 文风、已公开表达、可复用观点 |
| 第三方文章或录音 | 带归属的事实或引用，不能改成作者亲历 |
| 官方资料 | 日期、功能、政策、公司动作核对 |
| 用户当轮明确要求 | 文章合同和营销口径，不能静默删除 |

无法判断是否作者原创时，先查来源；仍无法判断，不改写成第一人称经历。

## 3. 原话金句卡

写正文前建立：

```text
素材ID：
原始表述：
作者归属：
类型：事实 / 亲历 / 感受 / 判断 / 营销口径 / 第三方信息
时间范围：
可保留原话：
必要纠错：
禁止扩写：
拟放章节：
```

先用这些卡片搭结构。不要先写一篇标准文章，再往里粘几句原话。

## 4. 五类主张

1. **作者亲历**：限定在作者真实使用和经历范围。
2. **官方或公开事实**：保留主体、时间、数字和适用范围。
3. **作者分析判断**：是文章的核心价值，可果断表达，但不要伪装成官方结论。
4. **用户批准的营销口径**：视为必须处理的内容合同，不得因模型偏好“更严谨”而悄悄删掉。
5. **第三方事实或观点**：保留来源归属，不能偷换为作者原创。

对第4类，执行顺序是：

- 尽量找到支撑材料。
- 找不到充分支撑时，保留其观点位置和冲击功能，改成可承担的判断表达。
- 在阶段B事实说明中记录原口径、证据状态和最终写法。
- 只有出现实质法律、隐私、人身声誉或重大商业误导风险时才暂停，并把风险和可选写法交给用户决定。

“未经核实”本身不是静默删除用户核心观点的授权。

## 5. 事实说明模板

阶段A内部维护主张台账，阶段B再交付事实说明：

| 编号 | 正文主张 | 类别 | 原始材料 | 外部来源 | 状态 | 最终口径 |
|---|---|---|---|---|---|---|
| C01 | 具体产品更新 | 公开事实 | 笔记ID | 官方链接 | 已核 | 明确陈述 |
| C02 | 作者近期使用变化 | 作者亲历 | 逐字稿 | 无需 | 可用 | 第一人称 |
| C03 | 行业即将洗牌 | 作者判断 | 逐字稿 | 多条信号 | 判断 | 果断表达 |
| C04 | 用户指定营销判断 | 营销口径 | 当轮要求 | 待补 | 待说明 | 保留功能 |

## 6. 停止条件

遇到以下情况不得自行编造或强行定稿：

- 找不到被指定的原始逐字稿，只有摘要。
- 素材作者归属无法判断且会影响第一人称真实性。
- 需要披露私人身份、敏感个人信息或未授权录音内容。
- 主张可能构成具体诽谤、违法指控或重大商业误导。
- 用户要求与可确认官方材料正面冲突，且不同写法会实质改变文章。

停止时给出：原口径、风险、两种可用写法和推荐选择。不要直接删掉整段。
