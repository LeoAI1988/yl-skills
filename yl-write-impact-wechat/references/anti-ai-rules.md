# 全部已收录的去 AI 味规则

与 [执行约束](writing-foundation.md) 一起使用。下列规则按来源去重归并，保留相互补充和防误伤条件；提取范围与来源指纹见 [提取账](anti-ai-extraction.md)。没有列出的未来上游更新不视为已经吸收。

## Human Writing：材料、句法、节奏与复核

| 编号 | 识别与处理 | 保留边界 |
| --- | --- | --- |
| H-01 材料先行 | 写前列具体来源，现实长稿靠核实的经历、过程、数字、动作和原话成立；不把三条观点分别扩成意义/未来/风险十几段。材料不够先研究、补问真正缺项或缩短。 | 纯虚构可创造，但场景需有动作、选择、关系/信息变化与后果；不伪造现实出处。源版 1200 字/5 件材料/600 字短答是经验提示，不是本包统一门槛。 |
| H-02 说话位置 | 具体的人基于自己知道的事说话。保留用户已有的立场、措辞、推理和正常不确定性；不冒充产品实测、作者亲历或历史人物心理。 | 不靠粗口、错字、网络梗、咖啡香、烟味、天气布景或故作随便“增人味”。 |
| H-03 顺着问题推进 | 读者到此会问什么，下一段就补该关系；每段增加事实、解释、例子、区别、动作或后果。删掉不增加信息和表达功能的同义重述。背景只在影响选择、风险或理解时引入。 | 功能性复沓、回扣、真实强调和必要术语重复保留，不强行换同义词。 |
| H-04 判断正面落下 | 直接讲成立的判断和依据；修掉先虚构读者误解再反驳的翻案机关。 | 真实误判的修正、证据支持的前后差异、正常“不只……还……”不自动算问题。 |
| H-05 句子先有主干 | 主语、动作、对象尽早可辨。修多层定语和连环“的”，把“进行了优化/实现了提升”等空名词化还原为具体动作结果；清楚指代人物，背景不挤掉主干。 | 长句能顺着理解就保留，不为改变句长编造动作或数字。技术动词的准确含义可保留。 |
| H-06 自然节奏 | 长短随信息变化；合并切碎推理的短段，拆解造成负担的长句。修整篇均长、整齐三连、每段固定短句结尾和高频相同开头。 | 排比每项增加程度/对象/后果时可留；不随机拉长缩短以凑统计指标，诗歌、对白、短口播按文体。 |
| H-07 情绪与细节 | 已有动作、原话和选择能传情就停，不跟一句替读者命名情绪。不把空抽象词拟人，不堆抒情词和无关领域比喻。 | 用户原有比喻、宏大判断、锋芒和真实情绪有作用就保留，不能一律改成小情小景。 |
| H-08 清掉包装词 | 以下三组词与路标逐处核对；新加的空黑话、假洞察和无功能强调直接改成普通话或删除。 | 专业术语本义、真实引语、对该词本身的讨论可保留。命中不是作者身份或质量判决。 |
| H-09 标点与排版 | 检查用冒号宣布洞见、破折号追加玄虚解释、引号批量包装金句、Emoji 堆叠、装饰性小标题。 | 引出真实原话、技术字段、时间、URL、代码、文学对话和正常格式可保留。没有所有文章统一的小标题或标点配额。 |
| H-10 连词和翻译腔 | 修每段固定“然而/此外/因此/与此同时”，去空“作为/关于/基于/进行”外壳。优先修前提和信息顺序，不能只补一个“所以”假装逻辑成立。 | 真正表达因果、转折、条件的连词保留，不机械删一半造成断裂。 |
| H-11 及时结束 | 文章完成实际问题就收住，删重复总结、空泛祝福、硬回扣、强行上升到时代/文明/所有人的尾巴。 | 原稿已有且论证支撑的时代判断与回扣保留；用户自己的固定结尾按提供版本接在自然结尾后。 |
| H-12 七遍复核 | 保留来源七遍：谁在说 → 怎样往前走 → 表演性中文 → 中文顺序/照应/停顿/古意 → 词句标点候选 → 现实或设定 → 结尾。最后冷读全文并对照原稿。 | 在内部完成，不给用户贴“AI 率”，不把检查报告写进文章，不为了检查新增假细节。 |

### 复核细节补充

- 做删段和压缩试验：若删去约三分之一，事实、判断、行动与阅读体验几乎不变，优先去掉空转；这不是强制删掉三分之一。
- 对照人物在哪里、做什么、遇到什么限制和后续结果；虚构还要核人物所知、时空、伤势物件与世界规则。混合稿不能彼此冒充。
- 顺着逗号句号查人物和对象的接续；指向清楚可省重复主语，两个人或多对象在场应把名字写回。留白只省读者可自行得到的部分，不撤关键事实和因果。
- 单双音节词、成语、典故和文言按说话者与场合选择，不全改正式长词，也不为古意压成单字。孤立典故、需要追着白话解释的装饰或语体突变应修。
- 幽默来自真实取舍与反差，笑点后继续讲事，不规定每几百字吐槽。论坛长帖不伪造更新、楼主回归或网友互动；没有亲历可走核实的常见流程，但须明确为一般情形，不能加伪造精确经历充材料。
- 抽象词问清谁做什么，钱、时间、责任落在哪里；能原样放进十篇稿子的句子优先核查。金句单独截图好看而放回正文没有作用时应删。
- 分别去掉最后两段试读；开头物件在结尾回归须带来理解变化，不能只回来打卡。冷读检查可信处、继续读的理由、像完成模板的段落、比材料大的句子以及真正结束的位置。

### 词与形状清单（完整收录，按语义应用）

- 来源硬停词：说白了、说穿了、先说结论。
- 来源硬黑话 27 项：赋能、抓手、商业闭环、价值闭环、能力沉淀、拉通、底层逻辑、顶层设计、认知跃迁、价值释放、能力建设、降本增效、内容矩阵、全链路、组合拳、打开想象空间、结构性机会、关键命题、深层逻辑、技术底座、公共底座、技术主权、单点风险、主脊柱、材料锚点、认知增量、迭代闭环。
- 辨语境词 14 项：沉淀、颗粒度、对齐、协同、链路、生态位、心智、范式、方法论、核心变量、打法、想象空间、闭环、不丢。
- 抒情词 12 项：安放、抵达、微光、褶皱、丰盈、滚烫、轻盈、赤裸、剥开、锋利、坚硬、柔软。原检查脚本只列前 9 项，本版依据 prose 参考补齐后三项；实际触觉、材质、温度等本义保留。
- 路标：更微妙的是、还有一层、只说对了一半、值得注意的是、需要指出的是、从某种意义上说。本义“楼上还有一层”不算洞察路标。
- 洞察包装：真正、本质上、更深层次、归根结底、换句话说、不可否认、核心是、关键在于、这意味着。要查它是否给出新增的、受证据约束的判断。
- 反转及变形：不是 A 而是 B、并非 A 而是 B、不在于 A 而在于 B、与其说 A 不如说 B、你以为 A 其实 B、看似/表面 A 实则 B、A 不重要重要的是 B、答案恰恰相反、回头才发现、真正……的是。检查的是虚设误解与反转密度，不是禁止真实认知变化。

### 机械候选覆盖与阈值

检查器沿用 Human Writing 的启发式：同构排比至少 3 项；至少 600 汉字时连词超过 7/千汉字；短引号高亮超过 `max(3, 汉字数//700)`；至少 12 个可测句时句长变异系数低于 0.42；洞察词超过 `max(2, 汉字数//900)`；长前置成分超过 `max(2, 汉字数//1200)`；至少 38 汉字且 4 个“的”的句子多于 `max(1, 汉字数//1500)`；至少 10 段时单句段占 75%；连续 4 个短单句段；同类段首至少 4 次；800 字符窗口内至少 3 个比喻领域。全词表、反转、名词化和标点另逐处提示。

这些数值未经过 AI 来源识别校准，且各自计数口径不同，不能作为交稿质量分或强制改稿配额。统计不了的语义问题仍要完整检查。代码/机器字段被屏蔽以减少误报；标题、小标题及引语文字仍需复核。以反例测试约束误删，而不是追求零关键词。

## DBS：22 种特征逐项保留

| 编号 | 候选特征 | 修正与防误伤 |
| --- | --- | --- |
| D-01 | 把所有可能反驳先堵死 | 只留当前命题成立所需边界；学术、法律等需要全面论证时保留，不牺牲严谨。 |
| D-02 | 一次倒出所有知识 | 用本篇问题筛选背景，每段有新增作用；综述按任务保留必要覆盖。 |
| D-03 | 句法和排比过于整齐 | 先看每项功能，删空并列，保留递进；不随机拆句。 |
| D-04 | 反复先让步再转折 | 删礼仪性承认和套话，保留实际反证、条件和犹豫。 |
| D-05 | 反复给概念举行命名仪式 | “我把它叫做……”反复出现两次以上才查成套包装；有用定义可留，不为命名制造理论。 |
| D-06 | 情绪曲线异常顺滑 | 恢复原材料真正的转折、停顿和未决处；不能编狼狈、冲突或缺陷。 |
| D-07 | 设一个愚蠢读者再打倒 | 只有把不存在的观点强加给读者并贬低才判稻草人；正常问答和真实异议保留。 |
| D-08 | 高密度“不是 X 是 Y” | 源版 800 字内 3 次及以上是密度提示；逐个核对是否真实区分，不把日常对照全删。 |
| D-09 | 从无真实迟疑 | 保留实际不知道、想错和未完成的判断；没有不确定性就不要人工造一个。 |
| D-10 | 用异常精确数字描述情绪 | 如心情停顿 1.7 秒、沉默 2.3 秒须有记录；真实测量可用，无依据撤回精度。 |
| D-11 | 脆弱面恰好服务全部论点 | 查经历来源和推理关系；不编“失败的我”人设，不强加不相关脆弱面。 |
| D-12 | 给结论穿上协议外套 | 没有可执行条件就别叫协议、法则、模型；真正技术协议或用户真实方法保留。 |
| D-13 | 每段固定用金句收尾 | 只在承担判断或节奏功能时落句；短视频允许较高密度，仍不得重复喊口号。 |
| D-14 | 句子节拍高度统一 | 检查信息是否被切碎或机械排队，按论证改；短社交文本不凭句长统计判定。 |
| D-15 | 生理反应代替论证 | “后背发凉/头皮发麻”不能证明结论，补实际依据；真实身体记录本身可以是事实。 |
| D-16 | 钩子＋痛点＋承诺开头套件 | 从正文已有的对象和判断开场；不能每次制造普遍焦虑，标题承诺须兑现。 |
| D-17 | 连接词在固定位置高频出现 | 看相邻段真实关系；删空连接并修缺失前提，必要连接保留。 |
| D-18 | 为避免重复强行换同义词 | 同一对象叫同一名字，保留用户标志措辞；不让词汇轮换造成概念换义。 |
| D-19 | 翻译腔与名词化 | 谁做什么先说清，“进行/实现/关于/基于”有实际用途才留。 |
| D-20 | 假“讲一个朋友的故事” | 真实故事须有来源；虚构任务可创造但不冒充作者亲历，不临时造朋友证明观点。 |
| D-21 | 万能“你值得”祝福结尾 | 删与前文无关的抚慰；信件或真实情感表达按关系和任务保留。 |
| D-22 | 过拟合深刻 | “本质/归根结底”后命题若比材料大就缩回证据支持范围；有论证的深判断保留。 |

## 2.0.0 补充：有用方法内化，按任务启用

以下补充来自已退役的公开适配包，来源与排除理由见提取账。它们是语义审稿规则，不增加机械词表或配额。已有规则覆盖的内容不重复扩成新流程。

| 编号 | 采用的方法 | 应用边界 |
| --- | --- | --- |
| K-01 原话与回改校准 | 摘录关键句时保留上下文、归属、版本及它怎样推进判断；用户手改稿与上一版逐处比对，识别删背景、换主语、补因果、保留比喻等功能。 | 只服务本轮或已授权资产库，不把单篇题材词、笔误和口头禅擅自固化成长期画像。原始录音、已加工稿、第三方观点和智能摘要不能互相冒名。 |
| K-02 证据接住判断 | 区分一手事实、平台评测、具名观点、二次转述与用户材料。检查从事实到结论缺了哪一步，先修因果桥；必要术语解释它改变什么动作、带来什么成本或限制。 | 不规定必须按科技稿证据阶梯重排原稿；不要求每个观点都配个人项目。没有亲测可以写资料分析，不能发明失败或亲历来“增人味”。 |
| K-03 功能写到实际后果 | 产品、方法或行业稿中，把“强大、提升、颠覆”落到哪一步变了、谁省事或多担责任。建议确有需要时写成动作与可见验收结果。 | 文学与人物稿不强制写操作步骤；没有测量就不编节省分钟数、效果或收益。技术解释够用即止，不拿术语数量撑篇幅。 |
| K-04 动态事实与状态 | 产品能力、价格、许可、数据和榜单按版本、日期及统计口径核对；区分演示、内测、开放、计划与愿景。平台分数只能支持对应任务结论。 | 标题与正文使用同一事实边界；不拿一句文末限定挽救夸大的标题，不把热度当真伪证明。核验笔记默认留内部。 |
| K-05 原创性与作者声音 | 学习注意力、解释和证据的作用，再用本篇材料与用户判断成文；不用换名词、换同义词复制样本文的独特顺序、笑话、长句或比喻。 | 不继承参考作者身份、口癖、CTA、样本成绩或模板。不借原创性审计删改用户自己的原话和独特表达。 |
| H-13 知道什么就说到哪里 | 区分当时所知与事后理解、时间先后与因果、行动与动机。资料解读也可以有清楚的作者判断，声音来自取舍。 | 不用后来成功倒推早有远见；不强制第一人称检索表演或最强反方段落。只有影响结论的缺口才需要正文交代。 |
| H-14 叙述快慢服务理解 | 已有材料中的关键选择、关系变化可展开，重复过程可概述；事实、数字之后补它在本篇的作用，而不堆履历和名单。 | 口述稿默认不重构时间线；没有场景记录就不把概述“拍成现场”。契诃夫留白只省可推得的解释，不撤关键因果。 |
| H-15 形式跟随用途 | 问答尽早接问题；教程说明前提、动作和结果；资料评测标明材料性质；口播检查听觉指代与呼吸；小标题帮助定位而非提前宣布每段结论。 | 只启用当前交付形式所需部分，用户长度与原稿优先。不把所有稿子改成论坛帖，也不把全文短句化。 |
| H-16 虚构才创造 | 明确虚构任务中，对白服务人物当下目的，人物所知一致，细节跟随视角，关键转折有既定条件或代价。 | 现实口述、人物经历与新闻稿不得借这条补对白、天气、心理或冲突；未授权虚构时仍按现实边界。 |

不内化：HKRO 强制评分、O 不得为零、1800/2000 字通用上限、开头固定百字、中段两三次反转、每个判断必须挂个人实测、强制行业升维、强制行动收尾、禁全部破折号/冒号/三项排比、随机调整句长或固定删半数连词。这些会改换任务或误伤口述、契诃夫与暴击的有效表达。
