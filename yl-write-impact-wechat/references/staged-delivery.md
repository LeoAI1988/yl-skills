# 两阶段交付与成品合同

## 阶段A：文字定稿

对用户只交付一份正文 Markdown：

```text
项目/
└── 公众号文章-主题.md
```

修改期间只维护这一个文件。标题、正文、小标题和固定结尾都在其中。

阶段A不产生：

- 图片或图片提示词成品
- Markdown 图片引用
- HTML、复制版页面或预览页
- 多个并行正文版本

默认先完成正文并取得文字定稿确认，再做包装。若当前任务已明确授权同时做文字与包装，按该授权执行；不得把默认阶段门解释成用户无从覆盖的额外限制。

文字放行必须明确指向定稿或包装，例如：

- “文字定稿”
- “文案没问题，可以做图”
- “开始完整排版和 HTML”

含糊肯定不等于放行。

## 阶段B：图片与 HTML

文字放行后，按顺序执行：

1. 冻结正文和标题。
2. 规划封面；只有必要的真实资料证据才规划正文图片。
3. 获取或生成并检查最终图片。
4. 把最终图片引用写回同一份 Markdown。
5. 从该 Markdown 生成一键复制 HTML。
6. 生成发布说明和事实说明。
7. 运行自动校验并完成一次真实复制粘贴检查。

## 配图合同

每张图先定义：

```text
编号：
插入位置：
叙事功能：封面 / 竞争 / 机制 / 危机 / 行动
口号：
画面主体：
主色与氛围：
比例：
禁止元素：
文件名：
Alt：
```

规则：

- 视觉服务本篇主题，不复用无关文章的家族传记、复古纸张或旧照片分格风格。
- 封面涉及真实人物时，优先使用公开真人照片，保存来源链接；只调整裁切、色调、明暗、背景和标题排版，不篡改面部，不用AI生成肖像冒充真人。
- 正文默认不使用装饰性AI配图，只在真实聊天截图、公开资料图、数据图等确有证据或解释价值时插图；没有必要素材时只保留封面。
- 不涉及真人的AI科技封面可使用黑色、警报红、电光蓝、数据流、速度感和危机感。
- 图片口号取自正文核心判断，必须呼应上下文，不另造一套观点。
- 口号使用醒目、清晰、美观的大字；用户指定时采用白色大字。
- 封面只承载全文最强冲突，移动端缩略图仍能识别。
- 检查中文错字、乱码、人物畸形、旧图残留和比例裁切。

## HTML 构建

在 Skill 根目录运行：

```powershell
node scripts/build-wechat-html.mjs --input ARTICLE.md --output ARTICLE.html
# 可选：追加 --cta-file CTA.txt，读取安装者确认的结尾
```

构建器会：

- 将本地图片嵌入为 Data URI，支持离线打开。
- 使用内联样式生成公众号正文。
- 将二级小标题设置为约22px、900字重。
- 指定 `--cta-file CTA.txt` 时，校验正文以该 CTA 结尾并将对应段落设置为红色、加粗，与上文额外拉开约一行。未提供时不插入或强制任何固定 CTA。
- 在正文外提供“复制公众号全文”按钮。
- 同时复制 `text/html` 和 `text/plain`，并提供回退复制。

只允许本地图片路径。远程图片、缺失图片和不支持的格式必须先处理。

## 校验

阶段A：

```powershell
node scripts/validate-wechat-article.mjs --phase text --md ARTICLE.md --max-chars 2500
```

阶段B：

```powershell
node scripts/validate-wechat-article.mjs --phase package --md ARTICLE.md --html ARTICLE.html --max-chars 2500
```

调整 `--max-chars` 以符合当轮明确篇幅。

```text
项目/

├── 公众号文章-主题-一键复制版.html
├── 事实核验与素材说明.md
├── 发布说明.md
└── assets/
    ├── cover.png
    └── source-*.png（仅在确有必要时）
```

## 发布前验收

- Markdown 和 HTML 文字逐段一致。
- 图片数量、顺序和二进制内容一致。
- HTML 断网可打开，图片仍显示。
- 点击复制后，粘贴不包含工具栏。
- 标题、小标题、加粗、图片和固定结尾均保留。
- 没有本地路径、旧图、TODO 或内部证据标记。
- 事实说明区分亲历、事实、判断、营销口径和第三方来源。
