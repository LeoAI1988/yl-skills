# 暴击风格文字合同

## 1. 写作顺序

先摘原话，再搭结构，最后成文。

原话金句库至少分四栏：

| 类型 | 优先保留内容 |
|---|---|
| 事实动作 | 时间、数字、公司动作、产品变化 |
| 作者口语 | “杀疯了”“掀桌子”“把活干完”等自然表达 |
| 亲身细节 | 安装、卸载、报错、修改、项目实践 |
| 判断落锤 | 已形成作者辨识度的结论句 |

允许删口头重复、纠正明确转写错误、补必要主语。不要把原话统一换成“值得注意的是”“由此可见”“赋能千行百业”。

## 2. 标题

使用：

> 核心事件或对象＋明确阶段判断，必要时带普通人后果

标题必须同时给出事件、判断和读者关系。优先使用具体冲突词，不写“浅谈”“一些思考”“未来展望”。

示例：

> 新工具接管了三道重复工序，最先改变的是交付时间

这是结构示例，具体功能和时间必须由本轮材料支持。

## 3. 开头前100字

公众号开头保留最高能量判断，但不机械搬运短视频三秒口号。用成熟、准确的措辞立住判断，随后马上交代发生了什么。事件和判断谁先出现都可以，首屏必须让读者知道文章在讲哪件事。

不要先讲远处的行业历史，不用“在这个日新月异的时代”占满首屏，也不要写作者此前发过的视频、文章和播放量。

## 4. 推进节奏

使用循环：

> 事件推进 → 人话解释 → 短句停顿 → 力量关系显现 → 留白

操作规则：

- 一句话优先只承担一个意思。
- 重要判断单独成段。
- 连续事实之后，用极短句刹车。
- 重复必须递进：“越来越爽”推进到“停不下来”，不能只是同义反复。
- 自然问句和对照可以使用，但不能把“你以为……？错。”“不是……，是……”写成固定机关。
- 每节只留一两句最强比喻，避免满篇耍狠。

## 5. 正文结构

采用：

1. **判断与事件**：立住分量，迅速讲清发生了什么。
2. **新东西与差异**：回答它与主流方案真正不同在哪里。
3. **第一性原理与机制**：只讲普通人理解差异所需的原理。
4. **力量与局面**：用事实、案例和必要的历史暗示呈现后果。
5. **当天行动**：确有必要时，给读者一件能执行和验收的事。

少分节，不强制 `01、02、03、04`。只有信息类型或阅读任务真正切换时才使用结论型小标题。

宏观判断必须有事实或力量关系承接。不要替读者命名情绪；有行动价值时才给当天动作。

## 6. 作者味与 AI 味

| AI 味问题 | 暴击风改法 |
|---|---|
| 工整地凑三个抽象名词 | 换成一个具体结果或动作 |
| 每段都像金句海报 | 用事实段支撑一两句落锤 |
| “我看到的数据是”反复打底 | 可确认的事实直接写，判断另起一段 |
| “颠覆、赋能、重塑”代替解释 | 写清时间、数字、功能和后果 |
| 替读者编焦虑或编作者经历 | 只使用逐字稿和可回指材料 |
| 结尾只喊“拥抱变化” | 给真实资料、验收标准和死线 |

## 7. 自编辑

逐段检查：

- 这段有原始材料支撑，还是模型自己觉得顺？
- 作者会自然说这句话吗？
- 能否删掉一个抽象词，换成动作、数字或细节？
- 这一段是在推进因果，还是重复焦虑？
- 最强句是否被埋在长段中？
- 个人经历是否承担论证功能？
- 行动建议能否今天执行？
