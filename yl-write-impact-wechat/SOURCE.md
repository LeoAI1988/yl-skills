# 来源与公开版范围

## 来源

本目录是日常版 `write-impact-wechat` 的独立公开适配版；原版未被修改。本版自己的版本见 `VERSION`，逐文件上游指纹见 [references/source-snapshot.json](references/source-snapshot.json)。快照只记录来源 slug、安全相对路径和 SHA-256，不包含作者机器路径、账户凭证或原始私人材料。

## 许可

原目录未附独立 LICENSE。本轮用户将其作为自制技能授权公开整理，本公开版方法、脚本和整合文档以随附 [MIT License](LICENSE) 发布，署名为 yl Skill Cluster contributors。用户称呼中的“咪蒙风格”仅用于辨识高冲击叙事方向，不代表该作者参与、授权或背书；不分发其文章全文。图片、文章、安装者素材等第三方内容按各自权利处理，不受本包 MIT 扩权。

## 适配内容

- 保留原话卡、主张分层、高冲击结构、标题与节奏规则、文字/包装两阶段流程和离线富文本 HTML 工具。
- 将作者身份和特定文章样例替换为安装者说明与虚构测试样例。
- 删除个人固定结尾与赠品导流；支持可选 `--cta-file`，不配置时无需 CTA。
- 将未列明的私人子技能依赖改为可选连接器与文件导入。
- 保留 Markdown/HTML 文字一致性和图片 SHA-256 校验，修复数字 HTML 实体解析判断。

## 运行与数据

Node.js 18 或更新版本，只使用 Node 内置模块。无需访问维护者的机器、账号或其他私人 Skill。安装者提供自己的原始素材。所有任务输入、CTA、临时文件、日志和派生成果应保存在安装者自己的项目目录；本目录只放规则、可分发参考和脚本。连接外部笔记或图片服务时，由安装者自行配置工具与凭证，并按其实际授权范围调用。没有连接器仍可用本地材料完成写作。

运行路径均相对当前 Skill 目录，建议从 Skill 根目录执行，输入和输出可指向安装者项目中的绝对路径。逐文件复核与验证见 [AUDIT.md](AUDIT.md)。
