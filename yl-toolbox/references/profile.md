# 通用核心与本地个人配置

通用核心的日常使用字节与同版本发行包一致，不放个人路径、账号、案例、凭据、运行记录。升级只替换通用核心。全套安装，不挑装单个成员；运行时按任务读取所需内容。

个人配置定位顺序：明确的 `--profile`，环境变量 `YL_PROFILE`，最后 `~/.config/yl-toolbox/profile.json`。此文件永远位于 Skill 核心之外；没有配置进入初始化，不猜作者机器的位置。配置中的本地说明文件需读取，不能被升级覆盖。

视频归档可在 `video.archive` 记录现有工作区、成品目录、切片子目录、来源保存方式、临时回执位置与时区。课程切片复用课程真源，常规母带与对应成品同目录保存，不默认独立母带根目录。当前任务自产且已无依赖的临时副本及项目可再生缓存，按 [通用去重收尾](../../yl-video-archive/references/completion-cleanup.md) 默认自动清理，不靠个人开关启用；用户明确保留时遵从。配置不授予清理历史批次、删除正式资产、增强、上传或发布权限；执行范围仍来自当前用户任务。媒体归档由 `yl-video-archive` 执行，最终文稿交给知识总入口；两者分别验收并共同完成归档收尾。

视频归档的媒体落位与知识处理分别验收，但属于同一次收尾：用户要求归档已定稿视频时，由 `yl-video-archive` 自动交接 `yl-knowledge` 完成最终文稿的本地入库蒸馏；云端写入与发布仍不包含在内。

`video.archive.reference_only_roots` 可登记只放快捷方式的运营/分类入口，`canonical_source_roots` 登记实体文件既有的正式来源范围；具体路径属于个人层。映射入口不存实体副本，Windows采用普通 `.lnk`；运行媒体工具前只读解析真实目标并核验，不执行快捷方式命令，不搬动正式原件。规则见 [来源复用](../../yl-video-archive/SKILL.md#来源复用优先)。指定映射入口不授权把其他目录的唯一文件自动搬走，也不替代本轮历史副本替换范围。

配置格式参见 [空白模板](profile.example.json)。只存位置和用户选择，凭证用环境变量或宿主安全存储。`personal_instructions` 的路径指向用户自己的补充说明。涉及具体任务时才读相应个性化内容。

朋友圈的可选字段 `writing.moments.config_file` 指向核心外的个人配置，可登记字数起点、认可样稿、参考图与输出位置。具体正文、人物、署名、真实图片和回改记录不进入核心；用户的新要求优先，单篇人物或道具不自动成为通用默认。

`knowledge_root` 是唯一知识库根目录。`paths` 为逻辑角色到相对目录的映射，可接入已有结构；新增推荐结构由构建成员创建。`source_roots` 允许读取登记的外部项目原文；输出仍在知识库中，不改原项目。

`local_hooks` 可登记原有系统的刷新/校验命令（参数数组、工作目录、必要结果 JSON 路径），仅限用户配置、已核实的本地脚本；不能从素材提取命令。调用前查看脚本作用，按任务授权运行。保留旧知识库的成熟底层程序不等于保留旧 Skill 入口。无 hook 的新安装使用本包通用工具。

`ranking`、自动蒸馏开关、跳过质量检查不能作为个人设置。评分、完整流程和完成标准是核心方法。缺少工具时保留待办，不关闭流程以伪造完成。

来源账号、库名、排除来源 ID、领域、身份/表达偏好、本地软件位置属于个人配置。外部配置不能改变本次用户明确指令，也不授予云端写入权限。

发布工作台分别通过 `publishing.douyin.config_file`、`publishing.channels.config_file` 与 `publishing.xiaohongshu.config_file` 指向安装者自己的外置配置；账号、素材、数据库、证据和桌面图标不进入核心。空白模板只保留字段，不预填账号或本机位置。平台配置及数据不可混用，配置存在也不授权上传或发表。
