# 复盘回流

读取同级共同合同及 `yl-media/references/ranking.md`。自媒体负责原始采集与分析，本成员维护知识库作品/选题关系。先按平台发布 ID 与 work_id 匹配，不按标题猜同一作品，不把排名当 ID。

每次快照保留实际采集时间与证据，不将本次处理时间当采集时间。累计数不相加；相同快照重复导入不重复记账。平均观看、涨粉、三秒、完播等缺失留空，不填0。

评分只调用同级 `yl-media/scripts/ranking.py` 的统一方法。公众号保留自身指标，不套视频评分。已有读者层通过配置的 `review_refresh` hook 更新，新库将规范化 JSON/CSV 和正文关系置于系统资料、作品、选题视图。

新正文→知识总入口完成归档、去重、蒸馏、表达、关系和检查；已有正文只变指标→仅刷新表现。来源未取得正文、音频未校对等明确保留，不把数据表齐全当文稿已完成。
