# 项目案例

先读取[个人配置约定](../yl-toolbox/references/profile.md)及安装者任务相关说明。从 `knowledge_root` 与 `paths.projects` 定位项目区，案例位于其 `案例` 子目录。已有项目资料通过路径和聊天 ID 回源，原件沿原位置保留。

## 查找和复用

1. 先将需求转换成少量关键词（问题、技术、场景或想复用的成果），运行 `search`。结果少时分开查同义词，或按分类查。查资料为只读。
2. 打开匹配的案例正文与决定性证据。交付时分清曾经有效的办法、当时环境与条件、仍待验证的环节。目录命中和文件存在只证明可回源。
3. 确认旧案例在当前项目适用的环节，再引用或改用。引用保留稳定 ID 和明确来源。

## 归档和更新

1. 核对用户授权、聊天及可用原件，按项目事实选一个可独立复用的案例。保留有用的决策、失败回退、结果和使用边界。将观察、判断、计划和已验证结果写清楚。
2. 搜索项目名、成果、旧标题或 ID。匹配同一事项时沿用原 ID 和分类，合并有证据的新结果，保留有意义的历史阶段。新建时使用尚未占用的稳定英文 kebab-case ID。分类应沿用已有体系，确有需要时扩充；分类迁移前核对旧引用。
3. 按[卡片格式](references/card.md)准备完整 Markdown，读回核对全文，运行 `archive`。该命令扫描全库 ID，再更新同一位置或落下新卡；完全相同的内容不会重写。改动日期用于实际变更。
4. 用 `verify` 检查结构、目录归属、重复 ID 与本地证据路径。确认新增或修改的卡片可搜到，回读其原始证据与关键结论。说明实际验证范围和剩余缺口。

案例索引可按需生成。对外文章、作品文稿蒸馏、平台发布或上传按当次任务另行路由。

## 命令

从本 Skill 目录执行，或使用脚本绝对路径。可用全局参数 `--profile` 指定配置，`--root` 指定现有案例目录或隔离测试目录。

```text
python -B -X utf8 scripts/cases.py search "课程 字幕" --limit 5
python -B -X utf8 scripts/cases.py search --category "课程"
python -B -X utf8 scripts/cases.py index
python -B -X utf8 scripts/cases.py verify
python -B -X utf8 scripts/cases.py archive "待归档案例.md"
```
