# 视频字幕与标题版式

先读最终显示画布（含旋转、裁切）、实际镜头、已锁的文字和出现时段。已有字幕可从轨道或工程读取；烤入画面的旧字随底片裁切，需换样式时优先回无字底片。用户圈出的播放器画面须先换算为有效画布。只排标题或只排字幕均可独立执行。

| 实际画布 | 布局 |
| --- | --- |
| 横屏 | [侧置标题与低位字幕](references/landscape.md)。在视线侧或空白较大的一侧放标题，底板局部羽化。字幕固定下方基线，按最长页定统一字号。 |
| 竖屏 | [标题与字幕参考](references/portrait.md)。顶部安全区按语义分行，适配手机界面边缘、近景脸和嘴部运动。字幕在稳定基线上向上换行，保留底部界面安全区。 |

打开[布局工具](scripts/layout.py)，传最终宽高。横屏有标题时指定侧别，竖屏用 `--title` 加入顶部标题区。可用 `--title-region` 给出经过镜头核对的归一化区域。仅字幕省略标题参数。横屏读取 profile 的 `video.landscape_style_file`，竖屏读取 `video.visual_style_file`。颜色、实际字体、描边和装饰继续读取所选模板；转为另一画幅要重新排字和测量有效区域。

```text
python scripts/layout.py --width 1920 --height 1080 --side right
python scripts/layout.py --width 1080 --height 1920 --title
```

把像素版式、锁定时码、字行及字体身份交给当前文字生成器。数字、单位及专名作为不可拆单元；测最长页和双行页，保持固定字号。图解独立启用时，向其提供标题、字幕的可见框与时段。单独改样式时可以交付样式参数、逐页透明层或合成片，按用户要的产物执行。合成片复用同画幅底片和原音轨，从实际导出检查首句、最长页、转头、插入画面和标题退场。竖屏居中参考模板可另用[视觉检查器](scripts/validate-visual-contract.py)核对缓存来源及字面像素。横屏侧置标题单独验看其实际区域与羽化边缘。
