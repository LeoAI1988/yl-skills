# 横屏标题与字幕

## 先看镜头，再选标题位置

在标题出现、人物转头或伸手、标题即将退出的帧上，分别观察脸、视线方向、手势及正在讲解的物体。优先选择视线朝向且有容字空间的一侧；该侧有重要信息时，选择留白更多的一侧。标题与底板一起避开人物脸部和要读的板书。两侧都挤时，先收窄文字区、调整分行或在同侧上下移动。整段沿用选好的位置，镜头内不随头部晃动。用户圈出的框用来判断区域，实际定位以有效视频画面为准。

在选好的局部区域排一或两行，保留当前字体、主副行色彩和信息层级。黑底贴合排好的**标题字块**，四周留出羽化余量。先在透明灰度遮罩上画字块底形，再模糊遮罩，使黑色中心半透明、四边连续衰减到透明；最后叠清晰的文字。重点分析层已有底板参考时，复用其黑色、不透明度和羽化尺度。单纯给矩形降透明度或加圆角仍会出现硬边。

## 字幕

以有效画面底部为锚，用真实字体的排印基线居中排字幕。底部安全距离要包含下伸字形、描边和阴影。用户给圈框时把圈框从截图换算到有效画布，用同一句实际字面比对。增大字号后量最长页，优先按语义换行，最后一行基线固定，第二行向上生长。保持各页同一字号。时间轴已锁定时，页内换行保留原句与时码。

## 交给渲染器

运行 [横屏布局参数工具](../scripts/layout.py)，传入有效宽高；出现标题时按镜头传入侧别，可用归一化的左、上、右、下坐标指定可用区域。只排字幕时省略侧别。工具向标准输出写 JSON，内含像素坐标、字幕字号、固定末行基线、可用行宽和标题底板参数，适用于 Remotion、FFmpeg 图层或其他合成器。

```text
python scripts/layout.py --width 1920 --height 1080 --side right --title-region 0.58 0.16 0.94 0.55
```

个人 profile 的 `video.landscape_style_file` 可配置 `subtitleSizeAt1080`、`subtitleBaselineAt1080` 和 `subtitleWidthFraction`。按本次画布高度一次换算，宽度按实际画幅换算。`video.emphasis_style_file` 的 `backdrop` 提供黑底透明度与羽化参考。无个人配置时使用工具的起始值；任务明确给定的构图和样式优先。字体、颜色、字号以外的基础字形风格沿用当前工程。将输出存入本次项目样式，并让透明图层生成器、合成器和预览共用该份参数。

## 从实际画面核对

用 Pillow 合成时，可直接调用参数工具内的 `title_backdrop(layout, ink_bounds)`。传入实际字块包围盒即可得到全画布 RGBA 底板，在其上另叠标题。其他渲染器用相同的透明度和羽化宽度生成遮罩。

对比标题所处侧的人脸运动与板书，检查标题显示全程；放大底板四边，确认黑底自然消失，字形清晰。抽取首句、最长页、双行页与结尾，核对字面离底距离、统一字号和播放尺寸下的可读性。验证标题与字幕各自的透明层，可避开重点图形对像素测量的干扰。更新布局参数后重新生成相关视觉缓存。用户只要求记录时，将意见留在反馈或个人样式里，已有视频待用户授权再合成。
