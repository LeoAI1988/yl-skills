# 小红书浏览器核验

先读取宿主浏览器文档，所有选择器来自当前页面。仅使用可见正常页面，不用私有接口、Cookie 或隐藏脚本。

- 登录页只说明当前未登录，不能猜测账号、输入验证码或自行同意新的协议。保留现有会话，待用户正常登录；不反复刷新登录页。
- 先确认正在发布视频笔记并核对账号。上传后核对标题/正文计数、话题上限和实际定时规则；定时控件若仅在上传后展示，上传前看不到它不构成阻断。页面与本地预检不一致时采用更严格限制并报告，不能通过降低校验绕过平台。
- 上传前先按工具规范绑定文件选择器；只上传用户授权的一篇成片与对应封面。上传本身可能触发平台自动保存，进入页面前向用户如实说明该点，不能承诺云端绝无草稿。
- 本地原稿 `body` 不直接进入发布框，只用 `caption` 与获确认的相关话题。AI 参与说明若需要写正文，必须包含在最终 1000 字预检内。
- 话题逐个输入并选择当前页面的有效候选；不沿用抖音“空格一定转为话题”的假设。回读真实话题节点，最多 10 个，名称必须与选择一致。
- 队列在上传前已匹配本篇已有封面，或按已确认策略提取本条成片原帧。封面上传后核对实际预览与裁切，使用当前页面已有裁切控件保留标题与人物主体；不重新生成图片，也不把平台默认截帧写成自定义封面已上传。
- 平台自动推荐的标题、封面和章节不是用户已选内容。保留已有成片和封面，不点击生成或一键应用；章节建议出现时检查实际已添加数量，不能把建议当成已应用。
- 位置、活动、合集、可见范围、下载权限、AI 声明逐项回读。页面没有控件就记“不支持/未找到”，不把抖音设置映射成别的选项。不存在的合集不新建。
- 对定时开关、日期和时间读最终保存值，不仅看输入过程。不支持或失效时停止准备，不退回立即发布。
- 提交前回读该篇标题、话题数量、AI 参与情况、账号与实际时间。只有冻结清单明确为 `batch_publish` 且已有整批发布确认时，才能点击一次最终定时提交并核验；`prepare` 模式仍停在填表，`verify` 模式禁止平台写入。不能把开发或升级任务当成发表授权，不主动保存草稿。
- 提交后执行只读核验。若未出现在列表中，不能仅凭第一次未查到就认定未提交；检查定时、审核和公开列表及必要的实际视频内容。证据不足保持 `unknown` 或 `awaiting_manual`。若根本未选文件、未填表、未提交，记录明确的上传前中断，返回 `not_uploaded`，无需反复核对旧记录。
- 验证码、频率/风险提示出现时停止整个准备动作；不会随机等待后自动恢复，不切换账号或浏览器身份。


- 旧作标题或封面不可点击时，检查卡片的“编辑”入口，只读播放视频预览核对两个不同位置；不改字段、不点旧稿发布。无法确认同次录制时，将上传前的疑似重复隔离为 `duplicate_pending`，保留候选记录，继续其余条目。登录、验证码、账号或平台限制仍停整批。

文件选择先注册 filechooser 等待，再点击当前可见的上传视频按钮；不要点击隐藏文件 input 的辅助文字。调用 setFiles 前才记录 upload_started=true。若文件窗口未打开且未调用 setFiles，记录 choosing 失败及空白页证据，不把窗口尝试当作已传输文件。

单次页面读取超时与连接失效分开：立刻暂停写入，只做一次当前原标签页的只读状态或截图检查。若恢复正常且账号、文件名、上传/编辑阶段可明确对应本篇，未点击最终提交，可在同一页等待上传或继续填写，不重新选文件，不重传。不创建另一个编辑页绕过故障。若已点击提交，只能核验结果；原页不可访问、身份/状态不明、明确连接断开则仍停整批，不循环重试。

视频文件选择后须先确认本条上传完成，再打开封面编辑器或选择封面文件，避免视频仍在上传和初始化时叠加文件窗口。文件选择器等待必须立即处理 rejection（例如用 Promise.all 同时绑定点击与窗口等待），不能留下未捕获的异步错误重置浏览器工具。连接中断但明确未最终提交的批次，仅凭新鲜原页账号、文件、上传完成截图与冻结明细核对后沿原页恢复，不重传。

页面布局过小时，提交栏可能在截图中可见而普通DOM/AX文字未收录；不能把它误报成平台不支持。先按当前截图定位真实按钮；若布局确实无法操作，再用宿主文档允许的临时桌面视口，操作后恢复。已确认未采用的章节建议不要反复打开。工作台会保存工具输出截图，不需浏览器运行环境额外写文件。
