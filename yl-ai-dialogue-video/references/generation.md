# 生成、额度和补救

## 选择实际可用的渠道

先查当前任务的工具、连接状态和用户已选平台。豆包、即梦是可选网页渠道，其他有音频的视频生成服务也可用。连接器缺功能时说明后使用浏览器；浏览器操作须读取该环境的说明，不从旧记录猜按钮、URL参数或隐藏接口。

记录核查时间、账号的本地别名（公开材料不含账号标识）、模型、时长范围、画幅、有无生成对白、报价与剩余额度证据。显示“今日用完”只能证明当时不可继续；成功生成若干次不证明每天固定上限。余额与单次报价不同：有免费积分也未必足够选定模型。权益和页面会变，不把历史测试写成承诺。

按用户约定的成本执行。没有付费授权不充值、升级或切换付费模型；本地字幕、剪辑、速度和拼接通常不消耗生成平台次数。语音重合成、数字人口型重做或音画生成属于新的外部任务，应计入台账。

## 提交与恢复

在外部运行目录维护生成台账，每行至少包含：片段ID、尝试ID、提示词/参考资产摘要、提交时间、渠道/模型/时长、任务或会话引用、费用/额度证据、状态、下载文件摘要和采用/弃用原因。

状态示例：`prepared → submitted → running → ready → downloaded → accepted/rejected`，另有`failed`和`unknown`。下载文件存在且可解码后才算本地素材到手。

有任务ID或正在生成的证据只继续查询；卡片晚出现时先刷新/查历史。结果不明保留unknown，不盲目重提。只有明确失败，或用户要求的新版本且额度/成本允许，才建立下一次尝试。重做优先局限于失败片段；多次同类失败应改变提示词或方案，不能持续消耗额度碰运气。

用户本人处理需要其凭证、验证码或必须本人完成的声明步骤；已经在本账号完成的授权不再重复索要。不要将普通可逆剪辑也变成许可门槛。不要自动切换/创建账号来增加额度；用户明确提供另一个自有账号时按当前平台与工具规则处理，并分别记账。

## 下载后的缺陷处置

| 实际缺陷 | 优先处理 |
|---|---|
| 说完后的长等待、可确认无内容的空白 | 本地剪辑，保留末字与自然呼吸 |
| 各段正常但节奏不一致 | 同一源时间线按句调速，保持音调；检查相邻句的听感 |
| 重复、增词、漏词 | 独立转写定位，再听/看原声；可干净删除的重复本地处理，漏音或错音不能只改字幕 |
| 单个专名/字音确错 | 小范围重录或生成补句仅在需要时做，保留音色与上下文；记录拼接边界，重点听审 |
| 小字幕被烤进生成素材 | 先找无字导出、改裁切或可接受遮盖；修复必须检查时序和脸部，不能默认全画面重绘 |
| 身份、服装、声线、口型明显漂移 | 重做对应段或换连续镜头方案；字幕与提速不能解决身份错误 |

同音转写差异与真实发音错误分开。一次ASR输出不是修改音频的充分证据；需要时用第二种识别或局部上下文复核。任何声音补丁都保留可回溯的原素材和补丁区间，不能宣称听审通过而未实际听过。
