# 参数到实际成片的执行契约

复用或修改生成器之前，以及最终放行之前读取。原有停顿、速度、排版和听审要求不变；本契约补足其实现证据。

## 先验证实现，再批量

视觉修订先锁定本轮唯一样式和参考来源。禁止全批自动避让覆盖已指定的字幕基线；禁止给旧文字图片补写当前样式哈希后复用。必须验证“参考要求 → 实际渲染参数 → 文字层像素 → 最终MP4”四者对应；验收器不能把生成器里的错误默认值写成预期值。主观观察按真实逐项结果记录，不运行一个只检查证据路径存在就写 PASS 的函数。

静态文字层可运行 `python scripts/validate-visual-contract.py --style <本轮样式.json> --captions <captions.json> --layers <layers_manifest.json> --report <新报告.json>`。该脚本只验证参数、来源记录和字幕像素区域；不能代替实际成片与参考的字形厚度、遮挡和画质比较。错误基线、旧样式缓存和违背装饰开关必须返回非零。

文字横向缩放时，中间未缩放画布必须容纳完整字形及描边。不能只验证缩放后的文字宽度小于安全宽度，却在缩放之前用更窄画布裁掉右侧字。检查器另比对标题实际彩色字面左右边缘与真实字体度量；长标题裁切的旧样例必须被拒绝。文字缓存同时记录生成器 SHA-256，生成器修复后不得沿用旧层。

| 要求 | 实际证据 | 不能代替的东西 |
|---|---|---|
| 停顿已剪 | 修后 keeps 确实排除裁决的区间，最终音轨再扫且切点复核 | 候选清单、把状态改为完成、VAD 返回成功 |
| 无残音/吞字 | 源中左右完整短语与输出连接对照；有声残字另设删除边界 | 字幕干净、段首静音、词时未经复核 |
| 倍速正确 | 每段 role、既有速度/未知、此次 appliedRate、源秒到输出帧映射及音画同步 | 文件总时长比、全片再乘一次倍速 |
| 字号位置正确 | 加载字体的真实 weight 与排印度量，原分辨率的可见字高/基线/阴影及渲染抽帧 | 字体文件名、`fontWeight:900`、配置中写124 |
| 本轮结果对应 | 输入/EDL/文字层/输出哈希与版本，帧数及浏览链接一致 | 进程结束、同名旧文件存在、运行后另改的计划 |

样式定义的是排印基线时，渲染器必须使用基线定位。Pillow 可用 `anchor="ls"`；浏览器须记录实际加载后的 ascent/descent；ASS 的 `Fontsize` 和 `\an5\pos(...)` 不能直接当作浏览器像素和基线，须通过同文小样测量换算。字形应按整层统一横向比例缩放，不按每页可见高度重新居中。先输出含中文、英文、数字和长短字幕的小样，再放行全批；标题下划线、阴影和10秒退场也要检查。

混用母带和既有成片时，记录原片/导出版的来源身份，不能把同一拍摄的导出计为新拍摄。已有字幕和历史倍速必须在复用前查明；找不到清洁源时显式处理烧录样式，不得因“它原来就是这样”自动豁免用户本轮的统一要求。

检测、裁决、执行、成片复核是四种状态。自动程序只能证明实际运行得到的结果，不得自动把听审或主观画质字段设为通过。听审不可用时保留实际未完成状态，同时继续修复所有可以确认和执行的问题。

## 本轮清单最低关联

为每个问题关联 source hash、源区间、裁决及理由、EDL 删除/保留区间、输出时段、复核方式、输出 hash。保留具体理由，不用“自然”“已优化”等空泛词结案。最终重新运行检查，旧报告不能随新版本沿用。
