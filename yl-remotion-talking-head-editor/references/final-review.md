# 转写覆盖与成片复审（2.1）

## 剪辑前防漏字

保存源媒体哈希、不可变 raw ASR、带时间戳的修订稿。把同一源时间轴上的 VAD 发声区间减去 ASR 覆盖区间，未覆盖达到 0.30 秒的片段必须局部听审或重新转写。VAD 可能误报，ASR 也可能漏掉话；未转写不等于静音，不能直接删除。

单音节持续约 0.45 秒、双字约 0.70 秒、token 超过 0.80 秒可触发小窗口复核，不能据时长或能量峰直接判定重复字。更正写在派生转写中，记录原区间、证据及修正。

用户只划掉词语时只删该词，整行删除须有对应标记或已有决定。未标记部分继续沿用已确认方案。删掉有声字词时同步修改音频、字幕和完整成片稿；只删空白不删文字。ASR 把删留字合并在一个 token 时，先细化词时或明确切音及替换文本，不能误删仍保留的字。

## 前五秒

以 `pause-policy.json` 的成片秒为准：开头 5 秒内，无信息间隙从 0.08 秒起逐处检查，确认可收紧时总保留目标约 0.05 秒。源时间中的目标需按实际速度换算，不能直接套相同秒数。

扫描应覆盖同一保留片段内部、词内和片段尾部；整句 VAD 无断点不代表没有停顿。低于约 -40 dB、持续约 0.15 秒仅是候选，须用原声确认，保留完整字音和有功能的语气。一般区间仍按自然浮动范围处理，不将全片机械切成 0.05 秒。

## GATE-3：从真实成片复审

两种模式均在提交增强前审核剪辑版，增强后再核验实际交付文件。可用独立检查脚本产生候选，再由执行者听审裁决。无需另装 Skill。

```text
python scripts/review_final.py --captions /work/captions.json --audio /work/final.mp4 --output /work/review-v1.json
```

字幕输入为数组，每项包含 `text`、`startMs`、`endMs`，均为成片坐标。Python 3.10+，音频扫描需要 FFmpeg（PATH 或 `--ffmpeg`）。输出文件必须新建且放在 Skill 目录之外；脚本不编辑输入。

复核相邻 2–8 字重复/近重复、40 秒内的重复短语、填充词、-32 dB 且达到 0.15 秒的静音和单页达到 8 秒的字幕。参数只是检出阈值；有意义的重复不能自动删除。字幕时间只定位到所在字幕页，精剪仍需对照音频字时。

每项写明“已修复并复验／有理由保留／误报”，关联同一 EDL、字幕及输出哈希；待处理为零才能放行。生成报告、候选为零、FFmpeg 成功都不等于语义通过。脚本失败必须修复，禁止把失败当作无静音。修改成片后重跑并重新听审，不能复用旧报告。

配置是唯一编辑真源；手改临时 spec 的决定必须回写持久配置，防止下一次生成恢复旧内容。用户手工成品和无归属文件不能清理；时长不符不构成删除依据，已拥有的旧输出也应先版本化保留。

## 规范化与增强回片

按素材的有效分辨率、比例、PTS、帧率和色彩确定画布，不无条件拉伸到竖屏或 30 fps。工具确需固定帧率时保留源到规范化媒体的时间映射及两者哈希。HDR 转 SDR 要真正转换像素并核验色彩标记。

回片横倒时先比较 `ffmpeg -noautorotate` 解码帧和旋转元数据。只有原始像素已直立、元数据确实错误时才清理显示旋转，例如在支持的 FFmpeg 版本以输入选项 `-display_rotation:v:0 0` 无损重封装；明确选择本轮已批准音轨，检查实际画面、音画同步、时长和元数据。真实需要旋转的素材不能一律清零，也不应先重复付费提交增强。
