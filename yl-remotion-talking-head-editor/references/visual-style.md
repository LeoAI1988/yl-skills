# 已确认的简洁口播视觉标准

以下是可移植的简洁口播样式起点，本轮用户提供的参考和截图优先。坐标适用于 1080×1920，其他画布按比例调整并检查人物位置。

## 严格按参考统一的核对流程

- **优先级与禁止静默覆盖**：本轮用户明确要求 > 当前个人视觉配置及已认可参考 > 本文默认起点。用户要求字幕位置按参考时，不得以“避让人脸”为由把全片或全批字幕整体下移；下面的避让规则只在未锁定位置或明确获准的范围内适用。确有冲突时保留参考基准并呈现具体冲突，不把旧版避让高度带入新工程。取消黄线、要求加大加厚等最新意见必须写入本轮唯一视觉配置并由渲染器直接读取。
- **唯一配置须贯穿实现**：标题、字幕、插图、可编辑工程和导出器共用同一份样式及版本。每份文字层 manifest 记录原始生成时的样式文件 SHA-256、真实字体 SHA-256、实际字号、基线和标题装饰开关；复用缓存先比对这些原始记录。禁止用当前样式重新计算旧图片的身份，把旧层冒充新层。
- **放行依据独立于生成器默认值**：验收读取用户当前标准，不能读取生成器自行覆盖后的高度来证明自己正确。先运行 [视觉契约检查器](../scripts/validate-visual-contract.py)，再对比参考与实际导出帧。任一 FAIL 或缺少实际画面核对，均不能写“排版通过”；证据文件存在、900字重字段或生成进程成功都不能自动生成主观 PASS。
- 本轮参考优先于历史默认。读取个人 profile 的 `video.visual_style_file`（如有），得到参考媒体、样式参数与版本；个人媒体、绝对路径和字体文件留在个人层，通用核心只存方法与可移植参数。
- 用户要求字幕移动“半个字高”等相对距离时，按当前真实字体的固定代表字形测量可见高度，记录代表文本、字形包围盒和换算像素，再整批平移基线；不得拿名义字号直接代替实际字高。标题“略放大”由执行者选择小幅增量并抽帧检查，记录为实现值，不声称用户指定了该百分比。移除黄线须将 `underline.enabled=false` 传到实际渲染器及层 manifest。将这些已执行值写回个人视觉配置，后续优先读取，不能被本文历史起点或旧缓存覆盖。
- 从参考视频原始分辨率抽帧。字幕可能在前0.2秒做缩放，应选稳定帧并至少核对两个时刻；不能按播放器缩小截图、进场中间帧估计字号。
- 一并核对标题与字幕的可见字高、实际字重、白黄颜色、描边、黑影偏移/模糊/不透明度，以及顶部两行、行距、下划线、字幕基线的归一化坐标。颜色取稳定大面积字面，避免抗锯齿边缘和阴影。
- 按参考画布比例换算目标尺寸，再用加载后的真实字体渲染同文小样，与参考原帧对照。字体名称/字重不能从像素证明时明确记录，不宣称恢复了原工程字体；在现有字体里比较字形和笔画，并记录最接近的实现及可见差异。
- 用户要求一批统一时，全部视频使用同一版参数和固定基线；用户明确连位置也按参考时，不能以旧版避让高度代替。先检查实际人物位置，核验遮嘴风险，必要时在审核中明确展示；未经授权不逐句跳位。
- 实际导出的长句、短句、英文、数字及标题消失前后都抽帧检查；只有配置相同不足以证明输出一致。样式修订冻结未授权的时间轴和原声；倍速另有授权时从原始音频一次应用，已有1.1倍不能再叠乘。

## 标题与前五秒

- **明确倍率的整批标题修订**：以当前已认可的标题字号、行距和顶部锚点为基准，用户要求整体1.1倍时只应用一次；例如字号136px对应149.6px，整数渲染可取150px，同时记录1.1目标比例和150/136实际比例。行距同步扩大，保持横向字形比例及统一字重，不把字号扩大后再整体缩小。个人目标值写入profile指向的视觉标准，通用核心不保存私人路径或批次。后续生成器必须读取配置，禁止硬编码旧字号或每次再乘1.1。
- 超宽标题优先按完整词与语义换行，保持原文；有必要可使用连续固定的三行标题布局并记录例外。检查全部标题显示区间的头脸位置与安全边距，禁止裁字、删字、逐条偷偷缩字号。仅标题放大不放大字幕、封面或视频画面；未另行授权时，保留同一EDL和音轨，保持各条已确定的倍速。

- 同时检查标题与第一句话：前五秒应迅速建立观众关心的矛盾、结果或问题，用现有原声完成。后段有更强内容才考虑前置，不能强行制造倒叙或重复播放。
- 标题源于整段口播，核心对象与判断清楚，不添加原声中没有的事实或承诺。按内容生成新标题，不复用样本的 AI 标题。
- 顶部两行，第一行白色 `#FFFFFF`，第二行黄色 `#FEE10C`，无底板，细黑描边和实黑投影。从 0 秒正常出现，到约 10 秒直接消失；视频更短则受时长限制。
- 一个字体 family：Noto Sans SC。标题用真实 900 字重，字体文件必须实际含该字重，不能把只有 700 的字体设置成 900 就当作已加粗。
- 已是真实900却要求再粗时，先确认实际加载与显示；可少量同色扩张字形，让黑描边仍在外缘，并核对字腔、间距与裁切。记录为视觉加厚，不虚写不存在的1000字重，也不只加宽黑描边冒充文字变粗。
- 起点：字号 130px、水平比例 0.932、两行文字基线 y201/y327（全角汉字可见顶边约 y88/y214）、最大宽 1000px、描边 1px、黑影 x5/y8/模糊3px/不透明度0.96。第二行下方黄色横线位于 y363，高5px，左右各56px留边。按当前标题长度微调分行与宽度，保证四周留边、字符不裁切，不靠压窄到难读来硬塞。
- 不自动添加 slogan、开场音效、标题飞入或全程常驻标题。

## 字幕

- 与标题使用同一字体 family，字幕也使用真实 900 字重，禁止继续使用旧 700 字重。普通文字白色，确需强调的词用黄色 `#FEE10C`；无黑底，仅细黑描边和实黑阴影，不做逐字跳动、缩放或花哨进场。
- 起点：字号 **124px**、水平比例 **0.946**、最大宽 **960px**，固定文字基线 **y1473**；全角汉字可见范围约 **y1365–1487**（画面71.1%–77.4%）。黑描边 **1px**，阴影 **x5/y8/模糊3px/不透明度0.96**；偏移参数包含实黑核心，不用旧7px大描边或软灰影替代。最多8个全角字，其他文字按实际字体测宽。基线按字体排印基线定位，不按每页可见字形的顶边或高度重新居中。
- 分页遵循口播短语和字词边界，不能把短语拆得难理解。文字等于实际保留的口播；时间按 EDL 与倍速重新映射，静态出现即可。
- **字号整条固定**：用最终加载的字体测宽，在排版前选定本条统一字号、字重、描边、字距、水平比例和行距；确认后所有字幕页面使用同一组数值。中文、英文、数字和标点都遵守这套样式，不能按内容长度临时缩字、压字距或改变横向缩放。**124px / 最大宽 960px 是 1080 宽画布的参考起点**（用于容纳约 8 个全角字并减少不必要的两行分页）；更高分辨率按画布比例统一换算，不按每句换算。
- **长句分行或分页**：在完整词语和自然短语边界排成最多两行，或按实际口播时间分为相邻页面；不要拆开专名、数字单位或同一词的两个字。若当前选定字号下一个不可拆词太宽，应在正式渲染前统一调整整条字幕字号/安全宽度再重新排全片，不能只缩这一个词。统一全片标点约定，保留小数点、百分号等语义符号；不通过临时改变标点字号来塞行。
- **先定全片稳定区**：先扫描整个原片的人脸、低头和近景轨迹，用普通镜头及最易遮挡的镜头选择本条固定字幕容器。容器宽度、高度、底部锚点、行高均固定；单双行变化从同一底部基线向上排，不能按当前字形包围盒或行数重新垂直居中。为两行预留足够安全区，避免一行不挡嘴、两行又压嘴。
- **仅允许少量镜头例外**：必要避让按连续镜头区间记录 `subtitlePositionOverrides`，每段只有一个稳定位置，合并相邻同位置区间；不按每句、每页或每字跟踪嘴部。以少量例外为目标，多数字幕应在基准区。若出现连续来回切换、多数字幕处于例外区，或几乎逐句跳位，退回重新选择整条基准区；不要继续堆更多 override。恢复尽量落在切点或字幕换页边界，避免一句读到一半上下跳。
- 字幕避让区间按当前片的镜头确定，不复用任何旧片的时间码。
- **基准区要用数据定，不能沿用上一条**：抽 6–10 个覆盖全片的帧，量出人脸最低点到画面上边缘的距离，再与候选容器的顶边比。容器顶边 = `bottomY - containerHeight`（两行）或 `bottomY - lineHeight`（单行）。若两行的顶边会低于人脸最低点，就不要用两行——把长短语按语义拆成相邻页，并把 `bottomY` 下移到「单行也在人脸最低点之下」。同一批素材里人物姿态可能差别很大，各条基准区可以不同，但每条内部必须只有一个。
- 单行拆页会产生字数很少的页（如只放「作」「路」）。优先调整切点让每页 2–6 字；无法避免时接受，不要为此改回两行去压脸。

**组件实现与预检**：旧样本 `Captions.tsx` 中的 `fitFontSize(caption.text, ...)` 不再适用，不能直接复制。实际字幕应使用 `fontSize: style.fontSize`，由上游生成 `lines` 或换行文本；固定容器底部锚点，不再用当前文本高度配合 `translate: 0 -50%` 重算中心。标题可以单独整组排版，不受字幕固定字号规则混淆。逐页记录实际字号、字重、行数、字距、描边、横向比例与容器位置，检查渲染结果，不只读取 config 里的名义字号。长短句、英文专名、数字、百分号、单双行切换都要纳入抽查。

## 少量重点卡片

- 用户未要求卡片：`cardsRequested=false`，`cards=[]`，整条 0 处。用户明确要求加卡片：`cardsRequested=true`，自行挑选整条 1–3 处，选择文字或关系图确实帮助理解的节点；长片也不按分钟累计数量。顶部标题、普通字幕、独立封面都不计作重点卡片。不要按固定秒数强制制造变化。
- 文字标签、数字、简单箭头关系优先。默认静态出现/消失，不加转场、弹跳或音效。用户说“弹出卡片”不必解释成需要动效。
- 与字幕、标题使用同一字体 family，白黄两色。可用 `rgba(0,0,0,0.76)` 黑底、轻边框和圆角，保持清楚、克制。
- 示例布局：x90、y100、宽900、高180、圆角20；主关系字约60–66px，核心词真实900，可配48px小标题。必须检查整个显示区间的人头轨迹，不能只看某一张图就认定不挡脸。
- 时段取编辑后语义锚点，适当停留以读完；不从旧片照搬卡片文案及其秒数。
- Hyperframes 在用户指定或可用且确实有益时用于简单卡片；现有 Remotion 静态文字层已经足够时直接复用，不为两张静态卡新增渲染依赖。
- 要求对照时，有卡版和无卡版共用剪辑、声音、字幕及标题，只有卡片层不同。

## 封面与美颜

- 需要封面时沿用用户已选模式；未选时由 `yl-short-video-covers` 提供黑底白字或半透明无头像选择。该成员未安装时按本次封面约定执行。独立导出 1080×1440 PNG 和 manifest；封面不硬塞为视频第一帧，人物素材仅按本次授权使用。
- 视频标题与封面标题可以表达同一核心的不同入口，内容必须来自本条口播。使用完整原稿或已校正字幕的 script 模式，避免为了封面重复转写同一条片子。
- 已通过封面被冻结，后续视频修订不改变它。
- 完整流程按入口选定的全自动／半自动模式，在剪辑审核通过后执行开拍增强；用户限制范围时遵守。新接入先做短样，核对肤色、眼镜、五官与细节。缺少凭据或 SDK 时如实标记增强未完成，不把锐化／对比度滤镜当作开拍美颜。

## 用户明确要求的插入素材

截图、后台数据和真实证明默认画中画；操作过程视频可按要求全屏覆盖相关语句，去掉悬浮边框，保留字幕可读性。插入视频默认静音，唯一连续叙事仍为本人原声。不主动增加这些素材，不用生成式图像替换真实证明。
