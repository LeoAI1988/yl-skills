# 口播包装交接

字幕、画内标题及其横竖屏样式由[视频字幕标题版式](../../yl-video-text-layout/SKILL.md)维护。原有竖屏模板和逐页核对见[竖屏参考](../../yl-video-text-layout/references/portrait.md)。复用现有字幕时，以实际字面与 EDL 对齐。选用重点图解时，将已占用区域与同版时间轴交给[视频重点标注图解](../../yl-video-emphasis-graphics/SKILL.md)。

## 封面与美颜

- 需要封面时沿用用户已选模式；未选时由 `yl-short-video-covers` 提供黑底白字或半透明无头像选择。该成员未安装时按本次封面约定执行。独立导出 1080×1440 PNG 和 manifest；封面不硬塞为视频第一帧，人物素材仅按本次授权使用。
- 视频标题与封面标题可以表达同一核心的不同入口，内容必须来自本条口播。使用完整原稿或已校正字幕的 script 模式，避免为了封面重复转写同一条片子。
- 已通过封面被冻结，后续视频修订不改变它。
- 启用开拍时，按入口选定的全自动／半自动模式在剪辑审核后增强。新接入先做短样，核对肤色、眼镜、五官与细节。缺少凭据或 SDK 时如实标记增强未完成，不把锐化／对比度滤镜当作开拍美颜。

## 相关视频与演示画面

城市航拍、企业实景、热点新闻、操作录屏和真实图片统一按 [素材插入流程](broll-workflow.md) 编排。该流程维护开场时点、选材、节奏、标题退场、裁切和真人收束要求。展示期间按已选版式核对实际字幕可读性。
