# 相关视频与演示素材插入

完整口播剪辑按讲述内容编排 B-roll，包含城市与建筑航拍、科技企业实景、事件现场和新闻报道、产品操作、录屏、成果视频及真实图片。重点段落通过可辨认的环境、规模、动作和人物建立视觉冲击力、氛围感与代入感，原声承担完整叙事。本轮纯口播、局部修订和指定插入位置按用户范围执行。

## 1. 从原句建立镜头计划

在结构分析阶段提取地点、机构、事件、产品、动作及对比关系，标出开场和关键论点。为可展示的重点段落落实相关镜头，连接性的抽象讲述可回到真人。

| 讲述内容 | 优先寻找的画面 | 核对重点 |
| --- | --- | --- |
| 城市与区域发展，如深圳、前海、后海 | 可识别地标的航拍或高机位全景，园区、交通与真实城市活动 | 地点准确，地标清楚，尺度与运动能表现空间 |
| 科技前沿、科技企业与 AI | 企业总部/研发园区、实验室、机器人或产品运行、研发与应用场景 | 企业和地点对应，技术动作可见，远景与细节互相补充 |
| 国际会议与热点事件，如 APEC | 对应年份和举办地的会场实景、航拍、筹备现场、官方或新闻报道 | 年份、举办城市、具体场馆及筹备/举办状态有来源依据 |
| 跨城市或企业对比 | 分别对应每一方的真实镜头，在口播转换对象时切换 | 每段画面身份准确，前后对应同一比较维度 |
| 操作、方法与成果 | 真实录屏、产品运行、工作台、成果视频、说明图片 | 对应正在解释的操作、变化或结果，关键内容可辨认 |

这些对象用于说明选材方法，实际镜头随本次主题决定。对“科技前沿”等宽泛概念，用可识别企业、真实研发或应用场景落地。只有标识的平面动画、笼统科技光效和无信息远景，在现场感要求下应换成具有代表性的实拍。

每段匹配表记录口播原句/源词时、需要展现的对象、候选来源与区间、采用理由及输出范围。原片 EDL 落定后再锁定展示帧，后续修订沿用同一表。

## 2. 寻找与核实素材

先检索用户指定目录、当前任务材料及 `profile.video.broll.material_roots`。本地素材不足时，通过当前可用的搜索/浏览能力补充相关实拍、官方公开影像、新闻报道或授权素材库，沿用已有授权。

- 板书、屏幕和指物镜头先从进入到退出连续查看，被人挡住的首帧作为截断上界。移动到目标前后都要看见目标，按主音轨连续回切。
- 查看候选的起、中、末帧和连续运动，选择语义贴切、主体明确、细节清楚、具有空间规模或实际变化的片段。清洁母带优先，保留必要来源标识并避开旧字幕遮挡。
- 记录来源页面、发布者、日期、地点/主体确认依据和使用许可或授权信息，下载素材另记录本地路径与哈希。公开可见素材的复用条件按其实际条款核对，付费获取按现有费用授权执行。
- 热点事件核查对应年份、城市、会场与阶段。未来活动优先选有依据的筹备现场或场馆实景，历史会议片段按历史资料标注。具体场馆未确认时选已证实的城市、活动或筹备画面，并准确描述其身份。
- 企业总部及园区核对名称和所在地，区分总部、分部、旧址与泛化城市镜头。新闻原有字幕若会干扰口播，调整选段或构图，保留判断其时间和身份所需的信息。
- 有优质相关视频时优先使用视频。真实照片可作为补充，适度推拉以保持主体完整。事实性现场选用真实影像，生成画面按示意性质标明并遵守本轮素材要求。
- 检索后仍缺合适素材时，记录检索范围和具体缺口，在该段保留真人并继续其他段落。访问失败先尝试可用来源，真实失败写入记录。

## 3. 开场与全片节奏

优先在最终成片第 **2～3 秒**切入首个强相关视频。开头先用原声建立主题，在最早可理解的语义点进入能迅速辨认对象的实景或航拍。用户指定更早切入时按其要求安排。第一镜可采用有规模感、明显运动或独特主体的画面，保留足够时长让观众看清。

切入时点以最终输出时间轴计算，包含删词、停顿、重排与变速的结果。缺少相关素材或讲述尚未进入可展示内容时，使用第一个有效匹配点并记录实际时点和原因。开场吸引力同时核对原声、标题、字幕和镜头。

后续按讲述密度编排。

- 城市和科技概述适合多镜头快速切换。可从约 1～2 秒一镜试排，再按运动、信息量和口播节拍调整。辨认地标、观看航拍推进或理解具体操作时适当延长。
- 优先组织不同尺度和内容的连续镜头，例如城市全景、企业园区、技术运行、应用与人群。通过实际动作和空间变化表现氛围，保证相邻镜头提供新信息。
- 用户指定“从这里到某个词前”时，以原声词界定位展示起止，覆盖整个要求区间，并在结束锚点准确回切。
- 在观点强调、解释转折、总结与末句适时回到真人。真人回切保留可感知的连续时段，消除几帧漏排造成的闪回。最后一个展示段结束后，真人连续讲完完整收束语。
- 为当前批次维护素材使用表，选段前读取同批已采用镜头及当前可查的近期成片映射；逐项比较源身份、实际源区间和画面内容。不同文件名或哈希也可能是同一母带的副本或重编码，不能据此认定镜头不同。近期记录不可用时写明已核查范围，不宣称完成跨批去重。
- 语义贴切的候选中优先采用未使用的原始镜头或不同操作、成果页面。复用同一源视频时，默认选择不重叠且画面内容明显不同的源区间，查看所选区间的起、中、末帧及连续变化；只平移起点几帧、换裁切、变速或调色不算有效换镜头。同一长镜头即使区间不重叠，若仍停在相同页面、主体和动作上，也应换到另一个操作阶段或更换素材。
- 每次采用后立即登记作品/版本、源身份与哈希、源起止秒、输出范围、可辨认的页面/动作、与既有使用的重叠情况及采用理由，再为下一条选段。不得仅在每条内部检查，也不得等整批渲染后才发现重复。用户明确“素材不要一样”时采用不同原始镜头；明确“起码换截取位置”时至少满足区间不重叠与内容可辨认变化。只有叙事需要回顾或用户指定复用时记录具体理由，不能默认循环同一段。
- 可用素材不足时先补充检索相关镜头或同源的其他有效段落；仍无合适内容时保留真人并记录缺口，不用重复镜头凑展示时长。
- 操作录屏按可理解的实际变化剪选，清除加载、空白和无信息等待。具体机制保留足够观察时间，长讲解可换相关操作或回到真人。
- 图片和对比图用独立图层、裁切窗口及缓慢缩放，主体与文字完整，信息密集的图留足阅读时间。

## 4. 时间轴、声音与标题

口播为主时间轴。纯换画面时冻结原声音轨、口播保留区间、倍速、字幕正文与时间，仅调整所要求的展示及标题退场。涉及删词、停顿或语速时，先落实原声 EDL，再重映射展示、字幕和标题。截图上的秒数用于查找位置，实际切点以词时和真实画面确认。

从原片一次应用目标语速，记录现有底片的已剪/已变速状态。展示视频速度独立计算，按其运动和理解需要决定。

每段展示记录稳定来源 ID、路径/URL与哈希、源身份、源起止秒、既有速度、输出起止帧、实际倍率、裁切锚点及匹配理由。新闻或事件素材同时保留第 2 节的身份与来源信息。源区间和输出区间均使用半开边界。

实际展示倍率为 `(源结束秒 - 源开始秒) / ((输出结束帧 - 输出开始帧) / 输出帧率)`。

核对段落边界、重叠、越界和有意的真人回切。口播字幕按主时间轴连续显示，展示视频源音频默认静音。配乐、现场声和音效按本轮要求使用，避免干扰主口播。

开头标题的退场帧取既定结束帧与首次展示起始帧的较早者，随后回到真人时维持退场状态。用户另有要求时按其时段设置。检查退场前一帧与退场首帧，独立封面按封面规则处理。

## 5. 画幅、色彩与合成

- 逐源核对旋转、有效分辨率、帧率和 HDR/SDR，按本源完成必要的 SDR BT.709 转换。
- 竖屏裁切优先保住地标轮廓、运动方向、人物或操作主体，保持纵横比及字幕可读。横幅主体过宽时采用完整呈现或合理构图，查看实际输出中的辨识度。
- 从清洁源合成，最终一次有损编码。多段高分辨率输入需要缓存时，使用有源哈希、命令哈希和帧数记录的无损缓存，核验色彩参数及实际像素转换。
- 需要匹配同批响度时测量整合响度、真峰值和动态，依据授权音轨调整并复测。纯画面修订直接复用已确认音轨。
- 输出使用本轮新路径，核对创建时间、大小、哈希、实际帧数与画面。缓存复用须匹配源、区间、速度、样式和 EDL。

## 6. 验收与归档

从真实导出按匹配表逐段验收，将结果纳入已有内容、节奏、排版、画质和技术五项结论。

1. 连看前五秒及前十秒，记录首镜实际时点、2～3 秒目标的执行情况、主题可辨认性、镜头运动和与原声的配合。
2. 检查每个重点段落的实际画面、指定起止词、全部回切和结尾。核对城市、企业、会场、事件年份与来源，检查相关性、代表性、信息变化和连续观看的节奏。
3. 将真实成片展示段与使用表及已核查的近期映射并排复核，逐项核销重复或重叠候选，记录“已换不同素材／已换不重叠且内容不同的选段／有明确理由复用／素材缺口回真人”。文件名、哈希、时间码不同及静帧相似度只能辅助，实际画面仍相同的候选不得标为差异化通过。同步更新采用表，供下一条或下一批检索。
4. 对照 EDL、字幕、展示计划、标题退场和最终文件的版本。纯画面修订比对解码 PCM，语速或音量修改比对新的授权音轨。完整解码并验收帧数、时长、同步、色彩、清晰度和裁切。
5. 读取预览页面实际 `video src`，核对媒体哈希与 Range 响应，刷新后抽查本轮修改位置。实际听审按独立状态记录。
6. 确认归档时把完整成片稿、字幕、原声及展示映射、素材来源/哈希、修订记录和验证边界合入自包含审查稿。核验媒体与知识交接后，按归档流程清理本批下载缓存、候选和过程工程，共享素材按既有归属管理。
