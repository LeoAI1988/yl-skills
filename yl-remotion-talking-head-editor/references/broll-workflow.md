# 口播中插入演示素材

完整口播剪辑默认执行本流程。用素材库中的录屏、产品演示、工作台、成果视频及已有说明图片配合对应讲解，保留原声的完整讲述。用户指定的本轮范围和插入位置优先。

## 0. 每条先检索并匹配画面

从本次指定的展示目录和 `profile.video.broll.material_roots` 查找素材，相关路径留在个人配置。已有课程画面可在本次指定的课程目录补充检索。配置缺省时检查当前任务已提供的素材，记录实际检索范围。

1. 按口播逐段提取对象、操作、结果和比喻，重点检查开头及所有可展示的讲解段。建立素材联络表，优先用清洁母带，查看候选的实际画面和连续操作。
2. 为每个讲解段记录原句/源词时、对应界面或动作、候选路径/源区间、匹配理由及采用决定。已检索且确无合适素材时，记录原因并保留真人。素材目录不可用时记录访问问题，继续可做部分。
3. 对有合适素材的讲解段均安排展示，从候选中选最贴切的片段。相邻同义讲解可合并为一个展示段，镜头数量由内容决定。优先级为语义对应、画面可辨认、有效变化、同批差异化。
4. 尽量让首个相关画面在成片开头约 3 秒出现，以吸引停留，按最终输出时间轴定位。有匹配机会可更早切入，开头没有合适素材时在后续首个匹配点切入，并记录实际时间与原因。首个画面须能看清所讲内容。
5. 后续每到适合展示的讲解继续穿插。多场景概述可快速切换工作流，具体操作或因果解释按理解所需留足时间。末句或完整收束语回到真人口播，保持连续到最后一个有内容的视频帧。

阶段 1 完成匹配表，阶段 2 在原声 EDL 稳定后落到展示轨，最终合成后按第 5 节验收。全自动自行完成选择，半自动沿用既有两个审核节点。用户限定纯口播或仅改已有成片某一层时，按该范围执行。

## 1. 锁定范围和两条时间轴

- 明确哪条口播、从哪句的哪一字开始展示、中间回切位置及末句真人收束区间。截图时间仅用于定位，按最终口播词时和真实画面确定切点。
- 口播是主时间轴。纯换画面时冻结原声音轨、口播保留区间、倍速、字幕正文与时间；标题退场、展示选段及缩放只在授权范围内解冻。
- 同时要求删词、停顿或改语速时，先落实原声 EDL，再排展示。后续改变原声时间轴必须重新映射字幕、展示切点和标题，不可直接套用旧成片秒数。
- 原片速度一次应用。例如目标倍率是 `r`，直接以原片音视频执行 `r`；不能把已有成片再乘同一倍率。展示视频的速度单独计算，不由口播倍率代替。
- 用户允许成片与母带任选时，可在授权目录中选择；优先使用没有旧字幕、标题、配乐或水印的清洁源。来源是相机母带还是历史导出、既有速度是否已知，分别记录。

## 2. 按语义选取实际变化

先查看素材联络表，再检查候选的起、中、末画面，建立“讲述内容 → 需要证明的界面/动作 → 素材区间”的小表。讲到项目管理就展示项目与任务，讲到引用就展示原文及关系，不能仅用同一产品的任意画面填满时间。

- 对不同工作类型的介绍，可用数个短镜头快速建立范围；解释具体机制时给对应界面足够辨认时间。镜头长短按信息量与口播节奏决定，不机械使用本次样片时长。
- 同一条前后讲到相近内容及同批多条视频，优先使用不同操作、源区间和镜头组合。维护同批素材使用表，比较实际源区间和画面内容，允许少量必要重叠。发现整段或大部分镜头雷同时重新选段，有语义必要的复用写明理由。
- 对已有对比图，可将上下或左右两幅图分别作为独立图层，在各自裁切窗口内缓慢放大，保持主体和关键信息完整。对信息密集的流程/关卡图留足阅读时间，避免缩放裁字。用户指定首尾图片时，以所指展示段为范围安排，中间接对应操作画面，视频末尾仍按本轮口播收束要求执行。
- 删除加载、空白等待、没有信息变化的长停留；需要继续讲述时跳到后续操作、换另一段相关展示，或切回真人数秒。
- 用户要求展示更快时，优先加快真实滚动、选择、打开卡片、任务响应等变化。轻微推拉或移动裁切只补充构图，不能把一张静止页面伪装为功能演示。
- 在观点强调、解释转折、总结或结尾适时切回真人。回切应有可感知的连续时段，避免因相邻展示段之间漏排几帧而闪回真人。
- 缩放以有效界面和文字可读为先，避免只放大键盘、裁掉关键按钮或遮挡演示对象。保持原始纵横比，记录裁切锚点。

## 3. 帧级映射和标题

每段展示至少记录：稳定来源 ID/路径及哈希、源起止秒、输出起止帧、源身份、既有速度说明、实际画面倍率、缩放/裁切及匹配理由。源区间和输出区间均使用半开边界。

展示实际倍率：`(源结束秒 - 源开始秒) / ((输出结束帧 - 输出开始帧) / 输出帧率)`。

检查输出段不重叠、不越界，间隙确为有意的口播回切。字幕跟随保留的讲述，不跟随展示源中的旧字幕。所有展示源音频默认静音，仅保留主口播；配乐另按用户要求处理。

除用户另有要求，开头标题最迟在首次切入展示的同一帧消失，实际退场点取既定标题结束帧与首个展示起始帧的较早者。以后切回真人保持标题退场状态。将标题退场作为明确输出帧写入文字层，检查退场前一帧和退场首帧。展示期间字幕继续跟随口播，独立封面沿用封面规则。

修改口播速度后，用源词时或源到新输出的映射计算切点，并核对实际输出总帧数。按旧输出帧数的倍率换算只能作为候选，需检查帧量化误差和真实词尾。

## 4. 色彩、响度与合成

- 每个源独立检查旋转、有效分辨率、帧率及 HDR/SDR。HLG 等 HDR 源先实际转换到 SDR BT.709 再叠加文字；只重写色彩标签不构成转换。不要把某个源的转换或旋转统一套到全部素材。
- 需要与同批视频音量接近时，测量参考和目标的整合响度、真峰值与动态范围。以参考中位响度决定增益，再测量最终输出并检查峰值；不为匹配音量无依据地压缩所有动态，不削波。口播和展示音轨不可叠成双重人声。
- 从清洁原片合成，一次最终有损编码。资源足够时可直接拼接；多段高分辨率/HDR输入导致内存压力时，逐段生成有来源/命令哈希的无损缓存，再顺序拼接和一次最终编码。缓存格式可能丢失色彩元数据，保留像素转换依据并在最终编码前正确设置帧色彩参数、码流及容器标记。
- 每个缓存验证帧数、源哈希、区间和实际倍率，不能仅凭存在就复用。最终输出使用新版本名并先确认目标不存在。某些编码器拒绝覆盖仍可能返回成功；核对创建时间、大小、哈希、实际帧和真实画面，不只看退出码。

## 5. 从真实导出验收

逐条核对匹配表与真实成片。每个已选段已插入、每个未采用段有检索依据；记录首个展示时间及偏离约 3 秒目标的原因；核查同批镜头组合及源区间复用；最后一段真人画面覆盖完整收束语并持续到结尾。这些检查纳入既有内容、节奏和排版验收。

1. 核对口播 EDL、音轨、字幕、展示计划、标题退场和最终视频对应同一版本。纯画面修订比较解码 PCM；改速度或音量则比较新的授权音轨，并核验从原片一次应用的参数。
2. 抽查每段展示的实际输出、全部回切、标题退出相邻帧及结尾，对照源画面。检查语义匹配、可读性、缩放、加载等待和短闪回；像素匹配只能证明采用了所选片段，不能证明选择合理。
3. 对要求有持续变化的展示检查连续画面。静帧/冻结检测辅助找线索，仍要区分真实页面等待与有效操作；不能用轻微摄影抖动自动判定内容在变化。
4. 核验全片解码、分辨率、CFR/PTS、帧数、时长、音画同步、峰值及 BT.709 解码帧/码流/容器。看实际字形、人物和界面细节，不以高码率代替画质对照。
5. 新版预览读取实际 `video src`、文件哈希和区间下载；网页写新版但仍播放旧文件视为失败。原声听审不可用时保留未完成状态，ASR、波形和技术结果不能冒充听审。
6. 用户确认归档后，把最终原声及展示映射、源哈希、字幕全文、审核修订和验证边界合入自包含审查稿。共享演示素材原位复用并保留来源引用；核验媒体与知识交接后清理本批可再生缓存，按归档 Skill 的范围处理历轮工程。
