# 真人口播 Remotion 剪辑

以本人原片、原声、措辞和完整论述为主干，按本轮范围完成剪辑。读取 [个人配置约定](../yl-toolbox/references/profile.md) 中相关说明、工具、素材库和视觉配置。环境准备见 [环境与参考](references/approved-example.md)。

## 范围与模式

先确定本次视频、交付物和已有确认状态。用户只要剪口误气口、纯口播或某一层修改时，执行对应范围。课程录屏交给课程剪辑流程，数字人和配音按各自任务处理。

新剪辑任务未指定模式时询问全自动或半自动，得到选择后进入剪辑。明确“直接给最终结果、不用问我”视为全自动，明确先审逐字稿再审剪辑版视为半自动。同一任务沿用已选模式。“先记录”“等我确认”“先不要开拍”等本轮要求优先。

| 模式 | 审核与交付 |
| --- | --- |
| 全自动 | 自主完成 GATE-1 结构审核、GATE-2 剪辑审核及本次增强、验收，连续做到最终交付。 |
| 半自动 | 一并提交本次全部视频的完整逐字稿修改方案，经用户确认后精剪并交付未增强剪辑版，再经用户确认后开拍增强。明确分批时按约定批次执行。 |

两模式使用同一质量标准，停顿、正字和剪点由执行者定位、裁决并落实。常规判断在已有授权内完成。技能维护和只读审查直接处理相应文件。

## 执行清单与规则归属

为每条视频维护一份本轮清单，记录实际动作、证据和状态。以下阶段即为清单，按用户范围标记适用项。待处理问题继续解决，真实素材或能力缺失时注明具体缺项并继续可做部分。

- 内容删留、开头与调序依据 [内容分析](references/content-analysis.md)。
- 转写覆盖和真实成片复审依据 [转写覆盖与成片复审](references/final-review.md)。
- 字词定位、审查稿、原声与 EDL 依据 [剪辑工作流](references/editing-workflow.md)，停顿参数统一读取 [pause-policy.json](references/pause-policy.json)。
- 相关实景、航拍、新闻和录屏的选材、节奏与映射依据 [相关视频与演示素材插入](references/broll-workflow.md)。
- 视觉参数依据 [视觉标准](references/visual-style.md)，生成器复用与批量导出依据 [执行契约](references/execution-contract.md)。
- 最终结论依据 [五项验收](references/acceptance.md)，每项绑定本轮产物和实际复核证据。

## 阶段 1　完整原稿与剪辑方案

1. 发现源片、参考、字幕、EDL、工程及已确认版本，记录源片和本轮需保护文件的哈希。核查有效分辨率、旋转、帧率/PTS、HDR、音轨和现有倍速。
2. 全文转写保留原始 ASR。比较同一源时间轴的 VAD 与 ASR 覆盖，对漏覆盖、重复、残句及长词疑点做独立小窗口复核。项目热词表来自本次材料或维护中的项目配置，正字有原声或可见名称依据。
3. 建立段落依赖、具体删留、开头、标题和顺序方案。原序适合时写明依据，需调序时验证指代、因果及前后承接。无信息重复、错话、失败起句落实到具体字词，保留有功能的强调、递进和完整语气。
4. 按 B-roll 流程逐段匹配可视对象和重点段落，兼顾本地素材与可用的公开实景来源。优先为成片第 2～3 秒安排能看清主题的强相关镜头，规划后续展示及真人收束。选段前核查同批及可查近期使用表，优先换素材；同源复用须换不重叠且内容明显不同的区间。匹配表记录原句、来源、选段、理由、首个切入和差异复核结果，每次采用后更新。
5. 每条产出完整原始逐字稿及调整标记稿。删除用删除线，调序注明来去处，ASR 纠字写出原识别、修正及依据。停顿在内部声学清单处理。GATE-1 按所选模式完成确认。

## 阶段 2　统一时间轴精剪与包装

1. 将结构重排、整句/词字删除和停顿收紧落实同一 EDL。候选逐项归为已剪并复核、有依据保留或误报，核查导出时间轴确实发生对应变化。
2. 扫描全片句间、词内及前五秒，按真实发音边界保留完整字音、连读和必要语气。单独精修最终开头，再连看前十秒验证承接。复制开头时使用已修保留区间并区分原段与前置段的字幕映射。
3. 从原始时间轴一次应用要求的语速，记录底片既有速度及源到输出映射。按稳定的口播 EDL 编排展示，分别计算展示素材速度，保持原声连续、字幕同步。
4. 按当前参考和个人视觉配置渲染固定字幕与标题，长句按语义分页或换行。小数、版本号、百分数与数字单位完整排版，生成前合并 ASR 碎片，生成后检查全部相邻页及行边界，逐处修复数字被拆开的错误。相对位置/比例修改换算为唯一配置中的绝对值，后续读取该值。真实字体、字形、基线及缓存身份按视觉契约校验。
5. 重点文字卡片默认 0 张，明确要求时全片选择 1～3 张。相关实景、录屏、截图按展示轨管理。封面按本轮要求制作并独立交付。
6. 按 [渲染与画质](references/rendering.md) 从有效源片合成，保留有效分辨率及细节，使用最终一次有损编码。正式文件采用本轮新路径，核对实际哈希、帧数、时长和画面。

## 阶段 3　剪辑版审核

在 GATE-2 中完成真实成片复审。全片重扫空白及重复，复听前五秒、所有风险切点和全片原声，逐项核销必剪清单。展示验收覆盖开场吸引力、语义代表性、连续变化、同批差异化、回切、标题退场及结尾。

内容、原声节奏、排版、画质、技术分别记录 PASS / FAIL / PENDING 及证据。机器检测和实际听审各记其结果。无法听审时如实保留未完成状态，继续其余工作。可修问题返回阶段 2 直至处置完成。

半自动交付明确标记的未增强剪辑版并等待约定确认，全自动内部通过后继续增强。本阶段的 GATE-3 复审名称沿用参考文档，属于 GATE-2 内的检查。

## 阶段 4　增强与最终交付

1. 按 [开拍画质增强](references/kaipai-enhance.md) 核对授权、能力和色彩。需要的 HDR→SDR 转换实际作用于像素，API 输入、原始回片与最终文件的解码帧、码流和容器色彩一致。
2. 提交同一 EDL 的无文字底片，保存匹配的无字增强回片，本地合成独立标题、字幕及展示素材，复用原剪辑音轨。新接入先验证短样。按实际对照判断肤色、眼镜、发丝、运动与高光细节。
3. 对最终导出重做五项验收。修复 FAIL，完成可继续处理的 PENDING。真实能力缺失导致仍未完成时交代具体状态，用户确认与执行者验收分别记录。
4. 提供本轮 MP4、字幕、EDL、审查稿、确认记录和要求的封面。按 [成片文字稿归档](references/final-transcript-archive.md) 导出完整成片口播稿，格式按用户约定，默认 Markdown。
5. 核验预览页面实际 `video src`、文件哈希及视频区间下载，确保链接对应本轮文件。旧页面缓存问题按 [修订操作与证据合同](references/revision-contract.md) 处理。

## 局部修订

先读 [修订操作与证据合同](references/revision-contract.md)，将反馈识别为原声删除、字幕纠字、复制、移动、倍速、画面或封面修改，按授权范围执行。

纯样式或纯展示修改冻结口播 EDL、语速、字幕正文/时间及已确认音轨，复用匹配的无字增强底片。仅本地重新合成并验证 AAC/PCM 一致性。涉及删词、语速或调序时，重建源到输出映射，并同步字幕、展示和标题。原底片不可用时按现有源材料重导，记录新版本的实际增强状态及新增调用授权。

反馈问题逐项对应操作、源区间、最终帧和复核结果。确认前保留本轮回改所需版本，确认后的正式保留集与清理按下节执行。

## 归档与清理

验收与预览结束后按 [视频归档](../yl-video-archive/SKILL.md) 的 [去重收尾](../yl-video-archive/references/completion-cleanup.md) 处理本批可再生缓存及未采用副本。

用户确认成果并要求归档时，完成媒体归档和最终文稿本地入库、蒸馏、表达、关系、检索验收。以自包含审查稿保留原稿、实际删留、完整成片稿、素材来源、最终映射及验证边界，核对正式保留集后清除本批历轮工程和临时文件。原件、确认成片、封面及明确要求的交付按归档规则保留。

知识云同步和平台发布分别按相应授权执行。独立磁盘排查按 [yl-anti-entropy](../yl-anti-entropy/SKILL.md) 处理。
