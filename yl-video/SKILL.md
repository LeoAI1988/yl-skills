# yl 视频

本 Skill 是 `yl-media` 下的视频子入口。尚未经过本次自媒体分流时，先读同级 `yl-media/SKILL.md` 的路由规则，再回到本分支；已分流则直接执行，不反复回跳。保留已选剪辑/封面模式，不因路由要求用户重复授权。

先按 [个人配置约定](../yl-toolbox/references/profile.md) 读取有关素材、工具与偏好的外部说明；已确认设置直接复用。

根据用户现有材料与目标选择工具：

| 任务 | 调用 |
| --- | --- |
| 已定稿文章或观点稿转无真人出镜的旁白科普/图解视频，包含声音试听、分镜、字幕、配套封面和局部回改 | `yl-article-narration-video`，以原文与用户批准的视频版为真源，封面与图解共同服务论述；用户明确不要封面时除外 |
| 本人原稿或历史内容改成数字分身双人问答、师生剧情，不用真人出镜；以及生成素材的节奏、字幕与封面回改 | `yl-ai-dialogue-video`，按原话分镜、统一形象、分段生成并本地精剪；与真人同稿多拍混剪区分 |
| 课程、教程、软件实操及录屏加讲师窗口的演示长视频；按课轻剪、字幕、倍速及播放音量 | `yl-course-video-editor`，按教学过程保留演示，默认本地 FFmpeg |
| 长视频切成多条独立短视频、批量切片或切片后补标题/遮盖 | `yl-remotion-video-slicer`，默认Remotion；依目标优先匹配，不由横屏尺寸改送访谈精剪 |
| 自动剪辑：剪真人短口播，口误、停顿、字幕及成片 | `yl-remotion-talking-head-editor` |
| 历史爆款/成交文案同稿多拍，找对应视频、母带并按留存数据重新混剪 | `yl-viral-video-remixer`，至少两次独立拍摄，不把同一 take 的不同导出当多拍 |
| 自动剪辑：剪横屏访谈、个人 IP 独白、长内容复盘 | `yl-chatcut-landscape-interview-editor`，主工具为 ChatCut Desktop |
| 黑底白字封面，可选黄字强调 | `yl-short-video-covers` 的 `black-white` 模式 |
| 半透明封面，不叠加头像 | `yl-short-video-covers` 的 `translucent` 模式 |
| 其他视频与封面都要 | 剪辑时同步确定封面方向，再用成片文字稿和本次素材完成封面 |
| 成片、母带归档或本批剪辑收尾清理 | `yl-video-archive` |

“改完归档”先由相应剪辑成员完成明确修改，再调用归档成员；已有确认版本直接归档。只归档不启动剪辑、倍速或开拍；用户要求归档已定稿视频时，自动衔接最终文稿的本地入库、蒸馏、表达与检索验收；云端写入和发布仍须另有授权。

用户已确认成果并说“归档”时，默认保留正式初始文件、最终成果及明确要求的交付，直接清除本批历轮工程与过程文件；不把它们搬入另一套“工程归档”。执行 [确认归档清场](../yl-video-archive/references/completion-cleanup.md#用户确认成果并说归档时)，不因一般“保留所需工程/增强母带”条款额外留一套中间工程。

剪辑默认以 [去重收尾](../yl-video-archive/references/completion-cleanup.md) 结束：验收与本轮预览完成后，调用归档成员清理本批临时副本、未采用导出及项目可再生构建/渲染缓存，包括 `node_modules/.cache/webpack`，不等用户另提清理，也不依赖个人配置开关。保留最终成果、唯一来源、必要工程及仍需回改/听审的材料，不扩展到历史批次或其他任务的共享文件。

已点名任务或模式就直接继续；仅说“做封面”且看不出风格时，说明两种模式并让用户选择。用户授权自行选择时根据素材和用途决定。封面内部的准确模式名、参数及选择规则以成员为准。

自动剪辑按产物分为文章旁白图解、完整课程/演示、多条独立切片、单条短口播精剪、横屏访谈/长独白精剪。文章转视频走新成员，不因“无真人出镜”误入数字人对话；多条切片先进入切片成员；单条横屏访谈精剪沿用ChatCut成员，不加载旧横屏Remotion适配。不能仅凭横向尺寸判断，结合目标和明确工具选择；用户指定Remotion的多条切片不要求ChatCut登录。封面可单独调用；文章旁白图解任务则随视频一起完成封面。归档是收尾能力。

完整读取同级对应成员的 `SKILL.md` 和当前模式所需参考；缺少成员就说明如何补装，不把分类入口当成执行能力。剪辑的全自动／半自动选择由剪辑成员处理，本入口复用已经明确的选择。

剪辑工具负责最终音视频验收，封面制作负责文案、构图和图片验收；不因组合而跳过必做项。原视频、原声音轨、既有批准版本及隐私边界保持可追溯。封面与视频共用本次完整文字稿，不重复转写同一素材。

只要求封面时不主动剪视频；文章旁白图解视频默认包含封面，其他剪辑任务的封面范围按用户任务和对应成员规则判断。安装不等于配置第三方服务或授予素材上传、平台发布权限。

## 防熵增收尾

唯一初始母带与唯一确认成片、必要说明和指定交付保留；日常制作/发布不备份旧输出。用户确认结果后自动完成本批工程清场；原始素材提供重剪兜底，不为以后可能回改留一套工程。

通用原则与独立磁盘排查汇总见 [yl-anti-entropy](../yl-anti-entropy/SKILL.md)；本成员上面的专项归档/清理步骤继续保留。
