# yl 视频

本 Skill 是 `yl-media` 下的视频子入口。尚未经过本次自媒体分流时，先读同级 `yl-media/SKILL.md` 的路由规则，再回到本分支；已分流则直接执行，不反复回跳。保留已选剪辑/封面模式，不因路由要求用户重复授权。

先按 [个人配置约定](../yl-toolbox/references/profile.md) 读取有关素材、工具与偏好的外部说明；已确认设置直接复用。

根据用户现有材料与目标选择工具：

| 任务 | 调用 |
| --- | --- |
| 课程、教程、软件实操及录屏加讲师窗口的演示长视频；按课轻剪、字幕、倍速及播放音量 | `yl-course-video-editor`，按教学过程保留演示，默认本地 FFmpeg |
| 长视频切成多条独立短视频、批量切片或切片后补标题/遮盖 | `yl-remotion-video-slicer`，默认Remotion；依目标优先匹配，不由横屏尺寸改送访谈精剪 |
| 自动剪辑：剪真人短口播，口误、停顿、字幕及成片 | `yl-remotion-talking-head-editor` |
| 自动剪辑：剪横屏访谈、个人 IP 独白、长内容复盘 | `yl-chatcut-landscape-interview-editor`，主工具为 ChatCut Desktop |
| 黑底白字封面，可选黄字强调 | `yl-short-video-covers` 的 `black-white` 模式 |
| 半透明封面，不叠加头像 | `yl-short-video-covers` 的 `translucent` 模式 |
| 视频与封面都要 | 先剪辑，再用成片文字稿和本次素材制作封面 |
| 成片、母带归档或本批剪辑收尾清理 | `yl-video-archive` |

“改完归档”先由相应剪辑成员完成明确修改，再调用归档成员；已有确认版本直接归档。只归档不启动剪辑、倍速或开拍；媒体文件归档与文字稿入内容库分别按授权执行。

已点名任务或模式就直接继续；仅说“做封面”且看不出风格时，说明两种模式并让用户选择。用户授权自行选择时根据素材和用途决定。封面内部的准确模式名、参数及选择规则以成员为准。

自动剪辑按产物分为完整课程/演示、多条独立切片、单条短口播精剪、横屏访谈/长独白精剪。多条切片先进入切片成员；单条横屏访谈精剪沿用ChatCut成员，不加载旧横屏Remotion适配。不能仅凭横向尺寸判断，结合目标和明确工具选择；用户指定Remotion的多条切片不要求ChatCut登录。封面和归档分别是独立的包装、收尾能力。

完整读取同级对应成员的 `SKILL.md` 和当前模式所需参考；缺少成员就说明如何补装，不把分类入口当成执行能力。剪辑的全自动／半自动选择由剪辑成员处理，本入口复用已经明确的选择。

剪辑工具负责最终音视频验收，封面工具负责文案、构图和图片验收；不因组合而跳过必做项。原视频、原声音轨、既有批准版本及隐私边界保持可追溯。两个工具共用本次完整文字稿，不重复转写同一素材。

只要求封面时不主动剪视频；只要求剪辑时，封面范围按用户任务和剪辑成员规则判断。安装不等于配置第三方服务或授予素材上传、平台发布权限。
