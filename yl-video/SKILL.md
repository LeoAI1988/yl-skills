# yl 视频

本 Skill 是 `yl-media` 下的视频子入口。尚未经过本次自媒体分流时，先读同级 `yl-media/SKILL.md` 的路由规则，再回到本分支；已分流则直接执行，不反复回跳。保留已选剪辑/封面模式，不因路由要求用户重复授权。

先按 [个人配置约定](../yl-toolbox/references/profile.md) 读取有关素材、工具与偏好的外部说明；已确认设置直接复用。

当次指定或个人设置优先使用 OpenAI API 额度时，同时读取 [API 额度执行方法](../yl-openai-api-credits/SKILL.md)。转写、分析、翻译、图像素材和合成按所需产物选择通道，将取回的文件接入本次剪辑或封面任务。

先明确交付一条还是多条、要不要改讲述顺序、有哪些画面必须保留，以及要做哪些文字层。画幅决定排法，剪辑工具和审核模式沿用本次约定。

| 用户要什么 | 使用哪些能力 |
| --- | --- |
| 只剪错词、气口、原序口播、调整语速或原声 | [口播基础剪辑](../yl-remotion-talking-head-editor/SKILL.md)。同一套用于长短、横竖素材。 |
| 一篇长稿重新梳理成一条有传播力的论证 | [长视频文案逻辑重构](../yl-long-video-script-structure/SKILL.md)。只要方案就交带源位的顺读稿；要成片时接入口播基础剪辑。 |
| 调字幕或画内标题 | [视频字幕标题版式](../yl-video-text-layout/SKILL.md)，按最终画布选横屏或竖屏。可直接处理已有视频。 |
| 用指定参考风格把口播做成横屏人物窗与动态图解，或从参考录屏建立这种预设 | [横屏人物图解风格](../yl-presenter-board-style/SKILL.md)提取有效画幅，按个人预设给稳定的口播时间轴安排大人像、信息板、演示和双语字幕。 |
| 随讲解或画面加重点标注、数字对比、流程关系 | [视频重点标注图解](../yl-video-emphasis-graphics/SKILL.md)，横屏侧区、竖屏纵向编排，按实际占用选择。可单用在无口播素材。 |
| 按原序连续切片、按现有选段出多条 | [连续或指定切片](../yl-remotion-video-slicer/SKILL.md)，每条单独时间轴；有人声且需要精剪时用口播基础。 |
| 长素材跨段重组为多个低重叠主题 | [多主题成组剪辑](../yl-long-video-multi-topic-editor/SKILL.md)划主题、分配共用素材和管理批次；用逻辑重构梳理各条，需要精剪时复用口播基础。 |
| 完整课程、录屏教学 | [课程剪辑](../yl-course-video-editor/SKILL.md)保护演示等待、操作因果、播放声和讲师窗口，按要求处理讲述、字幕与图解。 |
| 多人访谈、对谈，或明确用 ChatCut 剪 | [访谈及 ChatCut 工程](../yl-chatcut-landscape-interview-editor/SKILL.md)管理说话人、问答交接、机位和宿主工程；共用原声精剪。横屏独白按普通口播进入。 |
| 定稿文章做旁白科普；本人稿做数字分身双人剧情 | 分别使用 [文章旁白图解](../yl-article-narration-video/SKILL.md)和[数字分身剧情](../yl-ai-dialogue-video/SKILL.md)，保留原有声音、分镜、身份及合成流程。 |
| 同稿多次独立拍摄，按历史数据混剪 | [历史爆款混剪](../yl-viral-video-remixer/SKILL.md)匹配独立 take，复用原声及已选视觉层。 |
| 独立封面或成片附封面 | [短视频封面](../yl-short-video-covers/SKILL.md)读取已定文稿与素材，按已选风格制作科技大字（黑底）、实景大字或半透明原帧。 |
| 成片、母带归档或清理本批 | [视频归档](../yl-video-archive/SKILL.md)接收已确认文件。 |

组合时先把原稿和已有确认交给需要的内容模块，再由剪辑成员锁定源到成片的时间映射。版式与图解并行使用同一画布、最终时码和各自占用区域；声音和画面增强按约定执行，最后一次合成。局部改样式复用既有底片和音轨，已有字幕的素材保留其原始同步关系。只改一层就交付该层或指定的合成片。

“改完归档”先由相应剪辑成员完成明确修改，再调用归档成员；已有确认版本直接归档。只归档不启动剪辑、倍速或开拍；用户要求归档已定稿视频时，自动衔接最终文稿的本地入库、蒸馏、表达与检索验收；云端写入和发布仍须另有授权。

用户已确认成果并说“归档”时，默认保留正式初始文件、最终成果及明确要求的交付，直接清除本批历轮工程与过程文件；不把它们搬入另一套“工程归档”。执行 [确认归档清场](../yl-video-archive/references/completion-cleanup.md#用户确认成果并说归档时)，不因一般“保留所需工程/增强母带”条款额外留一套中间工程。

剪辑默认以 [去重收尾](../yl-video-archive/references/completion-cleanup.md) 结束：验收与本轮预览完成后，调用归档成员清理本批临时副本、未采用导出及项目可再生构建/渲染缓存，包括 `node_modules/.cache/webpack`，不等用户另提清理，也不依赖个人配置开关。保留最终成果、唯一来源、必要工程及仍需回改/听审的材料，不扩展到历史批次或其他任务的共享文件。

已点名任务或模式就直接继续；仅说“做封面”且看不出风格时，按封面成员的风格选择规则办理。用户授权自行选择时根据素材和用途决定。封面内部的准确模式名、参数及选择规则以成员为准。

完整读取同级对应成员的 `SKILL.md` 和当前模式所需参考；缺少成员就说明如何补装，不把分类入口当成执行能力。剪辑的全自动／半自动选择由剪辑成员处理，本入口复用已经明确的选择。

剪辑工具负责最终音视频验收，封面制作负责文案、构图和图片验收；不因组合而跳过必做项。原视频、原声音轨、既有批准版本及隐私边界保持可追溯。封面与视频共用本次完整文字稿，不重复转写同一素材。

只要求封面时不主动剪视频；文章旁白图解视频默认包含封面，其他剪辑任务的封面范围按用户任务和对应成员规则判断。安装不等于配置第三方服务或授予素材上传、平台发布权限。

## 防熵增收尾

唯一初始母带与唯一确认成片、必要说明和指定交付保留；日常制作/发布不备份旧输出。用户确认结果后自动完成本批工程清场；原始素材提供重剪兜底，不为以后可能回改留一套工程。

通用原则与独立磁盘排查汇总见 [yl-anti-entropy](../yl-anti-entropy/SKILL.md)；本成员上面的专项归档/清理步骤继续保留。
