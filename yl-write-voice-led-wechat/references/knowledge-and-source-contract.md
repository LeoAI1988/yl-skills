# 知识、原稿与表达资产接口

公共版使用安装者当前提供的资料，不依赖来源作者的私人仓库、路径、账户或历史授权。所有运行记录、原稿和输出放在 Skill 目录之外。

## 原始输入

完整原稿是事实与表达来源，索引、摘要、知识原子和表达卡帮助定位，不能冒充全文。消息可逐字存成只读基线；文件保留原件，另建工作稿。音视频先取得完整转写与时间定位，标题、摘要或片段不能声明为完整转写。

内部记录原对象 ID、文件/消息位置、时间、SHA-256（可取得文件时）、完整性和使用范围；原稿片段标为 S01、S02。先保存完整措辞与推进，再提炼功能。实际数字、姓名、否定词和指代疑点回到来源核对。

## 检索接口与状态

每次都检查当次材料清单、用户已指定目录、可用知识库与表达资产。不要扫描无关个人目录，也不要因看到平台名就联网或同步。

| 状态 | 行动 |
| --- | --- |
| 已提供且可访问 | 以原稿判断、痛点和缺口检索；回读命中原文及上下文；登记查询、对象 ID、定位、逐字片段、缺口及实际采用处。 |
| 已提供但无相关命中 | 记录实际查过的范围和查询；不硬贴无关案例，基于原稿可支持部分继续。 |
| 未配置 | 记录 `not_configured`，用当前原稿与已给材料完成有依据的修补；新增具体事实不足时指出一项真正需要的材料。 |
| 已指定但不可访问 | 记录具体接口/文件与失败，完成不依赖它的工作；关键事实缺失不能假装已核验。 |

读取综合稿或 synthesis 时先理解完整推理，再回读其引用的原对象；搜索摘要不是原话证据。用户已说足的观点不因旧资产更多而替换；新口述与旧稿冲突时保留时间与版本差异，重要冲突请用户决定，不能静默改立场。

## 新增内容

每处新增对应原稿中的缺口。区分：本人真实原话；可核实外部事实；基于已给事实的本次推导；待确认主张。推导可以帮助桥接，不伪装成用户曾经说过的话。未核实的新数字、亲历、对白、心理、产品功能和效果不得写成事实。外部材料不能冒充本人经验。

每段问“补哪里、凭什么、如何回到下一步”。新增事实逐项有来源；无新增事实时记录 `not_applicable`，不虚报覆盖率。来源线索和核验卡留内部，除非文章本身需要公开归属，不把正文写成仓库处理报告。

## 版本与后续动作

`draft`、`finalized`、`published`、`synced` 分别记录。成稿不等于定稿，定稿不等于已发平台或已同步。用户手改稿成为当前编辑底板；明确要求从原始材料重新写时保留旧版另起新稿。

本 Skill 只做文本任务及其必要内部记录。封面、HTML、云端归档、知识库维护或发布遵循当前任务已有授权；没有授权则不触发。不得复制来源作者的自动归档规则、私人推广结尾和账户配置给安装者。
