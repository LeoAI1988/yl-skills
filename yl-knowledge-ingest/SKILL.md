# 归档与去重

先读同级 `yl-knowledge/references/contract.md` 及知识库导航。逐份读真实正文，不用标题、所在库或摘要判断归属。混合材料按段分离本人表达、外部引用、私密事实。

判定位置：本人原始思考→来源资料；本人定稿/发布作品→作品全集；私人事实→私人档案；第三方→外部研究；明确排除→保留排除记录。文件名“定稿”不能单独证明确认状态，账号采集不能证明引句原创。

先按来源 ID 和正文哈希查版本，再检索相同内容核心。完全相同使用既有正文，增加来源别名；修订保存新版本，关联取代关系。多平台使用共同 work_id，各自发布身份和数据不合并。语义近似不能仅凭相似度自动删除。

原始快照不改。引用已有库时保留 ID、原文件、业务登记与 `.asset.yml` 语义；不为了新工具转换全部旧格式。新格式参见同级 `yl-knowledge-distill/references/objects.md`。

登记完成不是交付结束：明确排除和外部材料记录处置；本人及混合材料中的本人片段进入蒸馏与表达步骤。范围或归属不明部分标未完成，不扩大“本人确认”的含义。
