# 核心知识增量同步

本地知识库仍是真源。云端仅保留授权范围内的服务副本；不跟随正文里的链接复制外部原文，不上传整个磁盘或配置目录。

1. 读取安装者提供的配置文件；其中包含 `root`、`roots`、排除规则、服务地址及外部凭证文件路径。首次配置时确认真实目标和内容范围；既有授权内的再次同步直接执行，不反复征询。
2. 先运行 `python scripts/sync.py --config <配置路径> plan`。检查分类数量、被排除原因、正文变化和待移除条目。新内容若尚未完成本地知识处理，先由 `yl-knowledge` 完成本地管线；同步脚本不会冒称自己能做语义蒸馏。
3. 运行 `python scripts/sync.py --config <配置路径> sync`。按当前服务器清单只传新增或修改的正文；整个清单在同一事务中切换。移除只影响此服务副本，本地原文不变。
4. 验收回读清单与 SHA-256；再次同步应为零变更。报告实际新增、修改、移除、跳过及失败。超时后先读云清单，不能盲目认为未写入。401/403 停止并报告凭证问题，409 重新取清单。

个人配置、同步报告和令牌放在核心外。不得将个人路径、资料或服务密钥写入本 Skill。需要 Python 3.10+ 和 PyYAML；HTTP 服务协议见 [协议](references/protocol.md)。
