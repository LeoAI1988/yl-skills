# 样本分析与两种模式

## 学习单位

以一篇完整稿的“观众问题 → 作者判断 → 解释或证明 → 可执行动作”为学习单位。先逐段读懂原文，再记下这篇实际采用的结构。强首句需要后续信息承接。短稿可能一句话给判断、一个任务给价值，长稿可能通过比喻展开推理，结构由样本决定。

每张模式卡包含下列信息，实际证据不足的字段留明原因。

| 字段 | 要保留的内容 |
| --- | --- |
| 观众与动机 | 观众处境、欲望、顾虑、购买阻碍，注明这是作者明说还是分析推断 |
| 选题 | 承诺的具体收益，和商品解决的问题有什么关系 |
| 首句 | 原句、信息作用、从标题进入口播后提供的增量 |
| 论述 | 每一段做什么，前一段如何使后一段成立 |
| 原声 | 有辨识度的词、比喻、反问、重复和节奏，链接完整原段 |
| 信任 | 本人经历、可展示结果、操作任务或解释机制 |
| 转化 | 观众为什么在此处需要商品，实际 CTA 与商品身份 |
| 数据 | 账号、发布 ID、原稿版本、观察窗口、时长、播放、完播、涨粉、成交依据 |
| 比较 | 相似结构的弱表现作品、不同账号或重发结果、缺失字段与差异 |
| 学习结论 | 可复用的假设、适用场景、反例、当前信心与最近核验时点 |

把支持强度写清。多篇同账号可比作品复现、单篇成功、仅有题材相似，分别保留对应证据。高播放未必提供直接成交依据，低播放成交稿也可能包含强购买动机。缺失销售归因的稿件可以用来研究传播结构，其成交效果保留未知状态。

## 可比性

同一账号内优先检查相近发布时间、视频时长、商品与价格。同稿重发和跨账号版本对照能提示分发、受众及画面的影响。样本较少时逐篇展示差异，避免只剩一个综合分数。每个分组保留样本数，单样本百分位对排序没有区分价值。

账号订单、视频成交截图、用户确认私域成交分别保留口径。快照重复、重叠窗口、总计与子集各有身份。视频级付款转化率需要同一观察窗口、可用分母和真实归因。小店显示的千次观看成交额按平台口径引用，涉及新比较时核查其窗口。

播放数据属于已经发生的结果。开头和结构的作用是待验证解释，画面、商品、流量来源、发布时间和受众也可能改变结果。模式卡保留这些具体影响，稿件正文专注内容表达。

## 组装决策

先确定观众要解决的一个核心问题，再选主要论述链。每个借入段落须承担其中一个明确作用，包括把问题讲具体、解释原因、给真实例子、推进动作或承接购买。段落本身精彩但与主线无关时，留给另一篇。

拼装前回看原段的上一段与下一段。代词的指代、类比的两端、前提与结论、评价对象、时间背景一起保留。原稿中的对比、情绪和口语是否保留，按本次作者意图与适用表达约束判断。

字句由作者资产提供，篇章组织由当前任务决定。完整原句优先，允许调整句序、合并重复、补充必要连接和澄清指代。形成新观点关系时，内部记录为本轮组合推演，避免标成作者过去说过的原话。

## 持续生成

个人历史按母稿、开头、中心问题、比喻、案例、行动入口和知识来源记录。新一批先读最近已生成和已发布的内容，再决定本批差异。

重复检查同时看文字与信息。沿用作者标志句可能合理，多个版本都只讲同一个理由则需要新的段落价值。长期序列可从同一主张向不同受众、不同工作阶段、不同真实阻碍、不同案例和下一步行动展开。每篇承担一个独立信息任务。

数据更新后重新检验母稿，而后更新候选权重。旧稿的成功保留为历史证据，新作品的效果更新适用条件。生成历史中即使尚未发布的稿件也参与重复检查。

## 新素材的进入方式

新素材先形成一句工作判断，明确“发生了什么”和“这使我的哪个问题值得重新解释”。用本人旧稿验证第二部分的思想来路，再选择历史结构。

用户给外部爆文时可以学习开篇如何建立问题、如何排列证据、如何制造信息推进。主题、经历、案例和结论归属按来源保留。新闻涉及新产品时，只使用发布方已给出的功能和条件。本人做过的事从本人原材料取证。

新闻信息与个人判断在正文中自然衔接。真正影响判断的条件贴近对应句子，材料缺口记录在内部依据。新闻不适合商品时，采用能够兑现的学习或实践动作结束。
