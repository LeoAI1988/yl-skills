# 横屏访谈剪辑 · ChatCut

直接调用也读取 [个人配置约定](../yl-toolbox/references/profile.md) 及有关剪辑的个人说明；不把另一用户的路径、素材和偏好写入通用核心。

主工具是 ChatCut Desktop 的本地 MCP，交付可继续编辑的工程、成片和完整成片逐字稿。适合相机横屏单人独白、访谈及长内容复盘；常规短口播交给集群的口播剪辑成员。源视频、原始录音和批准版本保留，工作文件存放在本次项目目录，不能放进 Skill。

本 Skill 独立包含编辑标准，不依赖旧横屏 Skill 或 Remotion 渲染器。FFmpeg 等只辅助探测、波形、对比、解码与成片核验；保持 ChatCut 可编辑时间线为主工程。ChatCut 内部图形运行时名称不代表另起 Remotion 剪辑流程。

## 模式与授权状态

- 沿用本任务已选模式；未说明且无法从明确指令判断时，只问一次“全自动还是半自动”。“全程交给你、不参与过程、直接给成品”可确定全自动；“先给完整稿，我确认再剪”确定半自动。
- **全自动**：自行完成全文判断、精剪、包装、导出和核验；常规删留、停顿和切点不逐条提问。用户另有先看方案或暂停要求时遵守。
- **半自动**：先提交完整原稿、全文删除线稿、完整顺读稿与调整理由，等用户确认文稿后进入实际剪辑。用户说“先记录，发完给信号”，进入收集状态，只保存本轮意见；收到“开始统一修改”才应用。
- 文稿批准后持续完成精剪与交付，不在每个技术步骤重新索要批准。“不要初剪，给成品”确定最终文件交付要求，不把待审初剪当完成。
- 新一轮意见以本轮开始时的已应用版本为基稿，不能把旧删除重新套一遍。局部修音或样式修改冻结已批准的正文和排序。
- 授权与质量证据分开记录。缺听审能力时继续做可完成的检查、保留明确未验收项，不反复让用户批准同一编辑，也不编造完成。

## 接入与素材

先读 [ChatCut 执行与时间基](references/chatcut-workflow.md)。使用当前 `chatcut_desktop` 工具，先 `get_active_project`，再读取目标工程、时间线和素材；工具名称、参数及可用性以实时清单为准。不要用视觉点击驱动 ChatCut 自己的聊天框。

已有指定工程直接续接；找不到才定位或创建。检查真实本地源与云端代理、音频轨、时长、帧率、分辨率、隔行及源时间原点。原片可用时优先原片，不能把压缩代理叫作原画质。已有可用全文转写不重复提交。

默认 Desktop 本地导出；仅用户明确选 Web/Hosted 才读取该表面的插件说明。不得把 Hosted 云端导出当成本地免费导出；服务额度和价格查当日官方文档，不能承诺全流程永久免费。

## 先全文减法，再声音精剪

剪前必须读 [编辑偏好与红线处理](references/editorial-and-redlines.md)。通读完整原稿，检查转写覆盖，分开标注 ASR 错字、真实说错和听不清。

先回答三件事：全文主张与推进链是否清楚；每一段是否增加信息；开头是否有源内、语境完整的吸引点。第一版就处理重复论点、冗长功能枚举、重复铺垫、案例枝节与失败重说，不能只删“嗯啊”后把长稿交回用户。

保留说话者的原话、关键比喻、观点转折、因果、条件、否定与必要示例。没有固定删除比例，不为达到短时长改写或拼字造句。移动高能片段时保护立场变化与前后语境，默认移动一次而非复制重复播放；半自动先在完整稿中展示。

文稿工件为：原始全文及校对版、全文删除线稿、按播放顺序的完整顺读稿、逐项删留/移动账。每项有原句、源时间、原因、保留结果和上下文锚点，不能只交摘要。用户看实际词句，不暴露内部片段编号作为解释。

实际删留/调序走 `read_script → 暂存 → 预览 → apply_script → 回读`，保存实时 Script 的 occurrence 标识。ASR 文字纠错走转写工具；改字幕不等于剪原声。批准稿禁止再跑会额外删词的机械 cleanup。

## 切点、停顿与速度

读 [精剪与验收](references/precision-and-acceptance.md)。ASR 时间只做定位线索，用包含前后短语的源声检查弱辅音、尾音和气口；波形低谷、VAD 或多峰都不能单独证明该删。

避免“剪过”和“留太多”：逐一核对全部新连接、词内/词间、开头及结尾。帧量化和边界修正后双向对账，确认已删词不复活、保留词不缺失。用户只允许红线删词时，不以更顺为由扩大语音删除。

先结构与停顿，再整体变速。明确要求如 1.1 倍就执行并实测一次，不二次叠加；没指定时先用 1 倍核声，根据实际字速与听感决定是否小幅提速，280–320 字/分钟只作参考。使用保音高，核对视频、独立音频、字幕和插图的共同时间映射。

## 声音与视觉

声音读取 [音频排障与处理](references/audio.md)：先查重复混音、削波、变速和原声，再决定是否人声隔离。默认自然原声，不叠加环境音或配乐；人声稍增强必须留峰值余量并核听。若要求取消降噪，显式清除效果并回读，不能只调增益就声称已取消。

字幕、主标题、身份卡、插图读取 [画面包装](references/visual.md)。只做用户要求的包装；请求“沿用上次横屏风格”可复用其字号比例、白黄重点、黑描边与柔化阴影，身份文字仍取本次确认输入。无包装要求时只做适用字幕。参考红框要测比例并核实际字面，不能只写“已加阴影/半透明”就交付。

## 最终交付

完成文件交付要求时用 `local_export` 输出独立新版本，等待真实文件完成，再检查全片解码、音画同步、剪接、字幕与最终导出画面。路径返回不等于完成；不要重复提交同一导出来催进度。

交付成片 MP4、可编辑工程信息、完整成片 TXT/MD、SRT（启用字幕时）、变更及核验记录。分别标注内容、声音听感、视觉、技术检查的证据与状态；“0dB”“音效已挂载”“文件可解码”均不能替代实际听看。

维护或复盘时读 [案例教训与行为验算](references/lessons-and-scenarios.md)。只改 Skill 的任务不得顺带重新处理用户的视频。
