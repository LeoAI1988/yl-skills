# 切点、节奏与成片验收

## 紧凑但不吞字

先全文决定，再按保留范围扫描词间、词内、首尾及漏转声音。用带上下文的 2–6 秒短语核听疑点，必要时缩小窗口，不把单字短窗乱码当作说错。VAD 连续有人声仍可能包含重复、卡壳与找词；多峰也可能只是正常音节。

本风格偏紧凑，以下按最终成片秒作候选校准，不能自动覆盖语义与真实发音：普通无信息停顿约 0.15 秒起复查，超过约 0.20 秒优先收紧；连接两侧合计通常约 0.06–0.15 秒，句间约 0.15–0.24 秒，明确转折可留约 0.30 秒。开头五秒更严格复查约 0.08 秒以上的空隙，可将纯空白合计收至约 0.05 秒，但不得机械剪去送气、尾音或有意义的停顿。

这些数值来自紧凑剪辑偏好，不是所有说话人的统一切点。先保护完整声音，再选择最短自然连接；每侧都留 0.1 秒会合成 0.2 秒，须检查合计。倍率变动后重新计算输出留白。

禁止按词中心落区自动删、把长词时段等分当字音边界、给全部保留区统一外扩再合并。帧对齐后的真实边界要重新检查，尤其删一个字和两段拼接之处。

## 核验流程

- **文稿**：逐项红线和调序账与实际 Script 对账；完整顺读，检查主题、指代、条件、否定、开头立场与收尾。用户定稿范围外没有额外删除。
- **音频**：完整听感、全部新连接及开头/结尾；对比处理前后；重复混音、源范围、倍率、削波/真峰值与响度分开检查。
- **字幕**：完整文本与实际保留口播一致，时间从同一映射派生；疑似错字回查源声；字面大小、固定字号及遮挡实际看。
- **画质**：源片规格、代理差异、隔行梳齿、必要去隔行、清晰度和包装像素。原相机是隔行时不能只因输出标 1080p 就称已去隔行；按真实源验证。
- **文件**：真实导出已结束、完整解码、持续时间/帧数/音轨、音画同步、插图边界、首尾无多余黑场；输出新文件并记录 hash、项目和时间线版本。

状态使用 PASS / FAIL / PENDING，并写证据范围。五项全部相应证据充分才叫验收完成；技术检查不能补足听审。没有音频感知能力不装作听过，也不把“让用户再听”当全自动已完成；如实交代限制并完成其他可执行工作。

独立复核能提升可信度，尤其多轮红线和大量切点：任务允许且工具可用时可交给独立审阅者核对源工件；否则执行独立的第二遍对账并如实标自检，不伪造三角色。审阅结论按工件版本绑定，改动后受影响结论失效。

## 交付记录

记录：版本、模式、素材/hash、批准稿版本、反馈账、工程/时间线、源到成片映射、倍率、音频处理与发声轨、视觉更改、导出文件、逐项证据与未决项。完整成片逐字稿以实际应用后的词序为准。

用户要成品时不能只交工程或“待听审初剪”；确实缺能力时说明具体未验收项与已交付文件状态，不把未知写成已通过。不要反复索要用户参加已委托给 Agent 的常规检查。
