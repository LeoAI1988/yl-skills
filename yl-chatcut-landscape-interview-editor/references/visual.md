# 字幕、标题、身份卡与插图

## 范围与风格

横屏相机质感为底；不默认美颜、磨皮或新增配乐。主标题、身份卡、插图按用户要求启用。只改音频或包装时不修改定稿词句和剪辑顺序。

用户给红框时，读取实际截图，用框相对画面宽高映射到输出尺寸，检查字形的可见包围盒；容器宽度不等于文字已撑满。标题可用厚重白字、黄色重点、黑描边与明显柔化投影，按参考保留行数与位置，避开脸和字幕。不能把“阴影参数存在”当成阴影看得见。

身份卡放在用户指定侧，底色单独半透明、文字保持清楚不透明；不要降低整个组件 opacity 导致字一起变淡。黑底可从约 0.35–0.50 alpha 试起，判断背景细节是否清楚透出；0.78 在实拍上可能仍显得接近实黑，不能仅凭小于 1 就交差。身份名、业务描述与分隔线从本次输入取值，不把作者的身份预填给其他安装者。

## 字幕

固定字体、字号、位置和行数，长句分页而非忽大忽小；以实际画面可读性和用户框选校准，旧工具像素参数不是跨工具事实。正文遵循原声与批准稿，ASR 错字需核声；不能用改字幕掩盖未删掉的声音。剪词、移动、变速后刷新并全量核对字幕时间。

## Motion Graphic 改法

读取当前 Desktop create-motion-graphics Skill。位置/大小用 item，已有暴露属性用 propertyOverrides/defaults；阴影等内部机制才改源代码。当前 Desktop 官方指南优先内联 JSX；使用实时 schema 支持的 create_motion_graphic_from_code / edit_asset，不自行暂存到应用内部目录。如果该版本明确返回可编辑 codeFile 工作区并要求文件方式，才用工具返回的路径；不能猜路径或直接写应用数据。Hosted 与 Desktop 的代码提交方式不得混用。

保持已接受的字体、文案、颜色和时间，不为加阴影重做标题。字体使用 ChatCut 支持的家族；新选/替换前查目录。白黄字层在黑轮廓上方，SVG 可用独立柔化偏移投影，给 filter 边缘留空间，避免阴影被裁掉。柔化半径和偏移随实际尺寸调整，不把单次参数硬编码为通用正确值。

如果预览仍不对，检查资产默认值、实例覆盖、当前 timeline/asset、代码修订和缓存；看真实预览与最终文件再判断。重复创建多个同名组件不会自动修好错误。只有确认实例引用和实际像素都改变，才报告修改成功。

## 插图

“在某秒撑满、停留两秒”默认按已批准倍率后的成片时间定位，以当前 fps 计算起止帧；优先作为覆盖画面保留原声连续。若用户明确要冻结/暂停原声再插两秒，则是插入时长，依照指令重排后续时间。

插图作为普通图片置于合适高层，满屏 crop/contain 需兼顾完整信息；横竖比例冲突不得不说明就裁掉必要文字。此类静态素材不走 AI 图像生成，也不需要单独导出付费透明动效。

## 视觉验证

同次看入场、稳定期与退出邻帧，检查主标题白黄字/描边/阴影、卡片半透明、字幕、脸部遮挡和插图持续时间。再从最终本地 MP4 抽帧，排除预览与导出差异。缩略图只核看过的帧，不证明全片每一帧都正确。
