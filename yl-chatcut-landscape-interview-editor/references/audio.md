# 原声、杂音与人声增强

## 先定位，再处理

用户说“杂音还在”不能直接断言来自环境、降噪或倍速。先取原始录音、当前时间线实际混音和最新导出，在**相同内容、相近听感响度**下比较，覆盖安静段、普通说话、强音和切点。观察底噪、金属音、水声、爆音、重影和断续分别在哪一层开始出现。

排查顺序：

1. 全部发声轨：视频内嵌音、拆出的 A 轨、其他并行音轨、轨道静音/solo、增益/路由、附着音效及派生源；检查是否同源重复混音。只看 A1 的名称不能排除 V1 同时发声。
2. 原始源文件本身：名字含 original 不证明字节未经处理，核实路径、来源记录和波形；原始文件永不覆盖。
3. 变速及拼接：保音高算法、音画对齐、每一新连接的点击声；0.1 倍提速也可能改变听感。
4. 当前导出的削波、响度、峰值和真实听感。比较处理前后，确认改动在实际输出里生效。

## 回退与增强

要求恢复原声时用实时 `isolate_voice(action="clear")` 或官方对应移除接口，读取确认效果/派生引用已清除；只把 `decibelAdjustment` 改成 0 不等于清除人声隔离。

`0dB` 只是单位增益，不代表输出无削波。`max_volume = 0.0dB` 或 0dB histogram 是复查线索，不能单凭它断言已削波，也不能当成健康上限忽略。检查真实峰值、平顶/截断样本、混音重复和处理链；原片峰值接近满幅时先留余量，不机械加 +1/+2dB。

“人声加强一点”不是整条录音音量越大越好；加增益也会放大底噪。先保证单一路径和自然声音，按证据做轻微增益或支持的温和动态处理；如工具不支持，不虚构参数。输出真峰值建议留至少约 1dB 余量，最终以实际混音检查为准。

## Desktop 人声隔离

仅对说话录音使用。读取当前 voice-isolation Skill；按现有 `isolate_voice` schema 应用或清除。已知 Desktop 使用 MossFormer2，当前强度固定，旧 strength 值可能归一为 100；不要声称可以任意“降低一点处理强度”。具体行为以本机版本和工具返回为准。

先验证一段处理前后，听有无吞音、金属伪影、喘息突变，再覆盖剩余切片。应用时用当前源资产，不把已处理导出文件再处理。全部目标必须分页读取并核计数，批处理失败只重试失败项；不是给第一段加效果就算整片已处理。

效果可能挂载为 `audio-effect`，而非新音频素材，资产仍叫 original 不代表没有处理；看 `attachedEffects`、enabled 和实际导出。处理会利用全源缓存，但缓存命中、推理完成、导出完成须分别取证，不能凭预期推断。

支持 A/B 听审后再选自然且清楚的一版；用户明确要求取消 AI 处理时不得擅自重启。需要重新授权的处理偏好只问变化部分。已要求自行调整杂音可在授权范围内试验并保留可回退版本。

## 验收边界

音效已挂载、模型运行和平均响度下降，只证明操作/信号变化。没有实际听审能力时明确标记“未听审”，完成其他检查，不写“杂音已消除”“干净自然”。ASR 复转只能核内容，不能认证音色质量。用户反馈仍有杂音时回到诊断证据，不重复同样设置后再次宣称成功。
