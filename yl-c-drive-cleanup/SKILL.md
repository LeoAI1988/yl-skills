# C盘清理

办公与管理板块的 Windows 系统盘专项。让电脑只留必要内容，继承 [防熵增原则](../yl-anti-entropy/references/principles.md)：原始输入与确认成果各自唯一，日常清理不创建备份、回收站副本或永久工程归档。

先读 [个人配置约定](../yl-toolbox/references/profile.md)，只取相关配置。用户目录、程序路径与运行记录在当前机器发现，不能复用其他人的账户名或历史绝对路径。系统实际装在其他盘时说明范围，按用户点名的C盘处理，不擅自换盘。

## 从已有范围继续

- “扫描一下”“哪些可以清理”“先分析”：只读排查，列准确候选和条件。
- “先清理这些”“红框这些不要了”“按上次清单清”：恢复当前指令、截图选中项与已有报告，重新核验后直接执行，不重复要求确认。截图只圈了几行，就只处理这些行；同屏其他目录不是授权范围。
- “软件已经卸载，更新包不要”：可以处理明确选中的更新下载目录，无需再次问是否卸载；确认路径角色与当前占用仍不可省。它不授权删除整个应用数据目录或聊天/笔记数据。
- “清理C盘”“合理清理”：先定位范围，处理已证实无使用依赖的可再生缓存、确证重复副本和已确认结果的中间文件；用途未知、唯一文件和活动依赖保留并说明。

本Skill的安装不触发历史清理，也不建立计划任务。用户要求多盘、防熵增、一般工程归档时由 [yl-anti-entropy](../yl-anti-entropy/SKILL.md) 处理；不要为了C盘清理启动其他生产或发布任务。

## 先定位，再核验

1. 读取C盘当前总量、已用、可用，恢复上次候选与已处理结果；已删路径记为不存在，不重复计入本轮释放量。
2. 大范围扫描复用 [防熵增工具](../yl-anti-entropy/references/tools.md) 的 `scan --metadata-only`。先看用户目录、应用数据、临时目录及最大文件，再仅对候选补真实文件身份、硬链接和完整哈希。已有近期扫描就直接核对候选，不重扫百万文件或重建全盘数据库。
3. 对照 [C盘候选判定](references/windows-candidates.md)，分清缓存、待安装更新、卸载残留、原始素材、正式成果、运行组件和业务数据。目录名、文件旧、显示0.000 GiB都不足以证明可删或为空；拒绝访问单独记录。
4. 检查当前进程的可执行路径、命令行与被使用的子目录。进程信息不可读或相对命令无法排除相关依赖时结合实际任务和文件占用判断；查不到路径引用不是绝对无占用证明。活动npx分支、渲染任务、下载任务与续传材料单独保留，其他已确认范围继续处理。

## 受控清理

先得到准确的目标白名单和保留集。不要把用户的选中项变成“所有updater”“整个AppData”或应用安装目录。

- 每个目标解析成规范绝对路径，确认严格属于已授权目录。检查祖先和目标是否为符号链接/Junction；不沿重解析点递归，也不把链接目标空间计入释放量。
- 已确认的可再生缓存只清对应缓存子树。保留依赖包、浏览器、模型、配置和活动子目录；不要清整个 `node_modules`、运行时或共享包仓库。
- 更新目录先枚举实际文件，识别安装包与更新元数据。若出现无法解释的用户文档、数据库或来源素材，保留相应范围；不能仅因后缀是 `.exe` 或目录名含updater就猜用途。
- 删除前检查文件未变化、可读取且无冲突占用。重要保留文件在清理前后核验完整哈希；字节重复副本必须两侧重新读取完整SHA-256，核验正式位置与引用后才删。不能拿旧清单哈希代替当前文件。
- Windows在同一Shell/运行时内完成文件操作。少量文件优先按准确路径删除文件，再非递归删除已空目录；大量文件先做不跟随链接的范围清单，再逐项检查与删除，最后自底向上清空目录。可用原生文件API减少逐文件Shell开销，不能为提速取消边界、保留集与占用检查。
- 不结束用户软件、批量杀Node/Python、提权改权限或改注册表。失败/占用文件留在原处，记录具体路径；继续处理其余安全项。中断后重新核对剩余范围，不盲目重跑旧快照；只可管理本轮自己启动的辅助进程。

## 清理后核账

1. 复查已删目标不存在，保留分支、正式组件与原始/成果文件可达，必要完整哈希不变。
2. 分别计算实际删除文件数、删除逻辑字节与C盘可用空间变化。硬链接、文件系统分配及其他进程读写会造成差异；不要把逻辑大小写成实测释放量，也不要把空目录当成释放大文件。
3. 报告已清内容、实际释放、保留/失败的准确范围和原因；只对本轮核验结果报完成。旧报告的“未执行”“待更新”状态同步为最新执行状态，已清目录不再列为待办。
4. 只保留一份简洁结果与必要的小型续做清单，存于核心外；合并或清除本轮生成的大型扫描库、临时脚本和预览，不让清理过程本身积累一套仓库。不得顺便删除其他任务的记录或备份。

直接调用示例：`使用 $yl-c-drive-cleanup 排查C盘，先列可清理项。` 或 `使用 $yl-c-drive-cleanup 清理刚才圈选的更新残留，检查安全并核对实际释放空间。`
