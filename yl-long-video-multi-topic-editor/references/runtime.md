# 长素材执行与可选增强

## 本地执行

工具位置、模型、字体和样式从个人配置或当前环境读取。音频/视频、凭证、ASR、项目和缓存不放入 Skill 核心；不复制整段母带做多份备份。

1. 原片探测采用真实流、旋转、逐帧 PTS 和色彩信息。区分源物理帧、音频采样与输出帧，保留稳定源 ID。切换转写块、代理、工具或输出阶段，不重置绝对源时间。
2. 多小时音频分块读取/寻址，不将整段双声道 PCM、全部解码帧或巨大 JSON 一次装入内存。哈希流式计算；断点记录输入指纹、已完成范围和错误阶段。文本疑点只局部复核，不反复转写全片。
3. 内容确认后每条构建独立 EDL。以半开区间保存源时间和输出位置；用音频采样精度执行字词删除，用有理数帧率分配视频帧，误差不能逐段累计成声画漂移。视频需要补不足一帧时，不截掉语音尾音来凑帧数。
4. Remotion 为每条、每段、字幕和标题建立独立节点；字体加载完成再渲染。源内烧录文字随对应视频移动；新字幕按新时间轴生成，禁止源绝对时间直接覆盖重排后的视频。
5. 有复杂动态效果时走正常 Remotion 导出。静态文字层可用 Remotion 透明图层配合原片 FFmpeg 精确裁切/合成，新增的视频有损编码从有效基底直接生成。普通 CFR/SDR 的基础实现可参考同级 [切片运行方法](../../yl-remotion-video-slicer/references/runtime.md)，其固定输入合同不适用于尚未转换的 HDR/VFR/带旋转源。
6. HLG/PQ 原片按实际类型做真实 HDR→SDR，并同时检查解码像素、码流和容器色彩；不靠覆盖色彩标签。已旋正视频不能保留会再旋转的显示矩阵。硬件解码/编码先做本地小样，缺失时采用可用软件实现，不降低尺寸或偷换低质代理。
7. 反复局部改片时可复用未改帧的原编码包，但须核对关键帧、包哈希、准确帧数及局部字幕内容；无法证明可无损复用时，直接从原片/匹配的无字增强底片重导相应片段。不要只改存在性判断来跳过导出。

普通标题/遮盖/字幕的工程机制可复用现有成员脚本；本成员的全文策划、低重叠分配、字音精剪及本批绑定责任仍由执行者完成。不得因某脚本只支持一个源或统一倍速就悄悄缩减任务。

## 可选增强

仅在当前范围已授权开拍/相应增强后调用；账号、凭据、SDK 与费用能力实时核实。授权已覆盖的常规动作直接继续，不重复制造确认。不得把“免费次数”“余额”或历史成功当作本次可用额度的证据；不购买、充值或扩展付费范围。

入口可复用同级 `yl-remotion-talking-head-editor/scripts/kaipai_enhance.py` 的已审核 SDK 包装器；读其实际参数和对应 [接口说明](../../yl-remotion-talking-head-editor/references/kaipai-enhance.md)。不复制私人 SDK、凭据或它的运行 checkpoint 到核心，也不改公共包装器来绕过输入验证。

- 上传同一最终 EDL 的**无标题、无字幕、无插图** SDR 底片；保留输入哈希、总帧数、速度已应用标记和原剪辑 AAC。不能拿早一轮的底片跑增强后冒充全部意见已改。
- 先尝试接口允许的完整输入；达到已验证的大小/时长限制时，以最少必要分段处理。多个最终短片若能合并成较少请求、且不改变质量与限制，可用全局帧表合并增强再拆回。提交前说明实际必要分段数，费用超出既有授权才停止相关调用并澄清。
- 不用降清晰度换更少请求，不机械切成大量固定小片；不因画质成功而重复计次。新接入/参数改变先验证代表性样本，同条件已有可靠证据可复用，不机械为每条多烧一次测试。
- 每次提交即保存 task ID、实际参数、输入指纹和费用/权益结果。状态未知先核实；有 ID 只 query。下载、封装、字幕调整和验证失败不重新 submit。只保存安全错误码和阶段，不输出签名 URL、凭据或原始敏感响应。
- 回片保留原始字节，核色彩、分辨率、方向、帧数及所有包 PTS/DTS。只在确有证据的封装末包舍入等情况下应用相应验收例外，不伪造 CFR 或贴标签放行。
- 合回本批总帧坐标再按每条区间拆出；检查全部服务分段接缝与本来就存在的源剪点。增强已包含本批速度和剪辑，不能再次按源 EDL 重剪或加速。
- 最后叠独立文字层，回接原剪辑 AAC。视频与音轨分开控制末尾，不用 `-shortest` 牺牲尾音；核 AAC payload/PCM 与实际声画时长。增强输出自带声音不作为最终原声。

## 验收证据

每条检查完整解码、实际帧数、音轨起止/长度、画幅/旋转、色彩和字幕首尾；改过的切点加密检查。增强前后按同源同刻比对普通光、高光、动作、眼镜、发丝、脸型、皮肤和衣纹，兼看适当尺寸与原生人脸局部；不要用全画面均值替代人脸观察。

原声音频要实际听前五秒、新增/修改切点与结尾，尽可能完整听看。没有该能力，保留明确未完成项；播放按钮点击、机器转写和哈希只能证明各自检查范围。交付文件可据实提供，但“内容/节奏/排版/画质/技术全部通过”必须有各自证据。

媒体与截图核验完成后清理本批渲染分段、重复中间封装和可再生缓存；保留本轮正式交付、回改所需的无字增强基底及其绑定。未增强最终版在当前审阅/对照期间保留。用户明确归档时按归档成员和个人策略决定最终保留集，不能静默删除用户指定要留的阶段版本。
