# 超长素材多主题精剪

从同一批长素材中，做出多条各有问题、论证和收尾的短视频。先理解全文再分题；主题、证据分配、叙事顺序一起设计，不能只改标题，把同一段话输出多遍。

可独立调用。首次按同级 `yl-media → yl-video` 确认一次归属；已分流直接继续。读取 [个人配置约定](../yl-toolbox/references/profile.md) 和当前任务相关个人说明，复用工具、原片、风格、模式与已有授权。运行资料放在核心外。

## 适用边界与交付范围

- “超长”由内容跨度和重组工作量判断，不设一小时的硬门槛。多小时素材需要分段转写与全局索引；较短但包含多条交织论述的素材也可使用。
- 完整课程轻剪、保留演示与章节顺序，走 `yl-course-video-editor`；普通连续切片或后补包装，走 `yl-remotion-video-slicer`；单条短口播修剪走相应精剪成员。本成员负责从全文重新策划多个主题。
- 数量、目标平台、画幅、最终时长、倍速、字幕、封面、遮盖、增强分别恢复。具体数字来自当前任务，不把某次的三条、五分钟、某个倍速固化为默认。
- 用户要先看方案，就先交付所有拟做视频的详细脚本，确认前不渲染成片；说按方案剪就执行。已选全自动或已要求直接给成品时，内部完成策划与验收，不重复征求确认。意图仍不清楚时只澄清会改变工作或费用的部分。
- 要求“只记录、不修改”立即进入记录状态；后续“以上开始改”解除相应范围。开拍、其他云服务、发布及归档按当前授权分别执行，不能从一次剪辑授权推导其他外部动作。

## 1. 建立全素材地图

读取 [全文与选题](references/planning.md)。先探测全部源片的时长、音轨、画幅、PTS/帧率、旋转、HDR和已有倍速，给每个实际源分配稳定 ID。

长素材按能力分块处理，保留绝对源时间及分块边界重叠，核对边界的遗漏、重复和被截断字音；不能把 ASR 自动去掉的口吃当作原声已剪。覆盖清单须包含源片后半段与结尾，不只搜索高频词或依赖摘要挑片。

产出带来源的全文、话题/论述索引和候选证据表。转写疑点回到原声与画面；说话者归属、否定词、数字、专名、指代和观点条件优先核对。

## 2. 同时设计多条不同的逻辑线

每条写清：给谁看、回答什么、核心判断、独有证据、论证链、开头原句、结尾和未采用内容。先做全批对照，再逐条成稿。

详细脚本包含每段完整原话、源文件与起止、段落作用、调序关系、删留、倍速和预计成片时间。强开头取自源中已说出的完整原句，可以前置；不生成作者没说过的主张，不为了差异化删掉必要限定或歪曲因果。

低重叠同时检查**论述重复**与**源区间重复**。优先分配不同的案例、证据和收尾；必要背景可以少量复用并说明。`scripts/multitopic.py audit` 计算源区间并集、成片时长和两两重叠，只提供可计算证据，不能代替语义审阅，也不能保证平台将作品判为不同。

## 3. 落成可回源、可编辑的时间轴

读取 [执行与增强](references/runtime.md)。默认 Remotion，明确指定其他工具则保留内容方法并使用该工具。每条、每个保留段和字幕段独立编辑；生成后检查实际预览与导出是否读取同一 EDL。

- 保留源时间、输出帧和音频采样时间的对应，跨段重排后重新映射字幕与遮盖。VFR 使用真实 PTS；非整数帧率使用有理数，不粗略当成 30。
- 倍速从已核实的源基底按本次要求应用一次，保持音高。首句和正文不同速度时独立记录；不再次加速已有剪辑版或已增强底片。
- 代理只供预览，最终画面读取原片或已绑定本条时间轴的增强底片。正确处理旋转和 HDR→SDR，不靠改标签伪装转换。
- 包装与内容分开：独立字幕、标题、封面；源内原话为正文依据。仅改指定词时执行最小替换，保留其余文案和已认可版式。

## 4. 精剪与多轮意见

读取 [精剪、反馈与批次版本](references/refinement.md)。先完成自身的冗余、口误、咳嗽、填充词、残句与停顿检查，再提交阶段成果；不要让用户替执行者找所有明显问题。

重复词明确删第几个；删除范围回到源内字音，既不留上一句残音，也不吞下一句起音。完整词尾与自然气口优先，不能把“紧凑”理解为把所有切点贴死。ASR、波形与静音检测只能辅助定位，真实听审状态单独记录。

截图和成片时间必须绑定**当时看的视频、阶段和批次**，再反查源时间；后续改时长不能继续套旧输出时间。用户更正时保留历史、撤销被更正的指令，以最新意见为准；未指明的其他视频和封面冻结。

每轮用统一批次号记录全批状态，内容版本按条独立记录。未改视频可继续引用同一个已验证文件，不复制一份来凑版本号。用户界面必须清楚显示“本批最终未增强版”和“增强版”，以及哪条沿用了旧内容资产。

## 5. 本地剪辑版、封面与可选增强

先导出并保留所有修改已执行的**最终未增强版**及其 EDL、字幕和原声音轨绑定；同时提供明确可选阶段的播放入口。封面在范围内时使用 `yl-short-video-covers`，从本片完整稿确定文字，人物构图读个人规范，不把单次案例图当通用资产。

用户确认后或已明确授权直接增强时，再按 [执行与增强](references/runtime.md#可选增强) 接开拍。实际上传无文字 SDR 底片；核对当前服务限制、权益和计费，尽量整段或按限制用最少必要分段，不为提速增加计次。已有 task ID 只续查，不重复提交。

保留无字原始回片，最后本地叠字并复制原剪辑 AAC。增强回片已经有本次剪辑与速度，不再应用一次 EDL 或倍速。纯文字/版式回改优先复用增强底片；未增强版与增强版的时间轴、字幕和原声内容须对应。

## 6. 验收、交付与收尾

读取 [项目合同与工具](references/contracts.md)。每条分别记录内容、节奏/听审、排版、画质、技术和用户意见执行状态。技术至少核完整解码、实际帧数、声画时长、音轨、旋转、色彩、字幕首尾和所有修改点；增强另核分段接缝、同源同刻对照、五官/眼镜/纹理与原声一致性。

没有音频理解能力时如实标记实际听审未完成，继续其他可做工作；不能把 ASR、波形、播放器曾播放或技术 PASS 写成已听完，不能宣称五项全部通过。

交付独立 MP4、按范围制作的封面、完整顺读稿、可编辑工程、源到成片映射、意见回执和播放页。未增强与增强各自指向真实资产；页面标签、下载链接、时长、修改定位和当前批次同步更新，检查实际浏览器加载。

预览验收后按同级 `yl-video-archive` 的 [去重收尾](../yl-video-archive/references/completion-cleanup.md) 清理本批可再生缓存和临时合并副本，保留唯一原片、正式交付与仍需听审/回改的材料。用户确认并要求归档时再走正式归档及相应知识处理；用户指定保留的未增强版继续保留。清理前核对依赖及链接边界，不遍历共享依赖，也不触及其他批次。

## 本成员附带工具

`scripts/multitopic.py` 仅负责确定性检查与本地展示，不替代剪辑决策、不调用云服务、不剪改媒体：

```text
python -B scripts/multitopic.py audit /work/plan.json --out /work/plan-audit.json
python -B scripts/multitopic.py snapshot /work/delivery.json --out /work/review
python -B scripts/multitopic.py serve /work/review --port 0
```

参数、最小输入和检查边界见 [合同](references/contracts.md)。所有输出均在核心外；独立调用不要求安装另一份私人工作流。
