# 完成检查

先读同级共同合同。通用命令：`python -B ../yl-knowledge/scripts/knowledge.py --profile PROFILE check`；查看 `queue`，并检查本次来源清单是否全登记。脚本只能验证已登记材料，不能把未登记旧材料当作不存在。

已有库还要运行个人配置中已核实的来源、原子、逐字、关系和网络校验，读取报告内容与退出码。语义提炼是否完整要回读逐份原文和覆盖记录，不能仅靠哈希、字段或关键词判断。跨来源队列必须逐项处理或报告。

检查原文是否保持、每步引语是否准确、同义是否合并但保存变体、来源是否遗漏、作者/确认状态是否越级、作品关系能否双向打开。新旧来源中的同一概念是否连接。

按“本次新增/变更、已完整处理、合并、无需新增、明确排除、仍未完成”交付。云端未调用、原音未听、界面未打开、未登记旧库等必须如实说明；不能以安装/测试成功宣称真实全库已收尾。
