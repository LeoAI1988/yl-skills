# 完成检查

先读同级共同合同。通用命令：`python -B ../yl-knowledge/scripts/knowledge.py --profile PROFILE check`；查看 `queue`，并检查本次来源清单是否全登记。脚本只能验证已登记材料，不能把未登记旧材料当作不存在。

已有库还要运行个人配置中已核实的来源、原子、逐字、关系和网络校验，读取报告内容与退出码。语义提炼是否完整要回读逐份原文和覆盖记录，不能仅靠哈希、字段或关键词判断。跨来源队列必须逐项处理或报告。

本地新增同步先核对 `yl-knowledge-import/scripts/discover_local.py` 的发现清单、登记与处理收据三者；无边车文稿不能遗漏。已登记未读、旧哈希变更、原音未核分别列明，发现队列为空不能替代语义验收。

校验范围要以实际枚举的文件清单和调用链为准，不因脚本中出现旧路径常量就断言它只检查旧库。若同一中央库有多种对象格式，分别核对各格式校验覆盖、退役数量与未覆盖项，再合并验收；某一格式通过不能代替整个中央库通过。文字匹配警告中的“解释待本人确认”也不能改说成“来源待确认”。

检查原文是否保持、每步引语是否准确、同义是否合并但保存变体、来源是否遗漏、作者/确认状态是否越级、作品关系能否双向打开。新旧来源中的同一概念是否连接。

读取 `yl-knowledge-search/references/retrieval.md`；检查全文及语义覆盖、版本、来源定位和真实问题命中。用原文独有表达、未提炼段落与相似不同立场做正反测试。原话核验失败不能继续宣称已核引文；没有校图/校音不因匹配错误草稿而转正。来源清单不完整时只能报本次范围，不能用旧报告或空队列宣布全库完成。

按“本次新增/变更、已完整处理、合并、无需新增、明确排除、仍未完成”交付。云端未调用、原音未听、界面未打开、未登记旧库等必须如实说明；不能以安装/测试成功宣称真实全库已收尾。
